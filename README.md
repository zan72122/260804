# ピザやさん — 石窯のピザ職人ごっこ（WebGL 3D）

4さいの女の子が、iPhone / iPad の**たて画面・よこ画面**どちらでも遊べる、
ピザ職人あそびの Web ゲームです。文字は 1 文字も出てきません。

`index.html` を開くだけで遊べます（ビルド不要・画像/音声ファイルゼロ・オフライン可）。

---

## このゲームの主役は「具をのせること」ではありません

ピザ職人にしかない **からだの動き** を看板にしています。

**まわす → とばす → ピールにのせる → 窯の奥へスッ → 窯の中でクルッ → 手前へスッ**

とくに **ピールで石窯へ滑り込ませる操作**（シグネチャーアクション）は、
指のレイを窯への経路に射影して **ピールとピザが指と 1 対 1 で前進**し、
最後のひと押しで **ピザだけが炉床にスルッと残り、ピールが手前へ戻ります**。
「窯をタップしたら消えた」式の表現はどこにもありません。

---

## 描画は実 3D 空間（WebGL）

CSS の擬似 3D ではなく、**透視投影・深度バッファによる遮蔽・実ジオメトリ**を
持つ 3D 空間です。カメラが動けば視差もそのまま出ます。

**空間の分離**

| | 中身 |
|---|---|
| 近景 | 大理石の作業台、打ち粉の板、生地、具材の器、ピールの柄 |
| 中景 | ピール、窯口のレンガアーチ、すすけた迫石、職人 |
| 遠景 | 炉床の奥、薪、炎、レンガの壁、天井の梁 |

奥ほど暗く、フォグで彩度が落ち、窯口の中は熱でゆらぎます。
ピザが窯の奥へ進むと**アーチに実際に隠れていきます**（描画順ではなく深度バッファ）。

**実寸で作ってあります**（単位はメートル）

- 炉床の高さ 1.05 m ／ 窯口 0.58 × 0.50 m ／ ドーム外径 1.90 m ／ 窯壁の厚み 0.20 m
- 作業台の高さ 0.92 m ／ ピール：ブレード径 0.37 m・柄 1.45 m・厚み 9 mm
- ピザ：直径 0.30 m ／ 生地 4 mm ／ ふち（コルニチョーネ）は焼成で 20 mm まで実際に膨らむ
- 職人 1.72 m

窯のドームは**クリップ面で正面を切って**あり、その断面を同じ漆喰の厚い壁が
ふさいでいます。壁には窯口がくり抜かれ、内側は耐火レンガで張ってあるので、
窯口には本当に奥行き 0.20 m のトンネルがあります。台座の前面の薪置き場も
実際にえぐってあり、奥に薪が積んであります。

**材質**

すべて手続き的に焼いたテクスチャで、色だけでなく **法線マップとラフネスマップ**を
持たせています（レンガ、漆喰、オーク、バーチ、大理石、テラコッタ、耐火レンガ）。
環境マップを入れてあるので、大理石と磁器はつやが出て、木はマットに沈みます。

**汚れと摩耗**

窯口まわりのすす、炉床の焦げつき、レンガの欠け、板の打ち粉、薪の炭化。

**光**

窓からのキーライト（影を落とす）、天井の吊りランプ、**炎の点光源**（ゆらぐ）、
窯口からもれる光。後処理でブルーム、熱のゆらぎ、ACES トーンマッピング。

窯の中は塗りで明るくせず、**暗い耐火レンガに炎の光だけが当たる**ように
してあります。炎は 5 種類の舌のスプライトを 16 枚、高さも揺れ方も別々に
動かしていて、ひとつの塊には見えません。

## あそびの流れ（ぜんぶ絵とジェスチャーだけ）

| | やること | 指の動き |
|---|---|---|
| 1 | 生地玉を置く | 器から板へタップ／ドラッグ |
| 2 | 押し広げる | 生地の上をなぞる（押した方向に伸びる） |
| 3 | まわす | 円を描く（遠心力でまるく・大きくなる） |
| 4 | 空中へとばす | 上へスワイプ（実際に空中で回転する） |
| 5 | ソースをぬる | 中心から外へ、うずまきを描く |
| 6 | 具をのせる | 器から大きくドラッグ（チーズはなぞると降りつづける） |
| 7 | ピールへ移す | ピザをピールへドラッグ（吸着あり） |
| 8 | **窯の奥へスッ** | **画面奥へ長いスワイプ** |
| 9 | 焼ける | 見て楽しむ（窯をつつくと火がぶわっ） |
| 10 | **窯の中でクルッ** | ぐるっと円を描く |
| 11 | 手前へスッ | 手前へスワイプ |
| 12 | カット | 大人の職人がカッターを持ち、なぞって切る／1切れ持ち上げるとチーズが伸びる |
| 13 | つぎをえらぶ | おなじピザ／ちがうピザ／じゆうに |

メニューは **マルゲリータ / コーン&チーズ / カラフルやさい / じゆうトッピング**。

**焦げは炎に近い側ほど濃くなります。** だから窯の中で回す操作に意味があります。

具材は板ではなく**立体**です。チーズは焼けると実際に平たく広がり、
ラフネスが下がって照りが出ます。切り分けたピザは**別々のくさび形メッシュ**で、
1切れ持ち上げるとチューブジオメトリのチーズが伸びます。

## 4 さいのための設計

- **失敗がない** — 生地は落ちない、焦げて食べられなくなることもない、叱られない
- **文字ゼロ・数字ゼロ** — 得点・星・お金・待ち時間・ゲームオーバーなし。
  次にすることは、床に置かれた光る輪・経路に浮かぶ矢羽根・くり返し動く手だけで伝えます
- **止まらない保険** — 15 秒さわらないと職人がやってみせ、何もしなくても最後まで一周します
- **指ひとつで完結** — ドラッグには吸着（具材・ピール）と軌道補正（ピールは経路へ射影）
- **安全な構図** — 高温の窯に手を入れる絵はありません。
  プレイヤーが操作するのは 1.45 m のピールで、窯のそばに立つのは大人の職人です

## 画面の向き

- **たて**：ピザと手元を大きく。窯は正面、手前から奥へ突き上げる長いスワイプ
- **よこ**：職人・ピール・石窯がひと続きの空間。カメラを振って長い斜めのスワイプに

向きを変えるとカメラの構え（見る点・画角・振り角・伏せ角）が組み替わります。
たて画面ではレシピの皿を 2×2 に並べ替えてカメラを寄せ、
よこ画面では横一列にして職人と窯を同じ画面に収めます。

ピールを操作するのはプレイヤー自身です。職人はそれを取り上げず、
作業台の向こう側で見守り、カットのときだけ手を出します。

## ファイル

```
index.html
vendor/three.min.js   three.js r149（MIT・UMD 版なので file:// でも動く）
css/style.css
js/util.js     算数・補間・乱数
js/audio.js    WebAudio の効果音合成
js/tex.js      手続き的なアルベド／法線／ラフネス生成
js/geo.js      実寸ジオメトリ（アーチ壁・ドーム・ピール・器…）
js/scene.js    店の 3D 空間の組み立てと寸法定義
js/pizza.js    ピザの実ジオメトリ（生地・ふち・具材・スライス・チーズの糸）
js/fx.js       炎・熾火・粉・煙・熱のゆらぎ・ブルーム
js/stages.js   あそびの流れ
js/game.js     描画・照明・カメラ・入力（レイキャスト）・案内表示
tools/         検証用
```

## 検証

```
node tools/logictest.js iphone-p|iphone-l|ipad-p|ipad-l   # 実操作で一周できるか
node tools/idle-test.js iphone-p|...                      # 無操作でも一周できるか
node tools/shots.js     iphone-p|...                      # 各場面の見た目を撮影
node tools/playtest.js  iphone-p|...                      # 実時間で操作（GPU が要る）
```

（Playwright + Chromium が必要です。CI 環境のソフトウェアレンダラでは
実時間の描画が遅すぎるため、操作の検証は `logictest.js` を使ってください。）
