# クルッ！スルスル！ひかる標本ラボ

4歳の女の子が、iPhone / iPad のブラウザで指一本で遊べる 3D ミニゲームです。

パラフィン包埋ブロックをミクロトームで薄切し、連続切片のリボンを伸ばし、
温浴槽で伸展させ、スライドガラスですくい取り、脱パラフィンして蛍光染色し、
封入して、暗い蛍光顕微鏡でピントを合わせる——という
病理組織標本作製にしかない動作の鎖を、そのまま指の動きに変換しています。

中心にあるのは4つのシグネチャーアクションです。

| | 動作 | 指の入力 |
|---|---|---|
| **クルッ** | ハンドホイールを回すと、ブロックが刃を通り、切片が一枚生まれる | 円を描くドラッグ |
| **スルスル** | 切片がつながって、半透明のリボンが伸びていく | （同じ円運動を続ける） |
| **フワッ** | 縮れた切片が水面で、ゆっくり平らに開く | ドラッグして離す／水面をなでる |
| **パッ** | 暗い円形視野に、蛍光像が突然結像する | 大きなフォーカスノブを回す |

点数も、星も、制限時間も、ゲームオーバーもありません。失敗して標本が失われることもありません。

## 遊ぶ

```bash
npm install
npm run dev      # http://localhost:5173
```

ビルドして静的配信する場合:

```bash
npm run build    # dist/ を任意の静的ホスティングへ
npm run preview
```

WebGL2 が使えるブラウザが必要です（iOS 15 以降の Safari、Chrome、Firefox）。
WebGPU は使っていません。

## 設計のかなめ

### 一回転 ＝ 一枚

ハンドホイールの角度は `CircleTracker` が符号付き・非巻き戻しで積算します。
その角度の **どの区間で刃がブロックの中にいるか** までモデル化してあり
(`CUT_A`〜`CUT_B`)、切片はその区間だけで少しずつ生えてきます。
だから「回した分だけ出る」「途中で止めれば途中まで」「逆に回せば引っ込む」が
そのまま画面に出ます。逆回転しても、すでに出来上がった切片は絶対に減りません。

自動テストでも、2.2回転がきっかり 2.00 枚になることを毎回確認しています。

### 極薄に見せる

リボンは spline から毎フレーム作り直す ribbon mesh（約250頂点）です。
紙に見せないために効いているのは主に3つ:

- **接線まわりのねじれ** — 帯が光を拾い、一瞬だけ厚みがゼロに見える
- **プリマルチプライド合成** — 膜は背景を暗くせず、光を足すだけ
- **背面のディフューザー壁** — 数µmの膜が見えるのは、後ろから照らしているから

### 神の断面図

現実の肉眼では同時に見えないものを、ゲームでは見せます。
ミクロトームの筐体は半透明で、ブロックが刃へ進む量はゲージで読めます。
温浴槽はガラスで、水面・浮かんだ切片・水中のスライドが同時に見えます。
染色中は、色素が構造に結合していく様子だけを小さな窓で象徴的に見せ、
**完成像は顕微鏡まで一切見せません。**

### カメラ

自由カメラ操作はありません。10 個のショットが縦横それぞれに用意してあり、
ゲーム側が「いまその動作が一番よく見える位置」へ移動します。
薄切中だけは、リボンが伸びるにつれて画角が連続的に開いていきます。

### 音

音声ファイルはゼロで、すべて WebAudio の合成音です。
入力と音がずれようがない作りになっています
（カチッ／クルッ／スッ／スルスル／ポチャン／フワーッ／スーッ／コトッ／クルクル／パッ）。
最後の蛍光 Reveal だけは、あえて静かなベル和音にしてあります。

### 毎回ちがう標本

標本は 1 つのシード値から手続き的に生成されます。
組織の形（腺管・枝分かれ・密集）、リボンの波打ち、水面での広がり方、
そして最後に光る蛍光像まで、すべて同じシードから作られるので、
ブロックの中に見えていた形が、最後にちゃんと光ります。

## 構成

```
src/
  main.ts              起動・描画品質・リサイズ・フレームループ
  core/
    input.ts           一本指のポインタ + CircleTracker（クルッ／クルクル共通）
    rig.ts             スクリプトカメラ
    audio.ts           手続き的効果音
    util.ts            イージング・シード付き乱数
  gfx/
    materials.ts       パラフィン／ガラス／環境マップ／ヒントリング
    ribbon.ts          連続切片リボン（本作の看板）
    section.ts         切片（縮れ→平らの morph）
    water.ts           温浴槽の水面（解析的な波紋）
    fluoro.ts          蛍光視野（ピント・色収差・円形視野）
    fx.ts              脱パラフィンの湯気／染色の結合ウィンドウ
    hints.ts           言葉を使わない誘導
  world/
    lab.ts             ラボのジオラマ一式
    shots.ts           縦・横それぞれ 10 ショット
    props.ts           スライド・カバーガラス・封入剤・水滴
  spec/specimen.ts     標本の手続き生成（Canvas2D）
  game/game.ts         10 シーンのステートマシン
qa/
  play.mjs             4画面サイズでの自動通し操作（--abuse で誤操作試験）
  look.mjs             任意のシーンの画づくり確認
```

## 性能

- WebGL2 相当で完結。ポストプロセスパス無し（bloom はシェーダ内）
- 影マップ無し（接地影はスプライト）
- 布・流体・大量パーティクルは不使用
- 端末に応じて `low` / `high` の2段階（テクスチャ解像度・分割数・ボケのタップ数）
- 実測フレームが重い場合は描画解像度を自動で段階的に下げます

## 自動検証

```bash
npm run dev
node qa/play.mjs                      # 4サイズすべてを通しでプレイ
node qa/play.mjs iphone-portrait --abuse
```

`--abuse` は、連打・円運動の途中で指を離す・逆回転・水面外への投げ捨て・
染色工程の連打・フォーカスノブの高速回転・バックグラウンド復帰まで実行し、
**どの誤操作でも進行不能にならないこと** を確認します。
