# のぼって！みがいて！ひかりの灯台

4歳の女の子のための、灯台守のブラウザゲームです。
iPhone / iPad の縦画面・横画面どちらでも、指だけで最初から最後まで遊べます。

夕暮れの海にぽつんと立つ灯台。扉を開けて、らせん階段をくるくるのぼり、
大きなレンズをきゅっきゅっと磨き、歯車を戻し、ハンドルをぐるぐる回して、
最後に大きなスイッチをガチャンと入れる。
暗い海を一本の光がスーッと横切り、迷っていた船が正しい航路へ進みはじめます。

**失敗・時間切れ・点数・こわい演出はひとつもありません。**

## 遊びかた（文字が読めなくても遊べます）

| 場面 | すること |
| --- | --- |
| 扉のまえ | 画面をタップ |
| らせん階段 | 上へスワイプ（タップでも一段のぼれます） |
| 踊り場の小窓 | 雨戸をタップすると開いて、海と海鳥が見えます |
| 灯室・レンズ | 指でこする。こすったところだけ透明になって海が見えます |
| 歯車 | 台の上の歯車を、光っている穴へドラッグ |
| ハンドル | ぐるぐる回す（ジグザグでも進みます） |
| 大きなスイッチ | 下へドラッグ、またはタップ |
| 点灯後 | 見ているだけ。船が汽笛と光で返事をします |

終わったあとは「もういちど つける」「べつの よる」「じゆうに あそぶ」から選べます。

## 遊べるようにする

```bash
npm install
npm run dev      # 開発サーバ
npm run build    # 型チェック＋本番ビルド（dist/ へ出力）
npm run preview  # ビルド結果の確認
```

`dist/` は相対パス（`base: './'`）で出力されるので、静的ホスティングにそのまま置けます。

## 中身のこと

TypeScript + [three.js](https://threejs.org/) + Vite。CSS で立体風に見せるのではなく、
本物の 3D 空間・実ジオメトリ・遮蔽・接触影で奥行きを作っています。外部アセットはゼロで、
形も音もテクスチャもすべてコード生成です。

```
src/
  core/
    game.ts       場面の進行、カメラ演出、入力の割りふり
    input.ts      Pointer Events を一本化（スワイプ／ぐるぐる判定）
    audio.ts      WebAudio による効果音・環境音・やさしいパッドの合成
    state.ts      一回の点灯で持ち回る状態と保存
    palette.ts    天気・灯りの色・汚れの種類などの設定
  world/
    sky.ts        夕焼け→夜のグラデーション、雲、星
    ocean.ts      ゲルストナー波、空の映り込み、海面をわたる光の帯
    lighthouse.ts 塔（窓は本当の穴）、らせん階段、灯室、屋内ライティング
    keeper.ts     灯台守の女の子（うしろ姿と視線で行き先を示す）
    lens.ts       回転レンズと、指でこすって消せる「よごれの殻」
    machinery.ts  歯車・ベルト・ハンドル・大きなスイッチ
    beam.ts       入れ子の筒でできた、立体的な光の筋
    weather.ts    霧粒・雪（ビームの中だけきらめく）
    ships.ts      小型船・客船・漁船。光を見つけると航路を変えて汽笛を返す
    geom.ts       窓の穴があいた厚みのある壁、階段の一段
  ui/ui.ts        絵文字中心の最小限の UI
```

### 作りのポイント

- **窓は本物の穴** — 壁は外面・内面・窓のかえしを持つ一枚のジオメトリとして生成しています。
  だから内側からのぞくと、視差も遮蔽も正しいまま外の海が見えます。
- **磨きは実際に消える** — レンズの外側にかぶせた殻に CanvasTexture を貼り、
  指でなぞったところを `destination-out` で消しています。消えた穴からは、
  レンズのガラスと灯室のガラス越しに本物の海が見えます。円・ジグザグ・直線、どれでも成功します。
- **光の筋** — 加算合成の板を重ねると白飛びするので、太さのちがう筒を3枚だけ入れ子にして
  やわらかい芯を作っています。海面・霧粒・壁と床の反射は、同じ「回転角」を共有した
  別々のシェーダで表現しているので、光が一体のものとして動きます。
- **点滅させない** — 灯りは 2.4 秒かけてゆっくり立ち上がり、そのあとは穏やかに光り続けます。
  画面全体を高速で明滅させる演出は入れていません。
- **画面回転で状態を失わない** — 回転は resize として扱い、上った段数・磨いた範囲・
  直した歯車・点灯状態はそのまま保たれます。縦では塔の高さと縦長の光を、
  横では灯室と広い海を同時に見せるよう、場面ごとに構図を作り分けています。
- **モバイル Safari 向け** — 端末の画素数とコア数から品質を決め、フレーム時間が延びたら
  自動で解像度を落とします。階段・支柱・手すり子はインスタンシングで描画コールを抑えています。
  AudioContext は最初のタップまで作りません。

## 初期コンテンツ

- 天気 3 種（はれた夕方 / 霧の夜 / 雪の夜）
- レンズの汚れ 3 種（塩の粒 / 白い曇り / 水の粒）
- 灯りの色 4 種（きんいろ / ももいろ / みずいろ / にじいろ）
- 船 3 種（小型船・客船・漁船／全 5 隻）
- 階段の踊り場でみつかる小さなもの 8 種（貝・ねこ・びん・星・海鳥・花・オルゴール・リボン）
