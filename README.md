# ぽんぽん！ まほうの花さかガーデン 🌷

4歳児がiPhone / iPadのブラウザで遊べる、お絵かき×ガーデニングのWebゲームです。

**指で1本の線を描く → 線の先の光を「ぽん！」とタップ → 描いた線がそのまま茎になって、花が咲く → 蝶がやって来る。**

## あそびかた

1. 画面をひとさし指でなぞって、すきな線を描く
2. 線の先に出てくる光を「ぽん！」とタップ（ずれても大丈夫、失敗はありません）
3. 描いた線から葉っぱが生え、花びらが開いて、花が完成
4. 蝶やテントウムシがやって来て、花は庭にずっと残ります

文字の説明はありません。初回だけ半透明の指が描きかたを実演します。

## 描いた線で花が変わる

線そのものが茎として永久に残り、線の形が花の種類を決めます。

| 描く線 | 咲く花 |
| --- | --- |
| みじかい線 | まるまる花（ちいさな丸い花びら） |
| まっすぐな線 | ほしほし花（星形・先がキラキラ） |
| ゆるいカーブ | ひらひら花（半透明の花びら2重） |
| S字 | ふわふわ花（タンポポの綿毛） |
| ジグザグ | つぶつぶ花（小さな花の房＋葉がたくさん） |
| ぐるぐる | くるくる花（渦巻き） |
| 蛇行する線 | つる植物風（葉とくるくるのひげ） |
| 横向きの線 | 横を向いて咲く花 |

さらに、線の長さ＝花の大きさ、「ぽん」を長めに押す＝大輪、選んだ色（ピンク／ラベンダー／にじいろ）＝花全体の色になります。ランダムなのは模様などの小さな飾りだけです。

## 特徴

- **子どもの線を消さない**: 補正は最小限のスムージングのみ。完成後も「ここ、私が描いたところ！」と指させます
- **クレヨン質感の描線**: 色むら・粒子・厚み・ラメ・発光粒子つき。テクスチャは決定論的で、開花後も描画時と同じ見た目
- **失敗なし**: 点だけでも小さな芽が育ち、タップがずれても先端に吸着します
- **庭に蓄積**: 花は消えず（localStorageに保存）、風で揺れ、蝶が花から花へ移動。3本咲くと虹が出ます
- **効果音は全てWebAudio合成**: クレヨンの「しゃらしゃら」、ぽん！、花びらの「ぽぽぽ」、完成のキラキラ、蝶の羽音
- **iOS Safari最適化**: pointer events / safe-area / 高DPI / スクロール・ズーム抑止 / 低性能端末では粒子を自動削減

## 動かしかた

ビルド不要・依存ゼロの静的サイトです。

```bash
# ローカルで
python3 -m http.server 8000
# → http://localhost:8000 をiPhone/iPad/PCブラウザで開く
```

GitHub Pagesにそのままデプロイできます（`index.html` がエントリポイント）。

## 構成

```
index.html      エントリポイント
style.css       UI（色ボタン3個＋もどすボタンのみ）
js/util.js      数学・イージング・決定論的乱数
js/audio.js     WebAudio効果音（全て合成）
js/bg.js        庭のジオラマ背景（プロシージャル描画）
js/crayon.js    魔法のクレヨン描線（Hero Material）
js/flower.js    線の解析 → 花のパラメータ化 → 開花レンダリング
js/creatures.js 蝶・テントウムシ
js/main.js      入力・状態遷移・カメラ・パーティクル・保存
```
