# きって！つないで！ひかりの窓

4さい（女の子）向けの、ブラウザで遊べるステンドグラス職人ごっこ。
モチーフを選び → ガラスを切り → 色をはめ → 金属の継ぎ目でつなぎ → 磨き →
窓に取り付け → **雨戸をあけると、暗い工房が色の光でいっぱいになる**。

- 実装: HTML + CSS + JavaScript（**WebGL による実 3D 空間**。ライブラリ・外部素材なし）
- 対応: iPhone / iPad の縦持ち・横持ち、1本指のみ、失敗なし
- 起動: `index.html` をブラウザで開くだけ（ビルド不要）。
  ローカルサーバ推奨: `npx http-server -p 8080` → `http://localhost:8080/`

## 遊びかた（文章は最小限、画面はぜんぶ指で触れる）

| 工程 | 画面の言葉 | 操作 |
| --- | --- | --- |
| モチーフを選ぶ | えらぶ | 浮かんでいる 4 枚の型紙（おはな / ほし / ねこ / ちょうちょ）をタップ |
| ガラスを切る | きる | 板の上をなぞる。近くの切り線が光り、ピースが少し浮いて離れる |
| 色をはめる | いろ | 下の丸い色をタップして選び、ピースをタップ（なぞってもOK） |
| 継ぎ目をつなぐ | つなぐ | もう一度なぞる。金属のケイムが継ぎ目に伸びていく |
| 磨く | みがく | 曇りの上を指でこする。こすった所だけ透明になる |
| 窓に付ける | つける | 上へドラッグ。パネルが弧を描いて窓へ収まる |
| 雨戸をあける | あける | 横へドラッグ。中央から外へ、光が一気に広がる |
| 眺める | — | 1本指で見回し。右下のボタンで もういちど / いろちがい / 時間帯 |

**失敗しない設計**: どの工程も進むだけで戻らない。手が止まって数秒たつと
自動で少しずつ進み、ヒントの光る輪が「次に触る場所」を指す。

**最後の揭幕を最大化するための隠し方**:
準備中は雨戸が閉じたままで、工房は作業灯だけの暗がり。ガラスも
「すりガラスの生地色」で表示され、色は乗っても *光ってはいない*。
背面採光が入るのは雨戸を開けた瞬間だけで、そこで初めて完成形が現れる。

## 3D / 描画の作り

CSS の擬似 3D ではなく、透視投影・深度による遮蔽・視差・実ジオメトリを持つ
WebGL 空間。GLSL は ES 1.00 で書いてあるので WebGL1 / WebGL2 の両方で動く。

### 空間と寸法（すべて実寸メートル）

- 部屋 4.2 × 4.6 × 2.75 m / 壁厚 0.34 m（窓の見込みが深く、視差が出る）
- 窓 内法 1.32 m 幅、腰高 0.78 m、上部は半径 0.66 m のアーチ
- ステンドグラス板 1.12 × 1.10 m / 板厚 6 mm / ケイム幅 15 mm・出 6 mm
- 作業台 1.80 × 1.16 m、天板高さ 0.81 m、脚 75 mm 角
- 雨戸 0.98 × 2.14 m の 2 枚引き（別レール、中央で重なるので光が漏れない）

### 奥行きの分離

- **近景**: 作業台・道具（カッター、やっとこ、布、木箱）・作業灯
- **中景**: 窓、深い見込み、木の枠、雨戸
- **遠景**: 屋外の地面、3 列の稜線（46 m / 105 m / 230 m）、木立
  → 距離に応じた指数フォグ（空気遠近）で彩度と対比を落とす

### 色つきの光（この作品の中心的な仕組み）

太陽方向から見た **透過光マップ**（512²）を毎フレーム作る。

- RGB チャンネル: ガラス片の色 × 透過率（磨き残しの曇りも反映）
- A チャンネル: 不透明な遮蔽物（雨戸・窓枠・作業台）の光源空間深度

受光面のシェーダは、自分の光源空間深度と A を比べて遮蔽を判定し、
通っていれば RGB を太陽光に掛ける。結果として

- 床や壁に **正しい透視でゆがんだステンドグラスの模様** が落ちる
- 作業台は **色つきの影** を落とす
- 雨戸が閉じていれば全部きちんと暗い

同じマップを光の柱（窓開口を太陽方向へ押し出したプリズム）と、
その中を漂うほこりの粒も参照するので、空間の光が一貫する。

### マテリアルと照明

- GGX スペキュラ + ランバート拡散、半球アンビエント、点光源（作業灯）
- 手続き的なディテール: 床の板目・目地・摩耗・隅の汚れ、漆喰のこて跡と
  下端のしみ、鉛ケイムの曇り、塗装木の剥がれ、ガラスのうねりと気泡
- 太陽光は環境光の 100 倍以上（実際の屋内外の照度比に近い比率）
- ACES 風トーンマップ + ブルーム（明度をアルファに載せて 1/4 解像度で抽出）
  + ビネット + 微細なグレイン
- ガラスの平均色から擬似的な一次反射色を作り、室内をほんのり染める
- 接地影は乗算合成の板で、家具が床に「載って」いるように見せる

### 音（すべて WebAudio の合成音、素材ファイルなし）

切る音（帯域通過ノイズの掃引）、色をはめる澄んだ音（ペンタトニック）、
ケイムの金属音、磨くこすり音、雨戸のごろごろ音と木の当たり音、
揭幕のパッドとアルペジオ、屋外の鳥。最初のタップで AudioContext を起こす。

### 性能

- 全ジオメトリは 3 万三角形以下、ドローコールは 100 前後
- 描画解像度は devicePixelRatio 上限 2.0 かつ総画素 210 万でクランプ
- fps を 1.2 秒ごとに測り、遅ければ解像度スケールを自動で下げる
- 準備中（雨戸が閉じている間）は透過光マップの描画自体を省く

## ファイル構成

```
index.html          画面と読み込み
styles.css          最小限の UI（工程の言葉 / 色パレット / 3 つの丸ボタン）
src/math.js         ベクトル・行列
src/gl.js           WebGL ラッパ（シェーダ / メッシュ / FBO / 点群）
src/geom.js         ジオメトリ生成（箱・円柱・押し出し・掃引リボン・稜線）
src/shaders.js      GLSL 一式
src/motifs.js       モチーフと板の割り付け（中心円 + 放射 8 分割 + モチーフ）
src/world.js        部屋・窓・雨戸・作業台・屋外・パネル生成
src/renderer.js     透過光マップ → シーン → ブルーム → 合成
src/audio.js        合成音
src/game.js         工程の進行、入力、カメラ演出、時間帯・配色
src/main.js         起動とメインループ
```

## 再プレイ

右下のボタンで、モチーフ（4 種）× 配色（にじ / うみ / ゆめ）×
時間帯（ひる / あさ / ゆうがた / よる）を切り替えられる。
時間帯は太陽の向きと色、空、霧、作業灯の強さまで変わるので、
床に落ちる模様の形と伸び方もそのつど変わる。
