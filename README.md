# あわせて！くらくして！ ほしぞらドーム

4さいの女の子が iPhone / iPad（たて・よこ どちらでも）で あそべる、
**プラネタリウム技師** の ブラウザゲームです。

小さな技師の女の子が ドームホールの 中を あるいて、
レンズを みがき、棚から ほしぞらディスクを 抜いて 胸に かかえて はこび、
投影機に さしこみ、惑星を あわせ、しゃがんで 電源を つなぎ、
さいごに 主投影レバーを ひきさげます。
そして 天井が ほんとうの 夜空に なります。

**画面に 2D の UI は ひとつも 出ません。** あそびの ぜんぶが 3D 空間の 中に あります。

外部ライブラリなし。HTML + CSS + JavaScript と 生の WebGL だけ。
音も すべて WebAudio で その場で 合成しているので、画像・音声ファイルは 1つも ありません。

## あそびかた

`index.html` を ブラウザで ひらくだけ。ビルドも サーバも いりません。

```
open index.html          # macOS
# または
python3 -m http.server   # http://localhost:8000/
```

iPhone / iPad の Safari、Android Chrome、PC の Chrome / Safari / Firefox で うごきます。

## ゲームの ながれ

ひらくと、うす暗い ドームの 中に 女の子が 立っています。
足もとの **光る輪を タップ** すると 会場の 照明が つき、しごとが はじまります。

**うごきかた** … 床の 光る 足あとパッドを タップすると、そこまで 歩いていきます。
どこへでも 自由に 歩けます。次に いく もちばの パッドだけが 大きく 脈うち、
そこへ 光の すじが ながれます。3秒 まよっていると、彼女が その ほうを 指さします。

| # | もちば | しごと | すがた |
|---|---|---|---|
| ① | 投影機の 対物レンズ | ゆびで こすると くもりが 晴れる | 前かがみで クロスを あてる |
| ② | 壁ぎわの ディスク棚 | 4枚から 1枚 えらんで タップ | 手を のばして 抜きとる |
| ③ | 投影機の 差込口 | かかえた ディスクを ドラッグ（タップでも 入る） | **両手で かかえて 運ぶ** |
| ④ | 惑星コンソール | 3つの 球ノブを レールで すべらせる | 卓に 手を のばす |
| ⑤ | 壁の下の 配電盤 | ケーブルを ソケットへ（近づけると 吸いつく） | **しゃがむ** |
| ⑥ | 主投影レバー台 | 下へ ドラッグ（タップでも 下りる） | 両手で にぎる |

そのあと 彼女は ドームの まんなかへ 歩いていき、見あげます。
星空が ひらいてから **28秒** ながめる 時間が あり、
やがて 足もとに ふたつの 光る輪が 現れます。

- ✦ の 輪 … **もういっかい**（同じ ほしぞら）
- ディスクが まわる 輪 … **ちがう ほしぞら**（棚から やりなおし）

輪の ほうへ 歩いて 乗ると、次が はじまります。

### 4さい向けに していること

- 操作は すべて **ゆび1本**。2本指の 操作は ひとつも ありません。
- タイマー・とくてん・ゲームオーバー なし。**しっぱいできません。**
- あたり判定は 見た目より 大きめ。ねらいが あまくても、いちばん 近いものを 拾います。
- もちばの すこし 手前で 止まっても、そこから 自動で 一歩 すすんで しごとが 始まります。
- **文字が ひとつも 出ません。** 光・うごき・音・すがた だけで つたえます。

## フィナーレで おきること

彼女の 後ろ姿を 画面に のこしたまま、いっしょに 見あげます。

1. レバーを さげている あいだ、その場で 会場が 暗くなる
2. 彼女が ドームの まんなかへ 歩いていって、空を 見あげる
3. ドームが 白から 深い夜へ かわる
4. 星が **ひとつずつ** ぽつぽつと 現れる（音も 1つずつ）
5. そして **いっきに** 天頂から 外へ ひろがる
6. 星座線が つながる。そのたびに **彼女も カメラも その星座を 向く**
7. 惑星が ゆっくり 動く（おつきさまテーマでは 大きな 月も）
8. **天の川が ドームの はしから はしへ 流れる**（星の かわとして 現れます）
9. ときどき 流れ星が よこぎる
10. 足元の 床と 座席に 星あかりの 反射が ともる
11. さいごに ゆっくり 視線が おりて、星あかりの 客席が 見える

## テーマ

| | 星の色 | 星座 |
|---|---|---|
| 🐱 どうぶつ | あたたかい 金色 | ねこ・うさぎ・くま・ことり |
| 🐬 うみ | 青と みずいろ | ひとで・いるか・さかな・かに |
| 🌈 にじいろ | 虹色（天の川も 虹色） | うずまき・ちょうちょ・おうかん・ハート |
| 🌙 おつきさま | 銀と 白（流れ星 おおめ） | おおきなほし・ふね・ひしゃく・こぼし |

棚の ディスクの 色が、その ほしぞらの 色です。
えらんだ ディスクで 空の色・星の色・星座・惑星・天の川の 向きと 色・流れ星の 数が かわります。

### 女の子

球・箱・円柱・角丸箱だけで 組んだ 16パーツ。骨データも モーションデータも ありません。

- **歩き** … 足を 床に おく 軌道を つくり、腰から 2関節IKで ひざを 曲げる
- **しゃがみ** … 腰を 下げるだけ。足は IKが 床に とめつづける
- **手をのばす** … 肩から 目標へ 2関節IK。ひじの 向きは pole ベクトルで きめる
- **かかえる／にぎる** … 両手を 同じ 目標へ。ディスクや レバーは その手に ついていく

### 3D について

- 会場も 星空も **ひとつづきの 3D空間**。照明が 落ちると 同じドーム面が 夜空に なります。
- 星は 頂点シェーダで 大きさ・またたき・出現順を 制御した `POINTS`。
  出現順は「天頂からの 距離 + ゆらぎ」なので、外へ 広がる 波に 見えます。
- 星座線は 帯ポリゴン。先端が 光りながら 描かれます。
- 天の川は「帯にそって おいた たくさんの ちいさな星」＋ ひかえめな グロー。
  端から端へ 星が 順に ともることで 流れて見えます。
- レンズの くもりは 16×16 の LUMINANCE テクスチャ。こすった ところを 削って
  `texSubImage2D` で 送りなおしています。
- ケーブルは 毎フレーム つくりなおす チューブ（`bufferSubData`）。

### うごきの なめらかさ

フレーム時間を みて、おそい端末では 自動的に 描画解像度を さげます
（`Scene.quality`、最大 3段階）。暗転しきったら 会場側の、
明るいうちは 星空側の 計算を シェーダ内で とばしています。
