# ぐるる！どばーっ！ふさぐ！こうろこうじょう

iPhone / iPad のブラウザで遊べる、**4歳児むけの 3D モバイルWebゲーム**です。
テーマは「高炉鋳床における出銑口の開孔と閉塞」。

> **あける → でる → ふさぐ** の循環だけを、何度でも遊べるようにしたゲームです。

```
1. taphole drill（開孔機）が出銑口へ近づく      … スワイプ
2. ぐるぐるして、閉じた出銑口を開ける            … 円運動      「ぐるるるる！」
3. 貫通して、赤い溶銑がどばーっと噴き出す                       「あいた！」「どばーっ！」
4. 溶銑が樋を流れる                              … みているだけ
5. 巨大な mud gun がごごごご……と旋回して近づく  … スワイプ    「ごごごご……」
6. 閉塞材（tap-hole clay）をぐぐぐっと押し込む   … 長押し      「ぐぐぐっ！」
7. 出銑口がふさがる → また 1 へ                                「ふさがった！」
```

---

## あそびかた

| 操作 | ばめん |
|---|---|
| **タップ** | はじめる／もういっかい／溶銑をつつく |
| **スワイプ** | 機械を出銑口へ近づける |
| **ぐるぐる（円運動）** | ドリルをまわして開孔する |
| **長押し** | 閉塞材を押し込む |

操作はこの 4 種類だけです。

- 文章を読まなくても遊べます（絵と動きだけで因果が伝わります）
- **失敗・ゲームオーバー・制限時間はありません**
- 迷うと自然にヒント（指のアニメーション）が出ます
- それでも動かないときは、ゲームがそっと先へ進めます
- 再プレイは **1 タップ**（「もういっかい」／「じゆうにあそぶ」）

### 安全な描き方について

重工業の危険をそのまま再現していません。

- 作業者は溶銑のそばに立ちません。**遠隔操作の機械**と、**防護スクリーンの向こうで見守る整備ロボット**だけが登場します
- 怪我・事故・破壊・恐怖の表現はありません
- そのうえで、炉底・朝顔・炉腹・シャフト・送風環管・羽口・出銑口・樋・取鍋といった
  **高炉らしい固有の形**は残しています

## 起動

ビルド不要・依存ダウンロード不要（Three.js は `vendor/` に同梱済み）。
ES Modules を使うので、**ファイル直開きではなく HTTP で配信**してください。

```bash
npm start                 # http://127.0.0.1:8123 で配信
# もしくは
python3 -m http.server 8123
```

iPhone / iPad からは同じ Wi-Fi 上で `http://<PCのIP>:8123/` を開きます。

## 技術構成

| | |
|---|---|
| 描画 | Three.js r185（`vendor/three/` に同梱、CDN 不要） |
| ベースライン | **WebGL2**（WebGPU がなくても看板体験は壊れません） |
| ビルド | **なし**。素の ES Modules + importmap |
| アセット | **外部ファイル 0 個**。テクスチャ・環境マップ・効果音はすべて手続き生成 |
| 音 | WebAudio による合成（`src/audio.js` の `VOICE_FILES` / `SFX_FILES` に URL を入れると差し替え可能） |

### 「本物の物理」ではなく「意味が分かる偽装」

| 現象 | 実装 |
|---|---|
| drill / mud gun | 剛体の階層（旋回台 → ブーム → スライドする工具）＋単純な transform |
| 溶銑の噴出 | 半径が変化するチューブに emissive シェーダ＋UVスクロール |
| 樋を流れる溶銑 | カーブに沿って掃引した帯メッシュ。`uFill` / `uTail` で先端と末尾が進む |
| 溶銑の「皮」 | fbm ノイズで冷えた酸化膜のまだら模様をつくる（水やマグマに見えないように） |
| 発光 | ポストエフェクトを使わず、加算スプライト＋`toneMapped:false` による擬似ブルーム |
| 飛沫・削り粉・湯気 | CPU 更新の軽量 GPU パーティクル（最大 320 / 140） |
| 出銑口の内部 | 閉塞時だけ耐火ブロックを透かす**局所カッタウェイ**＋孔のガイド表示 |

流体・布・髪・群衆のシミュレーションは一切使っていません。

### カメラ鎖

自由カメラは採用していません（4歳児に視点を探させないため）。
工程ごとに最適なショットへゲーム側が導きます。

`wide → drillIn → drillWork → breakOut → flow → mudIn → mudClose → cutaway → wide`

各ショットは **横画面 / 縦画面それぞれの構図**と、ゆっくり流れる終着ポーズを持ちます。
`lift` パラメータで主役を画面の上寄りに置き、**下半分は指のためのゾーン**として空けています
（指で操作点と観察点が重ならないように）。

- **横画面**：drill（左）／出銑口（中央）／mud gun（右）で工程の位置関係を見せる
- **縦画面**：高炉が上、出銑口が中央、溶銑が上から下へ流れ落ちる構図に組み替える

### パフォーマンス

- 描画：約 20k 三角形 / 約 230 ドローコール（影パス込み）
- 内部解像度は `devicePixelRatio` を **1.75 上限**でクランプ
- フルスクリーンのポストエフェクトは不使用、bloom は局所的な加算スプライトのみ
- 起動時に端末を見て `low` 品質（影オフ・低ポリ・低解像度テクスチャ・粒子半減）へ自動切替
- 実行中も FPS を監視し、34fps を下回ったら解像度と影を自動的に落とす

## ファイル構成

```
index.html          … importmap と UI オーバーレイ
styles.css          … 大きなボタン・擬音・ヒント・ゲージ（縦横対応）
src/
  main.js           … 起動、描画ループ、リサイズ、品質の自動調整
  game.js           … 「あける→でる→ふさぐ」の状態機械（M1〜M7）
  camera.js         … カメラ鎖（横／縦それぞれの構図）
  world.js          … 高炉・出銑口・樋・取鍋・見守りロボット・ライト
  machines.js       … taphole drill と mud gun の剛体階層
  molten.js         … 溶銑（噴流・帯・発光・火花・湯気）
  materials.js      … 4つのヒーローマテリアルと環境マップの手続き生成
  geom.js           … 断面掃引・テーパーチューブ・角丸ボックス
  input.js          … タップ／スワイプ／円運動／長押しの寛容な検出
  ui.js             … 擬音ポップ・タスクバッジ・ゲージ・ヒント
  audio.js          … WebAudio による擬音（差し替え可能）
vendor/three/       … Three.js r185（同梱）
tools/              … QA スクリプト（Playwright）
```

## QA

```bash
npm start &            # 先に配信しておく
npm run qa:shots       # 横／縦それぞれ 11 工程のスクリーンショット
npm run qa:play        # 実際の指の操作を模して 1 周プレイし、遷移を検証
npm run qa:perf        # ドローコール・三角形数・WebGL2 の確認
```

## 音の差し替え

`src/audio.js` の先頭に URL を入れるだけで、合成音より優先して再生されます。

```js
export const VOICE_FILES = {
  guru: './assets/voice_guru.mp3',   // ぐるるるる！
  aita: './assets/voice_aita.mp3',   // あいた！
  doba: './assets/voice_doba.mp3',   // どばーっ！
  gogo: './assets/voice_gogo.mp3',   // ごごごご……
  gugu: './assets/voice_gugu.mp3',   // ぐぐぐっ！
  fusa: './assets/voice_fusa.mp3',   // ふさがった！
};
```

未設定のときは `speechSynthesis`（ja-JP）で読み上げ、それも無ければ効果音のみになります。
