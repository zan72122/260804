# かなざわ きんぱく — Kanazawa Gold Leaf

4歳児向けの、金沢の金箔づくりをなぞる iPhone / iPad 用ブラウザゲーム。
金色に「塗る」のではなく、**金箔という物体そのものの振る舞い**を触って遊ぶ。

```
トントン → ぺろん → ふわっ → ぺたっ → キラッ
たたく    ひらく    ゆれる    のせる    ひかる
```

失敗も、制限時間も、点数も、読ませる文章もない。終わったら素地が変わって、また最初から。

## 遊びかた

| 動作 | 操作 | 起きること |
| --- | --- | --- |
| **トントン** | 画面をタップ ×3 | 槌が落ち、打紙の束が沈み、埃が舞い、机が揺れる |
| **ぺろん** | 上へスワイプ | 打紙が蝶番のように開き、下から極薄の箔が現れる |
| **ふわっ** | 左右になでる | 指の起こした気流で箔に波が走り、端がめくれる |
| **ぺたっ** | 大きくドラッグ | 箔箸で箔を運び、暗い漆の下地の上に落として密着させる |
| **キラッ** | なでる | 毛棒で皺を伸ばすと、表面を反射がひと息に走る |

どの操作も大まかで通る。方向を間違えても、狙いが外れても、進む。

## 金箔の表現

普通の黄色い紙にしないために、箔だけは専用のシミュレーションと専用のシェーダーを持つ。

- **厚みゼロの実ジオメトリ** — 45×45 の膜メッシュ。金箔の実厚は約 0.1 µm（1万分の1 mm）で、
  押し出す厚みなど存在しない。だから板ではなく膜として解いている。
- **減衰波動方程式**（`src/scene/leaf.js`）— 1/240 秒の固定サブステップで解く。
  波が 109 mm の箔を渡り切るのに必要な波速は、1 フレーム刻みでは発散するため。
- **自分から浮く端** — 静止形状そのものが、縁と角でわずかに持ち上がっている。
- **皺の記憶** — 頂点ごとの皺の場が残り、毛棒でなでた場所だけ消えていく。皺は反射を曲げ、
  消えると反射が通る。これが「キラッ」の正体。
- **異方性の光沢** — 打たれた金属なので、ハイライトは点ではなく打ち目に沿って流れる。
- **緑の透過光** — 本物の金箔は透かすと青緑に見える。裏面と斜めの縁でその色が出る。
- **視線角度で変わる不透明度** — 正面からはほぼ不透明、浅い角度では向こうが透ける。

## 画面

- **遠景** 障子の面光源、梁と柱のシルエット、藍の暖簾。空気遠近（指数フォグ）で沈む。
- **中景** 打紙の在庫、膠と灰汁の壺、竹道具の筒。
- **近景** 作業台、革板、打紙束、槌、箔箸、毛棒、真綿、漆の下地。

CSS の疑似3Dではなく、透視投影・遮蔽・視差・実ジオメトリを持つ WebGL2 空間。
影は指向性シャドウマップ、描画は HDR → ブルーム → ACES トーンマップ。
寸法はすべて実寸（メートル）で、作業台の天板が y = 0。

| もの | 寸法 |
| --- | --- |
| 金箔（金沢四号相当） | 109 mm 角 |
| 打紙 | 158 mm 角 |
| 革板 | 322 mm 角 |
| 作業台 | 1420 × 780 mm、天板厚 45 mm |
| 漆の小皿 | 直径 156 mm |

## 工程の下敷きにした事実

幼児向けに工程は大胆に省略しているが、道具と順序の骨格は実際の金沢箔に合わせた。

- 金沢は国内の金箔生産のほぼすべてを占める。
- 金箔の厚さはおよそ **1万分の1 mm**。
- 製造は大きく **澄工程**（澄屋が担当）・**箔工程**（箔屋／箔打師）・**紙仕込み工程** に分かれる。
- 打紙は雁皮紙を灰汁や柿渋で仕込んだもので、この紙の出来が箔の出来を決める。
  ゲーム中の打紙が茶褐色なのはこのため。
- 打ち上がった箔は **竹箸** で **革板**（鹿革張り）へ移し、竹の枠で規定の寸法に切る。
  竹が使われるのは静電気を持たないから。
- 貼るときは、接着剤を塗った面に箔を乗せ、綿や柔らかい刷毛で押さえる。

## 動かす

ES モジュールなので、ファイルを直接開くのではなく HTTP で配信する。

```sh
python3 -m http.server 8123
# iPhone / iPad の Safari で http://<PC の IP>:8123/ を開く
```

WebGL2 が必要（iOS 15 以降の Safari、Android Chrome、デスクトップ各種）。
縦横どちらの向きでも遊べる。画面の縦横比に応じてカメラの引きが変わり、
縦持ちでは上半分が工房の奥行きに使われる。

## 検証

`tools/shoot.mjs` が Playwright で実機相当の画面サイズを開き、5つの動作を実際に操作して
各局面のスクリーンショットを撮り、状態を出力する。

```sh
node tools/shoot.mjs iphone   390 844 1     # iPhone 14/15 縦
node tools/shoot.mjs iphone-l 844 390 1     # 同 横
node tools/shoot.mjs ipad     820 1180 1    # iPad Air 縦
node tools/shoot.mjs ipad-l   1180 820 1    # 同 横
```

## 構成

```
index.html            画面と、大きな文字ひとつだけのオーバーレイ
src/main.js           5つの動作の状態機械、カメラ、進行
src/ui.js             オノマトペと指の動きのアイコン
src/core/renderer.js  影 → HDR → ブルーム → 合成
src/core/shaders.js   材質シェーダー、金箔シェーダー、ポスト
src/core/geometry.js  箱・円柱・回転体・格子の生成
src/core/audio.js     5つの音をその場で合成（音声ファイルなし）
src/core/input.js     タップ／スワイプ／ドラッグ／なで
src/scene/atelier.js  工房（遠景・中景・近景）
src/scene/props.js    道具と下地
src/scene/leaf.js     金箔の膜シミュレーション
src/scene/peel.js     ぺろんと開く打紙
```
