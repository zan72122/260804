# ちょきちょき！カタカタ！おようふく工房

4歳のこどものための、3Dのおようふく工房です。
**きせかえではなく、「たいらな布が立体のおようふくになるまで」そのものが遊びの中心**です。

<p align="center">
  ふわっ　→　なぞる　→　ちょきちょき　→　カタカタ　→　くるん　→　かざる
</p>

---

## 遊びかた（ことばはひとつも出てきません）

| | ステップ | 指の動き | おこること |
|---|---|---|---|
| 1 | **ふわっ** | 画面をなでる | たたまれた布がふわりとひらいて、作業マットの上にひろがります |
| 2 | **なぞる** | 光る点にそって指をすべらせる | チャコで型紙のかたちがえがかれます |
| 3 | **ちょきちょき** | 同じ線をもう一度なぞる | 裁ちばさみが線の上を進み、まわりの布が落ちていきます |
| 4 | **カタカタ** | ふちにそって指をすべらせる | ちいさなミシンが針を上下させ、縫い目がならんでいきます |
| 5 | **くるん** | 指をぐるっと動かす | ぺたんこの布が空にうかび、ひとまわりして、ふくらんだ立体のおようふくになります |
| 6 | **かざる** | したのボタンをえらんで、服をタップ | リボン・おはな・ボタン・おほしさまがつきます |

かざりつけが3つを越えると、つぎの布のたばがテーブルに届きます。
それをタップすると、できあがった服がかべのハンガーラックに並び、
つぎの一着（ワンピース → Tシャツ → スカート → ズボン）がはじまります。

### 4歳児のための約束

- **一指操作だけ** — なでる／なぞる／タップ。二本指の操作もドラッグ＆ドロップもありません。
- **失敗がありません** — 線から指がはなれても進みますし、押さえているだけでもゆっくり進みます。
- **点数も、タイマーも、文章も、数字もありません** — 画面のUIはすべて絵記号です。
- **縦でも横でも遊べます** — 画面の向きが変わると、カメラの構図が組みなおされます。
- **やり直しの必要がありません** — 終わりも失敗もなく、いつまでもつづけられます。

## 動かしかた

ES modules を使っているので `file://` では開けません。静的サーバーが要ります。

```bash
python3 -m http.server 8000
# → http://localhost:8000/
```

外部への通信はゼロです。Three.js は `vendor/` に同梱してあります。
最初のタップで音が鳴りはじめます（ブラウザの自動再生ポリシーのため）。
右上のスピーカーの絵で音は消せます。

## 中身のしくみ

このゲームの核心は、**布のパーティクルが最初から最後まで同じものである**ことです。
たたまれた状態も、ひろげた状態も、切りぬかれた型紙も、縫い上がった服も、
ハンガーで揺れているワンピースも、すべて同じ一枚のシートです。
「布が服になる」という体験は、そこから自然に出てきます。

```
src/
  main.js       起動とメインループ、画面の向きの処理
  world.js      レンダラ・光・作業台・カメラ枠・かべのラック
  cloth.js      ★ 布そのもの。ベルレ積分の粒子シート
  patterns.js   型紙（ワンピース／Tシャツ／スカート／ズボン）と生地の配色
  geom2d.js     多角形まわりの計算と、指にやさしい経路追従
  fabric.js     生地の柄をキャンバスで手続き的に描く
  tools.js      はさみ・ミシン・チャコ・ハンガー・かざり（すべてコードで造形）
  fx.js         きらきら・切れはし・紙吹雪・案内の点・チャコ線・縫い目
  game.js       6ステップの進行
  hud.js        絵記号だけのUI
  audio.js      効果音とオルゴールをWebAudioで合成（音声ファイルなし）
  input.js      一本指だけを見るポインタ
vendor/three/   Three.js r169（同梱）
tools/          開発用のヘッドレス撮影スクリプト
```

### 布の一生

1. **たたむ** — 格子を二回折った位置を解析的に求め、そこから始めます。
2. **ひろげる** — 折り目位置から平らな位置へ目標を補間しつつ、ふくらむ力を足し、
   その上でベルレの距離拘束を解きます。指の動きが進行度になります。
3. **切る** — 型紙の多角形の外にある四角形を落とし、
   残ったふちの粒子を輪郭線の上にぴたりと寄せます。だからシルエットがぼやけません。
   落ちた布は別メッシュになって、ひらひらと落ちて消えます。
4. **縫う** — 縫い目は小さなカプセルのインスタンス。毎フレーム布の表面から
   位置と向きを引きなおすので、布が動けばいっしょに動きます。
5. **返す** — 平らな位置を、型紙の上端を軸に90度おこして、
   同時にY軸まわりに一回転させます。これが「くるん」です。
6. **ふくらむ** — 各粒子には輪郭線までの距離から求めた「ふくらみ量」があります。
   描画時に表と裏の二枚を法線方向へ ±ふくらみ ずらすことで、
   平らな型紙が枕のように立体になります。**これが平面→立体の正体です。**
7. **ゆれる** — 上端を固定し、「返した直後のかたち」をゆるく記憶させたまま、
   重力とそよ風でゆらします。だからつぶれずに、けれど生きて動きます。

### 描画

Three.js r169。`MeshPhysicalMaterial` の sheen で布らしい光り、
ACES トーンマッピング、やわらかい影、控えめなブルーム。
端末の性能に応じて、格子の細かさ・影の解像度・ブルーム・粒子数を切り替えます
（`pickTier()`）。

### 音

音声ファイルは一つもありません。すべて WebAudio の合成です。
ちょきっ（帯域を掃引するノイズ）、カタッ（矩形波のクリックと機械のうなり）、
くるん（五音音階のグリッサンド）、かざり（ペンタトニックのベル）、
そしてゆっくりしたオルゴールの伴奏。

## 開発用

```bash
npm install                     # playwright（撮影用）だけ
node tools/shot.mjs             # 横画面で一着ぶんを自動プレイして撮影
node tools/shot.mjs --portrait  # 縦画面
node tools/shot.mjs --round=2   # 3着目（スカート）から
```

画像は `tools/shots/` に出ます。
