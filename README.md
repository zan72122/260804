# はちみつやさん — 4歳児のための養蜂ゲーム

iPhone / iPad の **縦画面・横画面どちらでも** 遊べる、WebGL の 3D 養蜂ゲームです。
文字も、制限時間も、ゲームオーバーもありません。指1本で、養蜂の固有動作だけをなぞって遊びます。

## 遊びかた

画面のしずくボタンを押すと始まります。5つの工程がぐるぐる繰り返されます。

| | 工程 | 指の動き |
|---|---|---|
| ① | **燻煙** — 蛇腹を押すと シュポッ と白い煙が出て、巣門へ流れこむ。ミツバチが落ち着いて巣へ帰る | タップ／長押し |
| ② | **巣箱をあける → 巣枠を引き抜く** — 屋根をドラッグしてはずし、木の巣枠を上へスワイプすると スーーーーッ と垂直に抜ける | 大きなドラッグ／上スワイプ |
| ③ | **蜜蓋除去** — 太い蜜掻きフォークで上から下へなぞると、白っぽい蜜蓋が帯状に剥がれて黄金色の蜜が現れる | 太い軌道をなぞる |
| ④ | **遠心採蜜** — ハンドルを指でぐるぐる回す。蜜が 巣房 → 空中 → 内壁 → 流れ落ちる → 底にたまる | 大きな円運動 |
| ⑤ | **瓶詰め** — 蛇口をタップすると トローーーッ と蜜が落ち、瓶の液面が上がる。満杯になったら蛇口を閉める | タップ |

満杯の瓶は棚に並んでいき、そのまま次の周回が始まります。

## 4歳児向けの配慮

- 指が少しずれても成功する（当たり判定を大きく取り、意図をくんで補正する）
- 何もしないでいると「おばけの手」がやってほしい動きをなぞって見せる
- 蜂に刺される・失敗する・時間切れ、といった要素は一切なし
- 文字による説明ゼロ。進行はハニカムの点灯だけで示す

## 動かしかた

外部依存もビルドも不要です。`index.html` をブラウザで開くだけで動きます。
（`file://` でも動きますが、iPhone 実機で試すなら簡易サーバ経由が確実です）

```sh
python3 -m http.server 8000
# → http://<PCのIP>:8000/index.html を iPhone / iPad の Safari で開く
```

## 技術メモ

- **three.js r128（`vendor/` に同梱、MIT）** による実ジオメトリの透視投影 3D。CSS 疑似 3D は使っていません。
- 画像ファイルは1枚も使わず、木目・剥げた塗装・傷んだ金属・草地・雲などはすべて Canvas で手続き的に生成しています。
- 効果音もファイルではなく **WebAudio による合成**（燻煙のシュポッ、巣枠のこすれ、遠心分離の唸り、蜜のとろみ、羽音、風）。
- **巣脾シェーダ** — 六角形の巣房を距離場で描き、蜜蓋・蜜の量・空房の深さを法線と陰影で表現。蜜蓋の除去は Canvas のマスクへの描きこみで、なぞった帯だけが黄金に変わります。
- **内壁の蜜の流体表現** — 分離機の内壁は GPU 上のピンポン移流シミュレーション。飛んだ蜜が当たった点に厚みが加算され、自重で下へ流れ、底で抜けてタンクに溜まります。
- **ガラスの屈折** — 瓶詰めの場面だけ2パス描画し、背景を描いたテクスチャを瓶のシェーダが法線でずらしてサンプリングします。
- 近景・中景・遠景を分離（作業道具／草地・他の巣箱・柵／連なる山と雲）。遠景は空気遠近で空の色へ溶かしています。
- 端末が重いときは解像度を自動で落とします。縦横の持ち替えは画角と構図で吸収します。

## ファイル構成

```
index.html              画面とスクリプトの読みこみ
css/style.css           タイトル・進行表示・操作ガイドの土台
vendor/three.min.js     three.js r128 (MIT)
src/util.js             数学・補間・ポインタ・円運動の検出
src/audio.js            WebAudio による効果音の合成
src/tex.js              Canvas による手続き的テクスチャ
src/materials.js        巣脾シェーダ・蜜蓋マスク・ガラス屈折
src/props.js            巣箱・巣枠・燻煙器・蜜掻き・遠心分離機・瓶
src/bees.js             ミツバチの群れ
src/smoke.js            煙・蜜のしぶき・きらめき
src/world.js            空・山・草地・林・柵・養蜂場
src/hint.js             文字を使わない操作ガイド
src/stage_*.js          ①〜⑤の各工程
src/game.js             カメラ・入力・進行・描画ループ
```
