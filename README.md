# パカッ！ぐるん！エスカレーターひみつ整備室

iPhone / iPad のモバイル Safari で遊べる、4歳児向けエスカレーター整備ゲーム。
床板を「パカッ」と開けると、ステップ・チェーン・ローラー・歯車・手すりベルトが
巨大な輪になって循環する秘密の内部世界が現れます。

## 遊び方(文字を読まなくても遊べます)

1. コトコト・カチカチ…異常音に気付く(💥をタップ)
2. 安全柵をドラッグで設置 → 赤いスイッチで「ピタッ」と停止 → 鍵で「カチッ」とロック
3. 取っ手を上へスワイプして床板を「パカッ」
4. ハンドルを付けて、ステップを「スポン」と引き抜く
5. 内部の断面で故障箇所を探す(音の方向・点検灯・ロボの視線がヒント)
6. 一指操作で修理(交換・位置戻し・ベルト掛け・拭き取り)
7. 手回しホイールで「ぐるん」と回して確認
8. ステップと床板を戻して、🐢低速 → 🐇通常の試運転。「スーッ」と直れば大成功!

修理は4種類: ガタつくローラーの交換 / ずれたチェーンガイド / 外れかけた手すりベルト / ほこりで曇ったセンサー。
場所は3種類(モール・駅・水族館)。内部自由観察モードとステップ着脱遊びつき。
制限時間・ゲームオーバーなし。音量設定と「動きをよわく」設定あり。

## 技術構成

- Vite + TypeScript(strict)、フレームワークなし
- 描画: Canvas 2D(単一キャンバス、DPR対応、静的レイヤーは OffscreenCanvas キャッシュ)
- 音: WebAudio 全合成(音声ファイルなし)。擬音15種+異常音・運転音ループ7種
- 入力: 寛容ジェスチャー(タップ/大スワイプ/円/なぞり/磁石吸着ドラッグ)
- 縦画面=片手・対象1つズーム、横画面=側面断面の全景。回転しても進行状態を保持
- 静的デプロイ可能(`base: './'`)

設計契約は `docs/CONTRACT.md` を参照。

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 型検査 + ビルド (dist/)
npm run preview   # ビルドのプレビュー
node scripts/e2e.mjs  # Playwright 統合試遊(iPhone/iPad 相当 4視口)
```

e2e はヘッドレス Chromium で、タイトルから試運転完了までの全フェーズを
実ポインタージェスチャーで一周し、4故障種・画面回転・全モードを検証します。
