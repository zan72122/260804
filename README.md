# ☕ バリスタごっこ — Barista Play

4歳児がiPhone・iPadの指1本で遊べる、**エスプレッソマシン操作**のごっこ遊びゲームです。
文字・点数・時間制限・お金・ゲームオーバーはありません。失敗もありません。

「材料を入れるだけ」の料理ゲームではなく、**バリスタ特有の手の動き**そのものを遊びにしています。

画面は擬似3Dではなく、**透視投影・遮蔽・視差・実ジオメトリを持つWebGL2の3D空間**です。
依存ライブラリはゼロ、ビルド不要。レンダラ・ジオメトリ・マテリアルはすべて自前です。

## 起動

```bash
npx http-server -p 8080 -c-1 .
# → http://localhost:8080
```

iPhone / iPad ではホーム画面に追加すると全画面で遊べます。WebGL2が必要です。

## 遊びかた（読めなくても分かるように作ってあります）

カウンターに並んだ4つのカップのどれかを触ると、その飲み物を作り始めます。

1. 空のポルタフィルターをグラインダーの下へ運ぶ → 粉が落ちてくる
2. 指で左右になでて表面をならす
3. タンパーを真上からグッと押し込む → **トン**
4. ポルタフィルターを**下から**グループヘッドへ差し込み、**横へ回して**固定 → **カチッ**
5. マシン上部のカップウォーマーからカップを取ってドリップトレーへ → **コトン**
6. パドルを引くと細いエスプレッソが2本落ちる
7. ミルクピッチャーをスチームワンドへ持ち上げる → **シューーー**、渦と泡
8. カップを手前へ引き出し、ミルクを注いでラテアート
9. 完成カップをトレーへ
10. またカウンターのカップを選ぶ（同じもの／別の飲み物）

飲み物は カフェラテ／カプチーノ風／ホットミルク／ココア風 の4種類。
ホットミルクとココアはエスプレッソ抽出を省いた短い工程になります。

## ビジュアル設計

### 空間

すべて**実寸（ミリメートル）**でモデリングしています。カウンター天板 950 mm、
2連エスプレッソマシン 740 × 530 × 490 mm、バスケット径 58 mm、
カプチーノカップ 口径 85 mm・高さ 62 mm、ミルクピッチャー 0.6 L。
だから物の重さと厚みが画面上で嘘をつきません。

奥行きは4つの手掛かりで読ませています。

| 層 | 内容 | 読ませ方 |
|---|---|---|
| 近景 | カウンター前板、真鍮フットレール、ノックボックス、布 | 大きなシルエット、高コントラスト、暖色の直接光 |
| 中景 | マシン、グラインダー、カップ、ピッチャー | 主役。鏡面金属と接地影が形を彫る |
| 遠景 | タイル壁、バックバー棚、ペンダント照明、窓 | 距離フォグで彩度と明度が上がり、遠距離ぼけが掛かる |

カメラは工程ごとに実際に移動します（視差が出ます）。フレーミングは
「注視点＋収めたい半径」で指定し、縦横それぞれ**狭いほうの画角**に合わせて
距離を解くので、縦画面では手元が大きく、横画面ではカウンター全体が入ります。

### 光と材質

- **物理ベースシェーディング**（GGX + 分割和近似）
- **環境**は手続き生成の equirect HDR。暖色の天井・バーの上の光溝・左手の大きな窓・
  暗い床。ステンレスの形が読めるのは、この部屋が映り込んでいるからです
- **キーライト**はバー上のペンダント。2048² のシャドウマップ（PCF 3×3）を
  作業領域に絞って張っているので、接地影が出ます
- **SSAO** で隙間と接地部が締まります
- **距離フォグ**＋遠景ぼかしで空気遠近
- ACES トーンマップ、控えめなブルームとグレイン

材質はすべて手続き生成で、albedo / ORM（遮蔽・粗さ・金属度）/ 法線の3枚を持ちます。

- ヘアラインステンレス：横方向の研磨目、微小ピット、手が触れる場所の指紋（粗さが上がる）
- クロム：ほぼ鏡面。磨き傷と埃
- オイル仕上げのオーク：木目、節、コーヒーの輪染み、立ち位置の摩耗で艶が変わる
- 施釉サブウェイタイル：面取りと目地、ミルクの飛沫
- ゴム、コーヒー粉（粒状）、磁器（貫入）、真鍮（変色）

## 中核の作り込み

### シグネチャーアクション：ポルタフィルターの「カチッ」

このテーマ以外ではまず出てこない動作なので、単発のタップではなく
**指の移動に追従する連続した感触**として実装しています（`src/game3d.js` の `scenes.lock`）。

回転は画面上の見かけではなく、**グループヘッドの実際の鉛直軸まわり**です。
指のレイを水平面と交差させ、その方位角がハンドルを駆動します。

| 段階 | 実装 |
|---|---|
| 下から接近 | 溝の下側からのみ磁力ガイドが働く |
| 溝へ入る | 吸着＋「コッ」＋蒸気の一吹き |
| 回転 | 方位角がハンドルを駆動。段階ごとにラチェット音が上がる |
| 抵抗が増える | 入力進捗が0.70を超えると、指の要求の**40%しか**ハンドルが動かない。<br>画面上は0.87付近で止まり、先端に「もう一押し」の合図が出る |
| カチッ | 見た目の全可動域を**12%押し切った**ところで固定。オーバーシュート＋金属音＋火花 |

途中で指を離しても失敗にはならず、進捗はほぼ保持されたまま握り直せます。

### スチーム

ワンドの先端とミルク液面の**相対位置**で挙動が変わります。液面近くなら空気を
巻き込んで泡が育ち「チリチリ」が鳴り、深く沈めれば渦が速くなって音がこもります
（バンドパスが 3.4 kHz → 1.25 kHz）。ミルク面は実ジオメトリで、渦のくぼみが
回転して深くなります。

幼児向けなので**失敗にしません**。理想位置から220 mm以内なら毎フレーム72%の
強さで自動補正がかかります。

### ラテアート

精密描画テストではなく、**流体**です（`src/fluid.js`）。

- 90×90 の非圧縮性ソルバ（semi-Lagrangian移流 → 発散除去12反復 → 渦度強調）
- 注ぎ点にミルク濃度と運動量を注入。指の速度がそのまま流れに乗る
- 左右に振ると往復回数を数え、**5回以上→ロゼッタ / 2回以上→チューリップ / それ以外→ハート**
- 最後に手前から奥へ一本線を引くと、その線を流体に刻んだうえで
  0.72秒かけて型へ収束。ただし**プレイヤー自身の場を22%まで残す**ので、
  「自分が作った」テクスチャが必ず残ります
- 結果はカップ表面のテクスチャとしてGPUへ毎フレーム転送され、
  ミルク濃度がそのまま**光沢と微細な起伏**になります（フォームは粗く、クレマは艶やか）

めちゃくちゃに塗りたくっても必ずかわいい模様になります。指を離して3.2秒経つか、
長く注ぎ続けた場合は自動的に完成するので、**詰まることがありません**。

### 音

すべてWebAudioの合成音です（音源ファイルなし＝操作と完全に同期）。

グラインダー / タンピング「トン」 / 固定「カチッ」 / 抽出ポンプの低い機械音 /
カップへ落ちる音（液面が上がると共鳴が高くなる） / スチーム「シューーー」 /
ミルクの「チリチリ」 / カップを置く「コトン」

## 動作確認

Chromiumの実機相当ビューポート（iPhone 390×844 / 横 844×390 / iPad 1024×768）で
実際にポインタ操作を流し、全工程の通しプレイを縦横で自動テストしています。
指の位置はワールド座標を画面へ投影して求めているので、テストは
「実際にその物を触る」操作になります。

描画負荷は端末に合わせて自動で落とします（フレームが遅れたらSSAO、次にブルームを外す）。
レンダー解像度も画素数上限でクランプします。
