# あわせて！くらくして！ ほしぞらドーム

4さいの女の子が iPhone / iPad（たて・よこ どちらでも）で あそべる、
**プラネタリウム技師** になって ほしぞらを つくる ブラウザゲームです。

外部ライブラリなし。HTML + CSS + JavaScript と 生の WebGL だけで できています。
音も すべて WebAudio で その場で 合成しているので、画像・音声ファイルは 1つも ありません。

---

## あそびかた

`index.html` を ブラウザで ひらくだけ。ビルドも サーバも いりません。

```
open index.html          # macOS
# または
python3 -m http.server   # http://localhost:8000/
```

iPhone / iPad の Safari、Android Chrome、PC の Chrome / Safari / Firefox で うごきます。

---

## ゲームの ながれ

夜空の タイトル画面 → **はじめる** で 会場の あかりが つき、準備室へ。

| ステップ | やること | さわりかた |
|---|---|---|
| 1 | レンズを みがく | ゆびで くるくる こすると くもりが とれる |
| 2 | ほしぞらディスクを えらぶ | すきな ディスクを スロットへ ドラッグ（タップでも OK） |
| 3 | わくせいを あわせる | 大きな まるを よこに スライドするだけ |
| 4 | ケーブルを つなぐ | 近づけると じしゃくのように 吸いつく |
| 5 | **レバーを さげる** | さげるほど 会場が くらくなる → 星空が ひらく |

そのあと **20秒ちかく** 完成した宇宙を ながめる時間が あり、
しずかに「もういっかい」「ちがう ほしぞら」の ボタンが 出てきます。

### 4さい向けに していること

- 操作は すべて **ゆび1本**。2本指の 操作は ひとつも ありません。
- タイマー・とくてん・ゲームオーバー なし。**しっぱいできません。**
- 多少 ずれても「やりたかったこと」を くみとって 成功させます
  （わくせいは 近くで はなせば すいよせられ、ケーブルは 近づけるだけで つながります）。
- 文字が 読めなくても、光・うごき・音・見た目の 変化で すすめます。
- ラベルは すべて ひらがな／カタカナの みじかい ことば。

## フィナーレで おきること

1. 会場の 照明が ゆっくり おちる（レバーを さげている あいだ、その場で 暗くなる）
2. ドームが 白から 深い夜へ かわる
3. 星が **ひとつずつ** ぽつぽつと 現れる（音も 1つずつ）
4. そして **いっきに** 天頂から 外へ ひろがる
5. えらんだ テーマの 星座線が つながり、なまえが 出る
6. 惑星が ゆっくり 動く（おつきさまテーマでは 大きな 月も）
7. **天の川が ドームの はしから はしへ 流れる**（星の かわとして 現れます）
8. ときどき 流れ星が よこぎる
9. 足元の 床と 座席に 星あかりの 反射が ともる
10. さいごに 視線が ゆっくり おりて、星あかりの 客席が 見える

## テーマ

| | 星の色 | 星座 |
|---|---|---|
| 🐱 どうぶつ | あたたかい 金色 | ねこ・うさぎ・くま・ことり |
| 🐬 うみ | 青と みずいろ | ひとで・いるか・さかな・かに |
| 🌈 にじいろ | 虹色（天の川も 虹色） | うずまき・ちょうちょ・おうかん・ハート |
| 🌙 おつきさま | 銀と 白（流れ星 おおめ） | おおきなほし・ふね・ひしゃく・こぼし |

テーマで 空の色・星の色・星座・惑星・天の川の 向きと 色・流れ星の 数が かわります。

## つくり

```
index.html
css/style.css      画面レイアウトと 手ざわりのある UI（3D風の ボタン・レンズ・レバー）
js/util.js         ベクトル/行列、トゥイーン、タイムライン、ポインタ処理
js/audio.js        WebAudio の 合成音（きらきら・カチッ・パッド・流れ星）
js/themes.js       4テーマの 色と 星座データ
js/glcore.js       WebGL の うすい ラッパと ジオメトリ生成
js/scene.js        ドーム・星・星座線・惑星・座席・投影機の 描画
js/ui.js           5つの 準備作業（ゆび1本の あたり判定）
js/game.js         進行と フィナーレの 演出タイムライン
js/main.js         起動・ループ・回転対応
```

### 3D について

- 会場も 星空も **ひとつづきの 3D空間** です。ドームの内側にカメラが座っていて、
  照明が 落ちると 同じドーム面が そのまま 夜空に なります（画面の 切り替えは ありません）。
- 星は 頂点シェーダで 大きさ・またたき・出現順を 制御した `POINTS`。
  出現順は「天頂からの 距離 + ゆらぎ」なので、外へ 広がる 波に 見えます。
- 星座線は カメラを 向いた 帯ポリゴンで、先端が 光りながら 描かれていきます。
- 惑星と 月は 板ポリゴンに 球の 陰影・帯・環・クレーターを 描いた 疑似3Dです。
- 天の川は「帯にそって おいた たくさんの ちいさな星」＋ ひかえめな グロー。
  端から端へ 星が 順に ともることで 流れて見えます。

### うごきの なめらかさ

フレーム時間を みて、おそい端末では 自動的に 描画解像度を さげます
（`Scene.quality`、最大 3段階）。暗転しきったら 会場側の、
明るいうちは 星空側の 計算を シェーダ内で とばしています。
