# ねつききゅうを とばそう！ 🎈

4歳向けの熱気球「地上スタッフ」3Dゲーム（WebGL / Three.js）。

実際の熱気球立ち上げ手順に沿って、風の確認からクイックリリースまでを
全部ちがう一指ジェスチャで体験。布が巨大な気球へ膨らみ、ゆっくり
起き上がり、朝焼けの空へ浮かんで、町・雲・朝日・虹を見下ろします。

## あそびかた

```bash
# リポジトリ直下で
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

（`index.html` をダブルクリックしてファイル直開きでも動きます）

- **一指操作のみ・失敗なし**: 判定は極太、ヒントの👆が常に次の場所を案内。
- **縦横対応**: スマホ縦持ち・横持ち・PCどちらでも。

## おしごと（全10ステップ・実務手順どおり）

| # | さぎょう | ジェスチャ |
|---|---------|-----------|
| 1 | パイバル（試験風船）で風チェック | 上へ はなつ |
| 2 | バーナーテスト点火 → かごを横倒し | 連打で スパーク＋ながおし |
| 3 | 収納袋から布を引き出して展開 | ずるずる 引っ張る |
| 4 | 交差したロードケーブルをカラビナ接続 | ドラッグ＆スナップ |
| 5 | 頂部パラシュートベントのベルクロ点検 | ペタペタ タッチ |
| 6 | 布の口を開いて保持（口もち） | よこに ぐいっと |
| 7 | ファンのスターターを引いてコールドインフレ65% | したに 引く |
| 8 | クラウンライン綱引きでゆっくり起立 | ぐーっと 引き続ける |
| 9 | パイロット搭乗・かご押さえ（ウェイオフ） | ながおし |
| 10 | クイックリリースを引き抜いて離陸 | 引き抜く |

飛行中は**本物の操縦**: バーナー長押し＝上昇、赤いベントロープ＝ゆっくり下降。

## 実務再現ポイント

- 砂袋は不使用（熱気球の実務どおり、人がかごを押さえ＋杭に係留）
- かごは横倒しでケーブル接続し、起立とともに引き起こされる
- コールドインフレで横倒しのまま65%膨張 → バーナーで起立
- クラウンライン係が張力で立ち上がりを制御、完了後にロープを放す
- ファンは使用時だけクルーが押してきて、ホットインフレ前に引き離す
- パイバル放球・ベント点検・搭乗後のウェイオフも実手順どおり

## 技術メモ

- Three.js r149（`lib/three.min.js` を同梱、外部通信なし）
- 気球の外皮は 2,220頂点のパラメトリックメッシュを毎フレーム CPU モーフ
  （袋の中 → 平らな布 → 口開け → 横倒し膨張 → 直立、法線再計算つき）
- 透視投影・PCFソフトシャドウ・フォグ空気遠近・ACES トーンマッピング
- 町・木・山はジオメトリ結合で低ドローコール化、雲・虹・鳥・火炎は加算合成/専用シェーダ
- 音は全て WebAudio でプロシージャル生成（オルゴールBGM、スパーク・ベルクロ・スターター・カチン等の実務SE）
- 自動試遊テスト（Playwright・実ポインタジェスチャ）で縦横両方の全10ステップ＋飛行操縦を検証済み
