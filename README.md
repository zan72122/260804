# バゲット職人 — 4歳からのバゲットづくり

スマホ・タブレットのブラウザで遊べる、文字を一切使わないバゲット作りゲームです。

このゲームの主役は **「自分が入れた斜めの切れ目（クープ）が、オーブンの中でその場所どおりにパカッと開く」** という体験そのものです。

## 遊びかた

`index.html` をブラウザで開くだけです。ビルドもサーバーも要りません。

```
open index.html          # macOS
```

iPhone / iPad で遊ぶ場合は、このフォルダごと適当な静的サーバーに置くか、
ファイルを端末へ転送して Safari で開いてください。
（音は iOS の仕様上、最初に画面を1回タッチしてから鳴りはじめます）

## 12の工程

絵と手の動きだけで進みます。読む必要はありません。

| | 工程 | 操作 |
|---|---|---|
| 1 | 生地を置く | 台をトン、と押す（ポフ） |
| 2 | ガスを整える | ぷくっとした気泡を指で押す ×4 |
| 3 | 巻く | 手前から奥へなぞる |
| 4 | 細長く伸ばす | 軸に沿って左右になぞる |
| 5 | 布に並べる | バゲットを布までひっぱる |
| 6 | 発酵 | 見ているだけでふっくらする |
| 7 | **クープを入れる** | 斜めに「スッ」×3〜5本 |
| 8 | オーブンへ | オーブンへ向かってなぞる |
| 9 | 蒸気 | 蒸気ボタンを押す（シュワッ） |
| 10 | **焼成** | 切れ目が開き、黄金色になるのを見る |
| 11 | 取り出す | ラックへ向かってなぞる |
| 12 | 叩く | パンをトントン（コンコン） |

最後に「同じ形」「べつの形」「自由クープ」から選んでもう一度。

## パンの種類

- 普通のバゲット
- 小さなバゲット
- 少し太いバタール風
- 自由クープモード（角度の補正がゆるく、8本まで入れられる）

## つくりの方針

### クープと焼き上がりが完全に対応する

クープは画像ではありません。指の軌跡から

- `t` … バゲットの軸方向の位置（0〜1）
- `off` … 軸からの横ずれ
- `angle` … 軸に対する傾き
- `len` … 長さ
- `depth` … 深さ（ゆっくり引くほど深い）

を取り出して保存し、焼成パラメータ `bake` を上げると **その同じ座標が** 少しずつ開きます
(`js/loaf.js` の `scoreOpen` と `_drawScore`)。
差分は毎フレーム計算されるので、「途中で別の絵に差し替わる」ことは起こりません。

正規化座標なので、**画面を回しても生地もクープも失われません**。

### 入力補正

指が曲がっても、位置がずれても、きれいな斜め線になります。

- 角度は理想の傾き（約21度）へ80%寄せる。最初の1本で決まった向きに以降も揃う
- 横方向のずれは70%吸着して中央へ
- 近すぎる2本は自動的に離す
- 生地からはみ出す角度は自動で寝かせる

ただし **長さと深さは指の動きがそのまま残ります**。長く引けば長いクープ、
ゆっくり引けば深いクープになり、焼き上がりの模様が変わります。

### 失敗がない

焦げる・膨らまない・食べられない、という結果はありません。
時間制限も、星の評価も、点数も、お金もありません。

### 画面の向き

- **縦画面** … バゲット1本を斜めに大きく。クープが引きやすい
- **横画面** … 3本を並べ、オーブンも広く見せる。プレイヤーが入れたクープの模様が
  隣の2本にも写し取られて、いっしょに開く

### 安全な描写

刃物と高温オーブンを扱うのは大人のパン職人です。プレイヤーは画面上の大きな
ジェスチャーでその仕事を体験します。lame は持ち手を大きく、刃は小さく描いています。

### 音

すべて WebAudio でその場で合成しています（音声ファイルなし）。
生地を置く「ポフ」、成形の摩擦音（なぞる速さに追従）、クープの「スッ」、
蒸気の「シュワッ」、皮の「パチパチ」、叩いたときの「コンコン」。
