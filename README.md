# ふんすいを なおそう！ 🚰⛲

4歳児向けの噴水設備整備 3D ゲーム（WebGL / Three.js）。

地下のポンプ室でパイプをつなぎ、詰まりを取り、ノズルとライトを選んで、
最後に巨大なバルブを回すと——水が配管を駆け抜け、静かだった広場が
大小の噴水・水の輪・交差するアーチ・虹色の光の水のショーに変わります。

## あそびかた

- **ゆびいっぽんで タップするだけ**。失敗はありません。
- ながれ:
  1. 🔧 ひかっている ばしょに パイプを つなぐ
  2. 🍂 とうめいパイプの ゴミを タップして とる
  3. ⛲ ふきだしぐち（ノズル）を タップして かたちを えらぶ
  4. 💡 すいちゅうライトの いろと じゅんばんを えらぶ
  5. 🎡 おおきな バルブを なんかいも タップして まわす → ショーが はじまる！
- 縦持ち・横持ちどちらでも遊べます。音が出ます（最初のタップで開始）。

## 実行

`index.html` 1ファイルに全て（Three.js 含む）バンドル済みです。

```sh
# そのままブラウザで開く、または:
npx serve .
```

## 開発

```sh
npm install
node build.mjs   # src/ → index.html にバンドル
```

- `src/main.js` — 進行・カメラ・入力・最終ショーの振り付け
- `src/room.js` — 地下ポンプ室（4つの整備ステーション＋バルブ）
- `src/plaza.js` — 地上の広場（夕暮れ→夜、噴水池、街のシルエット）
- `src/water.js` — GPU ステートレス水パーティクル（噴流・水輪・ミスト・気泡）
- `src/textures.js` — プロシージャルテクスチャ（コンクリ・石畳・金属・グロー）
- `src/audio.js` — WebAudio 合成のみの効果音・オルゴール BGM
- `src/ui.js` — ひらがな UI オーバーレイ

## 技術メモ

- 透視投影・実ジオメトリ・遮蔽・フォグによる空気遠近を持つ本物の 3D 空間
- 水は頂点シェーダで放物運動を解くステートレスパーティクル（CPU 負荷ゼロ）
- プール反射は水面を半透明にし、鏡像パーティクルを水面下に描画して表現
- 音はすべて WebAudio で合成（外部アセットなし・オフライン動作）
