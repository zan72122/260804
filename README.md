# はかって！トントン！ちいさな大工さん

4さいの女の子のための、ブラウザで遊べる大工あそび。
iPhone / iPad の **縦画面でも横画面でも**、指一本で最初から最後まで遊べます。

WebGL / Three.js による本物の 3D 空間で、木材が家具や遊具へ変わっていく過程そのものを触って楽しむ「しごとのおもちゃ」です。

```
python3 -m http.server 8000   →  http://localhost:8000/
```

外部 CDN もビルド工程も不要です。Three.js は `vendor/three/` に同梱しています。

---

## 看板となる 5 つの動作

すべて自動再生ではなく、指の動きと道具の動きが直接つながっています。

| # | 動作 | 操作 | 木材の変化 |
|---|------|------|-----------|
| 1 | 巻き尺を「シャーッ」 | 横へなぞって引き出す | テープが伸び、目盛りが現れる。ぴったりの位置で吸着し「ここ！」の合図 |
| 2 | 鉛筆で「スーッ」 | 点線の上をなぞる | 指の後ろに線が残っていく |
| 3 | クランプで「カチッ」 | 取っ手をぐるぐる回す（こすってもOK） | 口金が下がり、板がぎゅっと締まる |
| 4 | のこぎりで「ギコギコ」 | 前後になぞる | 切れ目が深くなり、木くずが落ち、最後に 2 本に分かれる |
| 5 | 金づちで「トントン」 | 釘をタップ | 一打ごとに釘が沈み、画面が小さく弾む |

このほかに **木材を置く / 紙やすりで磨く / 影に合わせて組み立てる / 刷毛で塗る / シールを貼る** があり、
最後は完成品を **ぬいぐるみ・ことり・ごほん** が実際に使ってくれます。

## 遊びの流れ

```
見本の絵をえらぶ → 木を置く → 測る → 線を引く → 固定する → 切る → 磨く
   （2 本ぶんくり返し）→ 影に合わせて組む → 釘を打つ → 塗る → 飾る → おひろめ
```

完成後は点数も星もなく、大きな絵の 3 つの選択肢だけが出ます。

* おなじのを もういちど
* べつのものを つくる
* じゆうに つくる

## 中身

* **作品 3 種**：こしかけ / ほんだな / ことりのおうち
* **木 4 種**：ひのき・パイン・さくら・ウォルナット
* **仕上げ 6 種**：ニス・ももいろ・そらいろ・わかば・れもん・にじいろ
* **道具 7 種**：巻き尺・鉛筆・クランプ・のこぎり・紙やすり・金づち・刷毛
* **飾り**：ほし・はな・ハート・にじ・まる（シールとエプロン・道具箱の柄）
* **じゆうモード**：好きな場所を切って、積んで、打って、塗る砂場遊び

## 4 さいへの配慮

* 寸法の入力・角度・お金・制限時間・失敗・ゲームオーバーは **なし**
* 線から指がずれても道具の方が寄っていく（鉛筆は半分引ければ残りを引いてくれる、のこぎりは横の動きも切る力になる）
* 数秒迷うと、道具が小さく揺れ、ロボットが視線と手で指し、点線の矢印と音でそっと教える
* 刃や釘のそばに **プレイヤーの手を描かない**。作業をするのは大工ロボットで、のこぎりを使う前には自分でゴーグルを下ろす
* 文字が読めなくても進めるよう、進行はすべて絵と音。短いひらがなの声かけは補助（対応端末では読み上げも）

## 画面の向き

* **縦画面**：一度に一工程だけを大きく映し、片手で届く位置に操作を集める
* **横画面**：作業台全体を広く映し、木材・見本・道具の関係が見渡せる
* 回転しても **切った・磨いた・組んだ・塗った状態はそのまま**（状態は 3D シーン側が持ち、画面はカメラの構図だけを切り替える）

## 技術メモ

CSS の擬似 3D ではなく、実ジオメトリによる 3D 空間で作っています。

* `PMREMGenerator` + `RoomEnvironment` による環境光で、金属・木・塗膜の材質応答を物理的に妥当に
* 影は **シャドウマップ + 接地影（ソフトな楕円）** の二段構え
* `THREE.Fog` と奥行きに散らした小物・舞うほこりで空気遠近と視差
* 木材は **三面投影（トライプラナー）** で、部品の大きさが違っても木目の密度が揃う
* 塗装は刷毛の軌跡を 1 枚のマスクへ描き、**ワールド座標から投影して全部品へ同時適用**（塗り残しで詰まらない）
* 研磨は切断面に「ざらざらの層」を重ね、なぞった所を消しゴムのように削って下の滑らかな面を出す
* 効果音はすべて **WebAudio による合成**（音声ファイルなし）。のこぎり・巻き尺・紙やすりは指の速さに追従する連続音
* ロボットの腕は 2 関節 IK で、いま使っている道具をいつも握りに行く

### ファイル構成

```
index.html          入口（importmap で vendor/three を読む）
styles.css          画面まわり（safe-area・縦横対応）
src/
  main.js           起動・毎フレーム・画面遷移
  core/  stage.js   レンダラ / 照明 / 縦横のカメラフレーミング
         input.js   一本指の入力を平面上のワールド座標へ
         audio.js   WebAudio による効果音の合成
         materials.js 手続き的テクスチャ・木材シェーダ・塗装システム
         fx.js      木くず・粉じん・波紋・きらめき・ガイド矢印
         util.js    補間とトゥイーン
  world/ workshop.js 工房（作業台・壁・窓・奥行きの小物）
         robot.js    大工ロボット（IK の腕・視線・ゴーグル）
         tools.js    道具のジオメトリ
         workpiece.js 木材（切る・磨く・塗るの状態）
         plush.js    くま・ことり・ごほん
  game/  blueprints.js 作品・木・仕上げのデータ
         step.js     工程の共通の枠組み
         steps_cut.js  置く・測る・線・固定・切る・磨く
         steps_build.js 組む・打つ・塗る・飾る・おひろめ
         flow.js     一作品を通す流れ
         freeplay.js じゆうモード
  ui/    hud.js, icons.js  絵だけで進む画面
vendor/three/       Three.js r169（同梱）
```

## 動作環境

iOS 15 以降の Safari / Chrome、Android Chrome、デスクトップの各ブラウザ（WebGL2）。
音は端末の作法にあわせ、最初のタップで鳴りはじめます。
