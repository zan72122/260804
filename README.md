# よまつりの じゅんび 🏮

4歳向けの「夜祭り準備」3Dゲーム（WebGL / Three.js）。

明るい昼間に提灯づくり（骨組み → 紙貼り → 絵付け → ろうそく入れ → ひも掛け）をして、
町の通りと門へ飾りつけ。夕暮れに大太鼓をひとつ「ドン!」と叩くと、
太鼓の音に合わせて提灯が端から順に点灯し、屋台・窓・門へ光が広がり、
提灯の絵が地面へ投影されて、町全体が夜祭りへ変わります。

## 遊び方

- すべて **一本指のタップ** だけで遊べます（光る輪と矢印が次の場所を教えてくれます）
- 絵付けは 花 🌸 / 魚 🐟 / 星 ⭐ から選択
- フィナーレでは画面のドラッグで見回し、タップで太鼓をもう一度
- 縦持ち・横持ちどちらでも遊べます

## 実行

静的サーバで配信して開くだけです（ES Modules のため file:// 不可）。

```
python3 -m http.server 8000
# → http://localhost:8000/
```

## 技術メモ

- Three.js（`vendor/` に同梱）による透視投影・実ジオメトリの WebGL 3D。
  近景（作業台）/ 中景（家並み・屋台・門）/ 遠景（山なみ）を FogExp2 の空気遠近で分離
- テクスチャはすべて Canvas で手続き生成（紙・木目・石畳・漆喰・縞幕・絵柄）
- 音はすべて WebAudio で合成（太鼓・鉦・笛・効果音）。
  点灯カスケードは AudioContext の時計でスケジュールし、描画側が同じ時計を参照して発火するため音と光が同期
- 夜の光は「実ポイントライト（近景）+ エミッシブ + グロースプライト + 地面投影ディスク」のハイブリッドでモバイル性能を確保
