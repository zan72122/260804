# いっぽん・いってん！ にじいろタウン

4歳児向けのWebゲーム。**一本の自由な線**を描いて、**最後に一点「ぽん！」**と置くと、
その線と点を骨格にして、ゲームが家・ケーキ・花壇を豪華に仕上げます。
子どもの描いた線はクレヨンの質感のまま完成物の中に残り、町の住民がそれを使い始めます。

## あそびかた

1. 光っている場所（おうち広場／おかし屋さん／にじいろ花壇）をタップ
2. 大きなクレヨンから色をえらぶ
3. 指で一本、すきな線を描く
4. 「さいごに、ぽん！」— すきな場所を一回タップ
5. 線が育って作品が完成。住民が使いはじめ、町に残る

線のかたちで結果が変わります（長い線→大きく、山→高い屋根やキャンドル、
波→うねる茎やクリーム、渦巻き→つるやウエハース、閉じた線→ドーム屋根、
点の位置→玄関・トッパー・大輪の花）。

## 実行

ビルド不要の静的サイトです。

```bash
python3 -m http.server 8000
# → http://localhost:8000 を iPhone / iPad の Safari で開く
```

## 技術構成

- 素の HTML + Canvas 2D + Web Audio API（依存ライブラリなし）
- クレヨン質感ストローク（速度連動の太さ・顔料グレイン・ラメ・描画音）
- ストローク特徴量解析（bbox／長さ／山谷／波打ち／渦巻き／閉曲線／偏り）→ 決定論的な自動補完
- 完成物・背景レイヤーはオフスクリーンにベイクして 60fps を維持（低速端末は DPR 自動降格）
- localStorage に「元ストローク＋点＋色＋シード」を保存し、起動時に決定論的に再構築
- 縦横レスポンシブ・safe-area 対応・prefers-reduced-motion 配慮

## ファイル

```
index.html      エントリ・UIオーバーレイ
style.css       ゲーム内UI（花びらボタン・クレヨン・バナー）
js/util.js      数学・乱数・パスユーティリティ
js/audio.js     プロシージャルサウンド（描画音・ぽん・成長・歓声・環境音）
js/fx.js        パーティクル（星・ハート・リング・粉）
js/stroke.js    クレヨン描画と特徴量解析
js/chars.js     住民・蝶・小鳥
js/gen_house.js  おうち広場の生成器（線=屋根の稜線、点=玄関）
js/gen_cake.js   おかし屋さんの生成器（線=クリーム、点=トッパー）
js/gen_garden.js にじいろ花壇の生成器（線=茎・つる、点=大輪の花）
js/town.js      町の世界・住民スクリプト・リアクション
js/make.js      制作シーン（クレヨン選択→線→ぽん→成長演出）
js/save.js      localStorage 永続化
js/main.js      ループ・カメラ・入力・シーン遷移
```
