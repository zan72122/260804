# 260804 — すいどうやさん 🔧💧

4歳児向けの水道修理ゲーム。配管工がシンク下へスルッともぐり、
ワイヤー通し・パッキン交換・ホース接続・レンチ締めで水漏れを直すと、
透明な管を水が気持ちよく流れます。

## 遊びかた（文字なし・一指操作）

1. **タップ** — 配管工がシンク下へスルッともぐる
2. **なぞる** — ワイヤーがパイプの中をスルスル進んで、つまりを退治
3. **ドラッグ** — オレンジのパッキンを継ぎ目へ（近づくと吸い付く）
4. **ドラッグ** — ホースの先を光るソケットへ（近づくと吸い付く）
5. **ぐるぐる** — レンチをグイッと回すと、ポタポタ → ピタッ！
6. **ごほうび** — 透明な管を水と泡がジャーッと流れる。タップで泡としぶきも

- 失敗・採点・制限時間なし。どこを触っても正解へ進む強い入力補助つき
- iPhone / iPad の縦横どちらにも対応（Safariで開くだけ）
- 効果音はWebAudioでその場で合成（素材ファイル不要）

## 起動

```
python3 -m http.server 8000
# → http://localhost:8000/index.html
```

構成: `index.html` / `style.css` / `game.js`（Canvas 2D、依存ライブラリなし）
