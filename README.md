# ピンのかえりみち

「ボウリングのピンは、倒された後にどこへ消え、どうして再び10本そろって現れるのか？」

この疑問への答えを、4歳の子が指でたしかめられる一周の循環にしたゲームです。
レーン奥の扉のむこうにある本物のピンセッター（ピット・コンベア・ピン整列機構・ピンテーブル・ボールリターン）の意味とめぐりを残したまま、危険・文字・失敗・待ち時間・採点をぜんぶ取り除いてあります。

## あそびかた

`index.html` をブラウザで開くだけ。iPhone・iPad の Safari（縦横どちらでも）で動きます。
サーバー不要・通信不要・インストール不要。ホーム画面に追加すると全画面で遊べます。

画面に文字は一切ありません。迷ったときは3秒ほどでお手本の手が現れて、さわる場所・こする方向を見せてくれます。どこを触っても壊れず、失敗もありません。

## 一周のながれ（本物の機械と同じ循環）

1. **レーン** — ボールをタップ → ゴロゴロ転がってクラッシュ！ピンが倒れる
2. **おそうじレーキ** — 指で掃くバー（実機のスイープ）を引いて、倒れたピンを奥へ
3. **扉** — レーン奥の扉をタップ → **パカッ**！ピンとボールがピット（地下）へ落ちる
4. **地下ベルト** — 画面をこするとベルトが動き、ピンの行列が**ガラガラッ**と運ばれる
5. **わけっこ穴** — まるいボールだけがまるい穴にストンと落ちる（実機のボール/ピン分離）
6. **エレベーター** — ピンが1本ずつ観覧車みたいな輪でのぼっていく（ド・レ・ミ…と10音）
7. **くるんメリー** — 回る台の上の、さかさま・横倒しのピンをタップ → **くるん**と起き上がる（実機の向きそろえ機構）
8. **ピンテーブル** — 10本が三角形にぶら下がる。タップ → **ストン**！と全部そろって着地
9. **ボールのちかみち** — 地下トンネルを指でなぞるとボールが**ゴロゴロ**、出口で**ポン**！とレーンわきに帰ってくる
10. 最初にもどる（周回ごとにボールの色が変わる）

## 五つの看板操作

| 感触 | 操作 | 場面 |
|---|---|---|
| パカッ | タップで扉が勢いよく開く | タイトルの扉・ピットの扉・トンネル出口のふた |
| ガラガラッ | 画面をこするほどベルトが速く、ピンが跳ね、機械中のギアが回る | 地下ベルト |
| くるん | さかさまピンをタップすると宙返りして起きる | くるんメリー |
| ストン | タップで10本が段々に落ちて画面がずしんと揺れる | ピンテーブル |
| ゴロゴロ、ポン | トンネルを指でなぞると転がり、出口で飛び出す | ボールのちかみち |

## 発明した機械あそび

- **わけっこ穴** — ピンとボールが一緒に流れてくるベルトで、まるいボールだけが穴に吸い込まれる。実機の「ボール/ピン分離」を型はめ遊びにしたもの。
- **おそうじレーキ** — 実機のスイープバーを自分の手で引いて倒れたピンを集める。
- **かくれんぼピン** — 1周おきに、ピンが1本パイプの中に隠れて目だけのぞかせる（実機の「ピン詰まり」）。見つけてタップすると飛び出す。見つからなくても少し待つと自分から出てくるので詰まない。
- **くるんメリー** — 向きのバラバラなピンが回転台で回る。台自体も指ではじいて回せる。

## つくりの約束

- 文字・数字・スコア・タイマー・失敗・広告・課金・通信：なし
- どの操作も「タップだけ」で先へ進める（ドラッグが苦手でも詰まない）
- 6秒さわらないと機械がそっと動き出し、遊び方を体で見せる
- 音はすべてWeb Audioで合成（左上の小さなスピーカーで消音可）
