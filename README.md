# ひらいて！てらして！ステージのうらがわ

4さいの女の子のための、iPhone・iPad ブラウザで遊ぶ 3D ゲームです。
遊ぶひとは俳優ではなく、**舞台のうらがわではたらくスタッフ**。

袖から背景セットをゴロゴロ送り出し、昇降装置で月や雲をそっと下ろし、
スポットライトを指で動かし、照明の色をえらび、大きな幕をすーっと開きます。
幕があいたら短い公演がはじまり、出演者に光を合わせ、花びらや泡を出して、拍手を聞きます。

## 遊びかた

- 操作は **一本指のタップ**と**大きなスワイプ**だけ。
- 制限時間・点数・失敗・文字の説明はありません。
- 光やセットが多少ずれても、自然に目標へ吸いつきます。
- 最後に「もういちど」と「じゆうに照明であそぶ」がえらべます。

## 遊ぶ

このフォルダを静的サーバーで配信して `index.html` を開くだけです（ビルド不要）。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

`file://` から直接ひらくと ES モジュールが読み込めないので、かならずサーバー経由で。

## 中身

| ファイル | 役わり |
| --- | --- |
| `src/main.js` | 進行（タイトル→したく→幕開け→公演→拍手→再プレイ／自由モード） |
| `src/theatre.js` | 劇場そのもの。床の映り込み、プロセニアム、客席、ゴーストライト、カメラ |
| `src/curtain.js` | 幕3種類。ひだが寄り、揺れ、止まったあとも余韻が残る布のシミュレーション |
| `src/spotlight.js` | スポットライト。光の円錐・床の光だまり・影・反射・ほこり |
| `src/stages.js` | 舞台3種類（もり・うみ・おほしさま）。書き割りと吊り物 |
| `src/performers.js` | 出演者3人。歩いて出てきて、踊って、おじぎをする |
| `src/effects.js` | 舞台効果3種類（花びら・しゃぼん玉・きらきら） |
| `src/postfx.js` | にじむ光・トーンマップ・周辺減光・幕開けの閃光 |
| `src/textures.js` | 絵はすべて canvas で生成（外部画像なし） |
| `src/audio.js` | 音はすべて WebAudio で合成（音源ファイルなし） |
| `src/ui.js` / `styles.css` | 絵と光だけの操作パネル |
| `vendor/three.module.min.js` | three.js r169（MIT / `vendor/THREE-LICENSE.txt`） |

外部のネットワーク接続・画像・音源ファイルは使いません。

## 動作について

- WebGL2 が必要です（iOS 15 以降の Safari、Chrome、Firefox）。
- フレームレートが落ちると、床の映り込み → 後処理 → 解像度 の順に自動で軽くします。
- `?hq=1` を付けると自動の軽量化を止めます（見た目の確認用）。
