# すけすけ！じどうはんばいき

4歳児向けの、内部が透けて見える自動販売機のWebゲームです。
100円玉を入れて、ボタンを押すと、自販機が透明になって商品が中を転がって出てきます。

## あそびかた（文字が読めなくても遊べます）

1. 下の100円玉を、指で投入口までドラッグ
2. 好きな商品のボタンを押す
3. 自販機が透けて、商品が中のレールを転がる
   - 途中の黄色いつまみのレールを左右にドラッグすると、商品の転がりが変わる
4. ガタン！と届いたら、フラップを上へドラッグして開ける
5. 商品を指でつかんで取り出す
6. プルタブ／キャップを上へドラッグして開封

## 実行方法

ビルド不要の静的ページです。

```
npx serve .        # または任意の静的サーバ
```

iPhone / iPad のモバイルSafariを第一級ターゲットにしています（縦・横両対応）。

## 技術構成

- 単一SVGシーン + requestAnimationFrame（Three.js等は不使用、60fps優先）
- 手調整の簡易物理（レール転がり・弾道・壁反発。商品は100%必ず取り出し口に届く）
- Web Audioによる全効果音の動的生成（チャリン・カチッ・ウィーン・コロコロ・ガタン・プシュッ等）
- 明示的な状態機械（READY → CREDIT_READY → VENDING → ROLLING → ARRIVED → FLAP_OPEN → OPENING → COMPLETE）
- 2秒無操作で次の操作対象がやわらかく光るヒント表示（文字による説明なし）
