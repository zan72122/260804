# コロコロカプセル 🎡

4歳児向けのモバイルWebクレーンゲーム。ハの字に開いた2本のバーの上のカプセルを、クレーンの爪で横からそっと押して「コロン」と転がし、バーの間隔がカプセルより広くなったところで「ストン」と落として、取り出し口から受け取る遊びです。

## 遊び方(文字を読まなくても遊べます)

1. 画面を指1本でドラッグすると、爪が左右に動きます(光るゴーストの爪が置き場所のヒント)。
2. 指を離すと、爪が自動で降りてカプセルの横をそっと押します。
3. カプセルがコロンと一回転して、バーの広い方へ進みます。
4. 2〜3回押すと、足場が足りなくなってストンと落下。シュートを転がって取り出し口へ。
5. 大きな絵のボタンで「もう一度」か「別の色のカプセル」を選べます。

## 起動方法

```bash
npm install
npm run dev        # http://localhost:5173
```

本番ビルド(静的ホスティング用):

```bash
npm run build      # dist/ に出力(型チェック込み)
npm run preview    # ビルド結果の確認
```

バックエンド・ログイン・APIキーは不要です。`dist/` をそのまま静的ホスティングに置けます。

## 技術構成

- TypeScript + Vite + Three.js(WebGL2)
- 物理エンジンなしの「補助付き物理」: バーの間隔から接触幾何(沈み込み量・実効転がり半径・落下位置)を解析的に導出。同じ入力は同じ結果になり、落下は見た目上支えが足りなくなる位置と正確に一致します
- 音はWeb Audioでの合成(アセットなし)。初回タッチで有効化
- 縦横両対応・safe area対応・画面回転で状態を維持
- フレーム時間を監視して解像度と影を自動調整

## 主要ファイル

| ファイル | 内容 |
|---|---|
| `src/params.ts` | バー・カプセルの幾何と接触物理の導出 |
| `src/scene.ts` | 筐体・バー・爪・カプセル・シュートの3D構築 |
| `src/game.ts` | 状態機械(狙う→降下→押す→転がる→落ちる→ご褒美) |
| `src/camera.ts` | 固定プリセット間を滑らかに移動するカメラ |
| `src/audio.ts` | 合成効果音(コツ・コロン・ストン・チャイム) |
