# ぴかぴかレールごう ✨🚃

4歳の子のための、レール削正車（レールをけずってぴかぴかにする働く車両）の玩具模型風3Dゲームです。
数字も、タイマーも、失敗もありません。四つの擬音だけがルールです。

| 擬音 | あそび |
|------|--------|
| **カタカタ** | ミント色の列車が波打ったレールの上でカタカタ跳ねて騒ぎます。光と音とゆれで見つけたら、そこをタップ。 |
| **ガコン** | 削正車のおなかの砥石（3つ）を、指で1つずつ下に引き下ろします。ガコン！と車体が沈みます。 |
| **シャーッ** | 指でレールをなぞると削正車がついてきて、砥石とレールの接点から金色の火花が長い帯になって流れ、通ったあとが銀色に変わります。**長押しするとその場でけずって火花の噴水**になります。ゴシゴシ往復するほど早くぴかぴかに。 |
| **スーッ** | ミント色の列車をタップすると、磨いたレールの上を今度は揺れずに静かに走り抜けます。お花が咲いて、夜が明けると、また別の場所が波打っています。ずっと繰り返し。 |

現実のレール削正のたいせつな意味（波状摩耗を見つける → 砥石を当てる → 削って平らにする → 静かに走れるか確認する）はそのまま残しています。

## あそびかた

- iPhone / iPad の Safari で `index.html` を開くだけ（縦でも横でもOK）。
- サーバに置けない場合は **`standalone.html`**（1ファイル完結版）をそのまま開けます。
- 音はすべてその場で合成しています（素材ファイルなし）。右上のスピーカーで消せます。

## 開発

- 依存は同梱の Three.js (`vendor/three.module.min.js`) のみ。ビルド不要。
- ローカル確認: `python3 -m http.server 8642` → `http://localhost:8642/`
- 1ファイル版の再生成: `node build-standalone.js`
