# くるっ、キュッ、ポン！ヴァイオリン工房

4歳向けのヴァイオリン製作ゲーム。iPhone / iPad の Safari(縦・横)で動く、
**Three.js (WebGL) によるリアルタイム3D** のブラウザゲームです。ビルド不要・外部CDN依存なし。

## 遊び方

静的サーバーで配信して開くだけです。

```
python3 -m http.server 8000
# → http://localhost:8000/ を iPhone/iPad の Safari で開く
```

操作はぜんぶ一指。文字が読めなくても、金色に脈動するガイド・ゴーストの指・
次の部品の光で進められます。制限時間・失敗・点数はありません。

## 工程(2〜4分で一周)

1. **木材を見る** — 壁に立てかけたスプルースとメイプルの板をコンコン
2. **側板を曲げる** — 台に据えた熱い曲げゴテに薄いメイプルを当て、指でなぞると
   ジュッ……と湯気を上げながらコテに巻き付いてC字にしなる(接触部が赤熱)
3. **型へ沿わせる** — 曲げた側板を実際に掘り込まれたモールドへ置くと、リムが一周立ち上がる
4. **表板を形作る** — 板に引かれたチョーク線をなぞると溝が刻まれ、削りくずが舞って板が抜ける
5. **f字孔** — ガイドをなぞると職人の手のナイフが追従し、表板に本当の開口が現れる
6. **箱にする** — 浮かせた表板を胴へ下ろすとポン!と閉じ、ネックが付く
7. **魂柱** — 表板が透けて内部が見える。小さな柱をf字孔から中へ入れ、
   表板と裏板の間に立てると内部の灯りがともる
8. **ニス** — 傍らの3つの瓶(琥珀・赤褐色・ローズ)から色を選び、吊るした白木に刷毛で塗る
   (クリアコートの実光沢、木目が透ける)
9. **駒と弦** — 駒を置き、弦を下から上へ張り、ペグを回すと音程が上がる(ソ・レ・ラ・ミ)
10. **初めて鳴る** — 弓を一度だけ引く。工房が暖かく光る最大のごほうび
11. **眺める** — スタンドの完成品をスワイプで回転(裏は虎杢)。ニス替え・リボン・
    飾りつけ、「もう一台」で別の木目から再スタート

熱ゴテ・刃物・刷毛・弓は職人の手が扱い、子どもは板を押す・なぞる・置くだけです。

## 実装メモ

- `index.html`(HUDのみ) + `js/`(ES modules) + `lib/three.module.min.js`(同梱 r185)
- 世界は実寸(cm)の3D工房: 窓からの太陽光(シャドウマップ)+作業灯+天空光、
  梁上の埃、板張りの床、使い込まれた作業台(傷・凹み・シミ)、道具掛け、棚のニス瓶
- ヴァイオリンは実ジオメトリ: 放射グリッドによるアーチ付き表板/裏板(エッジバンド付き)、
  厚みのある側板リボン、ロフト生成のネック、スイープ渦巻きのスクロール、
  透かし彫り付きの駒(押し出し)、張力で撓む弦(チューブ再生成)
- 材質はプロシージャルPBR: アルベド+高さ→法線+粗さ(スプルース柾目/メイプル虎杢/黒檀/
  使用感のある作業台)。ニスは clearcoat 付きオーバーレイをマスクへ実際に塗る
- f字孔は進行度に応じてアルファマップへ切り込まれる実開口(内部は暗部+f孔から見える魂柱)
- 自動試遊API `window.__VW` を同梱。Playwright で iPhone/iPad 縦横4構成の一周試遊を確認済み
