# どうろを つくろう 🚜🚚🛞

4さいの こどもむけ、**けんせつじゅうき 3D あそび**。
ショベルカーの アームを **ゆびで じかに** うごかして 土を すくい、ダンプへ どさっ。
さいごは ロードローラーで ごろごろ、まっすぐな どうろが できあがり。

- **しっぱい なし・てんすう なし・じかんせいげん なし**
- **レバーも ボタンも なし**（ゆびは 1ぽん だけ）
- iPhone / iPad の **たて・よこ どちらの がめん** でも あそべる

---

## あそびかた

| ばめん | すること |
| --- | --- |
| ① ざくっ | つちの やまを ゆびで なぞる → バケットが 土に もぐって すくう |
| ② どさっ | ゆびを ダンプへ もっていく → じどうで バケットが ひらいて 土が おちる |
| ③ ごろごろ | ダンプが いっぱいに なったら ロードローラー。ゆびで ひっぱって いったりきたり |
| ④ できた！ | みちが たいらに なると かみふぶき・おはな・くるまが はしる |

ゆびを 3びょう はなすと、つぎに さわる ばしょに ✋の わ が でる。

---

## にゅうりょくの ほじょ（ここが かなめ）

ちいさな こどもは 3D の いちを ねらえない。だから **「ゆびの いち」から「やりたい こと」を すいそく**して、きかいの がわで ぜんぶ ととのえる。

```
ゆびの レイ
 ├ ダンプに かかった？（土を もって いる ときだけ はんてい）→ どさっ（つみこみ いちへ スナップ）
 ├ つちの うえ？                                            → ざくっ（ひょうめんの すこし したを ねらう）
 └ それ いがい                                              → そらへ もちあげる（せんかいじくの えんとうへ とうえい）
```

- **せんかい・ブーム・アーム・バケット** の 4じくは、さきっぽの いちを きめれば **2リンク IK** で じどうけってい
- めいれいは そのまま つたえず、**ばね（Spring）+ 指数減衰** ごしに つたえる
  → こどもの ガタガタした ゆびの うごきが、おおきな きかいの **おもみの ある うごき** に かわる
- バケットは **ほった りょうに あわせて まるまり**、ダンプの うえでは **かってに ひらく**
- とどかない ところを さわっても、**とどく はんいに そっと おさまる**だけ（エラーは でない）
- ローラーは 土に さえぎられない ように、**ドラムの たかさの へいめん** で ゆびを うけとる
- ヒントは 「いま とどく はんいで いちばん 土が たかい ところ」を さがして さす

## 土の へんけい

`src/terrain.js` は **105 × 41 の ハイトフィールド**（1つの `BufferGeometry`）。

- 上面の グリッド ＋ まわりの **「土の だんめん」スカート** ＋ そこの ふた を ひとつの メッシュに
- `carve()` … まるく けずる。とれた たいせきを かえす → バケットの つみりょうに なる
- `roll()` … だ円の あしあとの なかを どうろの たかさへ ちかづけ、「ならし ぐあい」を あげる
- `finishTo()` … クリアえんしゅつで ひだりから じゅんに ピカピカに しあげる
- いろは たかさ・ほった ふかさ・ぬれぐあい・ならし ぐあい から **ちょうてんカラー** で
- こうしんは **かわった しかくけい だけ**（ダーティ矩形）→ スマホでも おもくならない

## 3D の みため

- three.js（`vendor/` に どうこん。ネットに つながなくても うごく）
- ACES フィルミック トーンマッピング ＋ ソフトシャドウ ＋ グラデーションの そら（シェーダー）
- ぜんぶ **かどまるの はこ**（`RoundedBoxGeometry`）で できた おもちゃっぽい かたち
- ゆあつシリンダーは まいフレーム けいさんして のびちぢみする
- うごかない けしき（き・しげみ・コーン・くも）は **メッシュを マージ**して ドローコールを やく 170 に
- カメラは ROI（みせたい はこ）が わくに おさまる きょりを **かいせきてきに** もとめる
  - よこ画面 … ほぼ しょうめん（方位 12°）
  - たて画面 … みちに そって ほぼ まうしろ（方位 84°）＝ ながい どうろが たての がめんに おさまる

## うごかしかた

```bash
npx http-server -p 8123 -c-1 .
# → http://localhost:8123/
```

ビルドは いりません。ES Modules + importmap の しずてき サイトなので、
GitHub Pages などに そのまま おけます。

### じどう しあそび（テスト）

```bash
npm i
node fullplay.mjs iphone-landscape   # さいしょから「できた！」まで じどうで あそぶ
node fullplay.mjs iphone-portrait
node fullplay.mjs ipad-landscape
node fullplay.mjs ipad-portrait
```

`window.__game` に デバッグ API（`info()` / `project()` / `digSpot()` / `reset()`）が でて います。
URL の パラメータ `?timescale=4`（ゲームの じかんを はやめる）と `?noshadow=1`（かげを きる）は
テストよう です。ふつうに あそぶ ときは つけません。

なお、fps が おちる はしゃくでは **じどうで えの きめこまかさを 3だんかい さげる**ので、
ふるい iPhone でも とまりません（はやく なれば もどります）。
