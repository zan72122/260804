# くるっ、キュッ、ポン！ヴァイオリン工房

4歳向けのヴァイオリン製作ブラウザゲーム。iPhone / iPad の Safari（縦・横どちらでも）で動く、
Canvas 2D + Web Audio 製の単一ページアプリです。ビルド不要・依存なし。

## 遊び方

`index.html` を静的サーバーで開くだけです。

```
python3 -m http.server 8000
# → http://localhost:8000/ を iPhone/iPad の Safari で開く
```

操作はぜんぶ一指。文字が読めなくても、光るガイド・ゴーストの指・職人の目線で次の手が分かります。
制限時間・失敗・点数はありません。

## 工程（2〜4分で一周）

1. **木材を見る** — スプルースとメイプルをコンコン
2. **側板を曲げる** — 熱した曲げゴテに薄いメイプルを当て、指でなぞるとジュッ……くるーんとC字にしなる
3. **型へ沿わせる** — 曲げた側板を型に置くと胴のリムが立ち上がる
4. **表板を形作る** — チョークの輪郭をなぞって板を切り出す（裏板はポンと登場）
5. **f字孔** — ガイドをなぞると職人の刃物が追従し、二つのf字が現れる
6. **箱にする** — 表板をのせてポン！ネックも付く
7. **魂柱** — 半透明のボディのf字孔から小さな柱を中へ入れ、表板と裏板の間に立てる（断面レンズで秘密を確認）
8. **ニス** — 琥珀・赤褐色・ローズから選んで塗る
9. **駒と弦** — 駒を影に置き、弦を下から上へ張り、ペグをくるくる回すと音程が上がっていく（ソ・レ・ラ・ミ）
10. **初めて鳴る** — 職人が弓を一度だけ引く。ここが最大のごほうび
11. **眺める** — スワイプで回転（裏は虎杢）。ニス替え・リボン・花や星の飾りつけ、そして「もう一台」

危険な道具（熱ゴテ・刃物）はすべて職人キャラクターが扱います。

## 実装メモ

- `index.html` + `game.js` のみ。Canvas 2D（DPR≦2）、Web Audio はタッチで解錠
- 木目（スプルース柾目・メイプル虎杢）はシード付き乱数でオフスクリーン生成 — 「もう一台」で木目が変わる
- なぞり判定は先読み投影式で大きな許容半径を持ち、精密さを要求しない
- 自動試遊API `window.__VW`（現在シーン・推奨ジェスチャー）を同梱。
  Playwright での一周試遊は iPhone/iPad の縦横4構成で確認済み
