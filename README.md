# ねじって！よりあわせて！ながいロープみち

4さいの女の子のための、伝統的な**ロープウォーク（綱作り作業場）**の遊び。
iPhone / iPad の Safari でそのまま遊べる、WebGL の 3D ゲームです。

線つなぎでも、結び目パズルでもありません。本物の製綱の手順を、そのまま遊びにしています。

```
繊維束を離れた回転フックへ掛ける
  → 長いロープウォークへ張る
  → 各ストランドを同じ方向へ撚る
  → ストランド間へ溝付きの木製トップを置く
  → トップをゆっくり進める
  → その後ろで3本が一本の太いロープへ閉じる
  → 端を処理する
  → 完成したロープで巨大な梵鐘を持ち上げる
```

## 遊び方

- 操作は**一本指のドラッグ・円運動（ぐるぐる）・スワイプ**だけ。
- 絡まりも、切断も、制限時間も、点数もありません。
- どの手順も**必ず成功します**。手が止まったままでも、しばらくすると仕事はひとりでに少しずつ進みます。
- 指の速さと揺れは、綯い上がったロープの**らせん模様に少しだけ残ります**（撚りピッチと膨らみ）。同じ手順でも、できあがるロープは毎回すこし違います。

| 手順 | 操作 |
| --- | --- |
| 1. あさの たばを とおくの フックまで | 束をつまんで奥へドラッグ（タップでも可） |
| 2. てまえに ひっぱって ながく はろう | 手前へドラッグ |
| 3. ぐるぐる まわして ねじろう | 回し車のまわりで円運動 |
| 4. きの トップを あいだに おこう | 下へドラッグ |
| 5. トップを ゆっくり すすめよう | ロープに沿ってドラッグ |
| 6. はしを ぐるぐる まいて とめよう | 円運動 |
| 7. うえに スワイプして もちあげよう | 上へスワイプ |

## 動かす

```bash
npm install
npm run dev        # 開発サーバ (http://localhost:5173)
npm run build      # dist/ へ書き出し
npm run preview    # ビルドしたものを確認
```

`?q=low` / `?q=mid` / `?q=high` を URL に付けると描画品質を固定できます。
付けない場合は毎フレームの重さを見て自動で上下します。

## つくり

`three.js` の透視投影カメラによる、本物の 3D 空間です。CSS の擬似3Dは使っていません。
遮蔽、視差、被写界の奥行き、指数霧による空気遠近が、そのまま幾何から出ています。
外部の画像・モデル・フォントは一つも読み込みません。**質感はすべて Canvas 2D で手続き的に描いています**。

```
src/
  core/
    config.js      実寸法（メートル）。ここが世界の縮尺の唯一の出どころ
    stage.js       レンダラ・カメラ・照明・霧・自動品質調整
    input.js       一本指のドラッグ／円運動／スワイプ
    textures.js    床板・木目・漆喰・麻・石・青銅・地面（すべて手続き的）
    audio.js       WebAudio による合成音（梵鐘は非整数倍音を6本重ねている）
    util.js
  rope/
    ropeSystem.js  ★ 中核。細い3本 ⇄ 太い一本を、ひとつの連続面として毎フレーム生成
    fiberMaterial.js 麻の繊維すじ・けば・撚り角を注入する物理マテリアル
    whipping.js    端止め（細紐のらせん巻き）
  world/
    environment.js 長い小屋、光の筋、埃、遠景の山、道具と材料
    hooks.js       遠方の撚り車（回転フック）／近端の回転環／引き出し台／繊維束
    top.js         ★ 溝付き木製トップ。溝はロープの撚りと同じらせんで実際に彫ってある
    payload.js     櫓・滑車・梵鐘・花びら
    cat.js         作業場のねこ（大きさの物差しでもある）
  game/
    game.js        七つの手順の進行と、手順ごとのカメラ構図
  ui/
    ui.js / ui.css ひらがなの案内、ゆびのヒント、すすみぐあい
```

### 中核：細い複数本 → 太い一本の連続表示

`RopeSystem` は、作業区間 `s ∈ [0, 14m]` にそって毎フレーム面を張り直します。

- `s < close`（トップの後ろ）… 3本が撚りピッチ 0.34m のらせんで抱き合い、外径 54mm の一本になる
- `s > close`（トップの前）… 3本が半径 132mm の円に開いたまま、それぞれ細い

この二つは別のメッシュではありません。**同じ頂点列**で、
中心円の半径 `R(s)`・ストランドの太さ `r(s)`・撚り角 `Θ(s)` を
トップ位置を峠にして滑らかに混ぜているだけです。だから境目に切れ目がありません。

`Θ(s)` は角速度の積分なので、綯い終わった側は形が凍り、
トップが進むぶんだけ手前の3本が回ります。遠方のフック車も同じ角度で回ります。
これは実際のロープウォークで起きることと同じです。

木製トップの形も、この収束の断面からそのまま起こしています。
だから前は3つに開き、後ろはロープの芯まで細くなり、溝はロープの撚りとぴたり合います。

### 奥行きの読ませ方

- **近景** … 手が届く作業台、麻束、籠、床板の傷。カメラが進むと横へ流れる（視差）
- **中景** … 3m ごとの柱と梁が果てまで続き、距離がそのまま目盛りになる
- **遠景** … 開口から見える三層の山なみ。遠いものほど彩度と明暗差を失う

小屋の中は埃っぽい茶色い霧、外は明るい霞。カメラが戸口を抜けると、
霧の色と濃さが入れ替わります。

### 端末での配慮

- 縦画面・横画面の両方に対応。縦では画角と寄り方を手順ごとに変える
- セーフエリア（ノッチ・ホームインジケータ）を避ける
- ピンチ・ダブルタップ拡大・スクロールを止める
- iOS の制約に合わせ、最初のタッチで音を起こす
- 描画が重いと、画素密度 → 影 → 光の筋 の順に自動で落とす
