# はねばし キャナルタウン 🌉⛴️

4歳向けの跳ね橋・運河管理 3D ゲーム（WebGL / Three.js）。
おおきな跳ね橋のメンテナンスをして、巨大レバーを引いて橋を開き、
大きな船を通してあげよう！

## あそびかた（ぜんぶ 一本指）

1. **はぐるまに あぶら** — さびた歯車をタップして油を差す
2. **くさりの こうかん** — さびた鎖をタップしてピカピカの新品に
3. **しんごうの しゅうり** — 消えた信号灯をタップして点灯
4. **すいもんの ごみとり** — 水門に浮かぶゴミを3つタップして回収
5. **きかいの せつぞく** — 左右の機構をつなぐシャフトをタップして連結
6. **おおきなレバー** — 下にドラッグ！

レバーを引くと…カンカンカン！と遮断機が下り、信号が赤になり、
待っていた車と人が止まり、巨大な跳ね橋がゴゴゴ…とゆっくり開きます。
汽笛を鳴らして大きな船が水面に反射しながら通過。
船が通りすぎると橋が戻り、遮断機が上がって、町がまた動き出します。
何度でも繰り返して遊べます（船は毎回反対側から来ます）。

## 起動方法

静的サイトです。リポジトリのルートで HTTP サーバーを立てて開くだけ:

```bash
python3 -m http.server 8000
# → http://localhost:8000/ を iPhone / iPad / PC のブラウザで開く
```

GitHub Pages でもそのまま動きます。

- iPhone / iPad の縦・横どちらにも対応（画面比率でカメラが自動調整）
- 音はすべて WebAudio によるプロシージャル生成（音声ファイル不要）
- 依存は同梱の Three.js (`js/vendor/`) のみ。ビルド不要

## 技術メモ

- **本物の 3D**: 透視投影 + 実ジオメトリ + 遮蔽 + 影 + 空気遠近（フォグ）
  で近景（操作デッキ）/中景（跳ね橋・町）/遠景（スカイライン・風車・丘）を分離
- **水面**: ミラーカメラによる平面反射レンダーターゲット + 波法線での歪み
  + フレネル + 太陽ギラつき（`js/water.js`）
- **跳ね橋**: オランダ式バランスビーム型の二枚跳開橋。桁・天秤・カウンター
  ウェイト・鎖・歯車・同期シャフトが連動して動く
- **町の生活感**: 信号と遮断機に反応して並ぶ車と歩行者、カモメ、風車、
  旗のはためき、蒸気船の煙と航跡
- **テクスチャ**: すべて Canvas でプロシージャル生成（レンガ・石垣・板材・
  アスファルト・錆・汚れ / `js/textures.js`）
- `?fixeddt=0.033` を URL に付けると固定タイムステップ（自動テスト用）

## 検証

Playwright + 同梱 Chromium によるフルプレイスルー自動テストを実施済み:
全5タスク → レバー → 遮断機 → 開橋 → 船通過 → 閉橋 → 祝福 → 2周目
（逆方向の船）まで、縦・横両画面でエラーなしで完走。
