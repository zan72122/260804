# 🍰 ぱてぃしえ だいすき！

4歳向けのパティシエ3Dゲーム。WebGL（three.js）による実ジオメトリの3D空間で、
タイトルで好きなレシピを選んでお菓子作りを最後まで楽しめます。指1本で遊べ、
失敗も採点もありません。

## レシピ

| レシピ | あそび |
|---|---|
| 🍫 ひみつのドームケーキ | まぜる → そそぐ → やく → かさねる → かざる → チョコドームでかくす → あたたかいソースでとかしておひろめ |
| 🪞 かがみのケーキ | ムースをそそぐ → フルーツをひみつにしずめる → こおらせる → 型からするり → グレーズでとろ〜り鏡面に → かざる → きって断面のひみつを見せる |
| 🔥 あぶってパリン！ | カスタードをそそぐ → アイスをのせる → メレンゲでかくす → お砂糖をふる → バーナーであぶってこんがり → タップしてパリンと割っておひろめ |

タイトル画面のボタンでレシピを選ぶと、そのレシピだけが読み込まれて始まります。

## あそびかた（共通操作）

| そうさ | いみ |
|---|---|
| ぐるぐる | ボウルの上で ゆびを ぐるぐる（まぜる） |
| ながおし | 画面のどこでも 押しっぱなし（そそぐ・のばす・あぶる等） |
| なぞる | ゆびで なぞる（あぶる等、なぞると速く進む） |
| タップ | トレイのボタンや画面をタップ（えらぶ・のせる・わる） |

すべての長押し/なぞり工程は「画面のどこでも長押し」だけでも確実に進みます
（なぞると速い、押しっぱなしでも完了する無操作アシスト）。

最後は紙吹雪・ファンファーレ・キラキラと共に完成したお菓子がお披露目されます。
「もういちどあそぶ」で最初からやり直せます。

## 実行

外部依存はありません（three.js は `vendor/` に同梱）。静的サーバーで配信するだけです。

```bash
node test/server.js        # http://localhost:8347/
```

iPhone / iPad の Safari（縦・横どちらでも）、およびデスクトップブラウザで動作します。

## 自動試遊テスト

Playwright で指定したレシピの全フェーズを通しでプレイし、スクリーンショットと
コンソールエラーを検証します。

```bash
npm install                 # playwright-core (devDependency)
node test/server.js &       # サーバー起動

node test/playthrough.js portrait dome        # iPhone縦・ドームケーキ
node test/playthrough.js landscape dome       # iPhone横・ドームケーキ
node test/playthrough.js portrait glaze       # iPhone縦・かがみのケーキ
node test/playthrough.js landscape glaze      # iPhone横・かがみのケーキ
node test/playthrough.js portrait brulee      # iPhone縦・あぶってパリン！
node test/playthrough.js landscape brulee     # iPhone横・あぶってパリン！
```

第1引数は画面向き（`portrait` / `landscape`、省略時 `portrait`）、
第2引数はレシピ（`dome` / `glaze` / `brulee`、省略時 `dome`）です。
スクリーンショットは `test/shots/<向き>-<レシピ>/` に出力されます。

## 構成

```
index.html          UI（ヒント・トレイ・進捗・レシピ選択）と起動
src/main.js          コア: フェーズ非依存の入力・カメラ追従・メインループ・ctx API提供
src/recipes/
  dome.js            🍫 ひみつのドームケーキ（まぜる〜ソースでとかす）
  glaze.js           🪞 かがみのケーキ（ムース〜グレーズ〜断面カット）
  glazeObjects.js    かがみのケーキ用ジオメトリ・マテリアル部品
  brulee.js          🔥 あぶってパリン！（カスタード〜トーチ〜パリン割り）
  bruleeObjects.js   あぶってパリン！用ジオメトリ・マテリアル部品
src/cake.js          共通ケーキ関連オブジェクトと流体シェーダー
                     （生地の渦・注ぐ流れ・絞りクリーム・溶けるドーム・ソース・炎・紙吹雪等）
src/env.js           キッチン環境（近景/中景/遠景・照明・環境マップ・フォグ）
src/audio.js         WebAudio合成サウンド（効果音・オルゴールBGM）
src/util.js          トゥイーン・イージング・プロシージャルテクスチャ
vendor/               three.js r160（同梱）
test/                 静的サーバー・自動試遊テスト
docs/
  recipe-contract.md       レシピ拡張の構造契約（ctx API・フェーズ仕様・ファイル所有権）
  visual-quality-spec.md   ビジュアル品質の合格基準
```

## 技術メモ

- 透視投影 + 実ジオメトリ + 影 + 環境マップ + 暖色フォグで近中遠の奥行きを表現
- レシピは `src/recipes/<id>.js` のプラガブルモジュールで、共通コア（main.js）が
  提供する `ctx`（scene/camera/カメラ演出/入力/UI/audio/共有ケーキスタンド等）だけに
  依存して実装。タイトルで選ばれたレシピだけが初期化される
- 流体・質感はレシピごとのカスタムシェーダー/プロシージャルテクスチャで表現:
  生地の渦（頂点変位+法線再計算）、注ぐ流れ（くねり+テーパー）、絞りクリーム
  （TubeGeometryのdrawRange逐次表示）、チョコドームの溶解（ワールド高さ+ノイズに
  よる溶解カット・垂れ下がり頂点変形）、鏡面グレーズ（低roughness+envMap反射の
  とろり流下）、飴ガラスのカラメリゼ（動的CanvasTextureへの焼き色スタンプ+段階LUT）
- 進捗・トゥイーンは実経過時間ベースなので低フレームレート環境でも体感が安定
- 音はすべてWebAudioで合成（外部アセットなし）。初回タップでアンロック
