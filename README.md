# きらきら まどそうじ — Rope-Access Window Cleaning

高層ビルの外壁をロープで下降しながら窓を磨く、4歳児向けのモバイル web ゲームです。
文字を一切読まずに遊べます。指でさわる／なぞる／下へスワイプするだけ。

## 遊びかた（すべて文字なし）

| 手順 | 操作 | 画面の合図 |
|---|---|---|
| 1. ハーネスを締める | 光っているバックルを **タップ** ×3 | 光る輪 + カチッ |
| 2. 下降器をロープにつなぐ | 画面を **ドラッグ** | 光る輪 + カチン |
| 3. ビルの縁を越える | **下スワイプ** | 落ちていく矢印 |
| 4. 下降する | **下スワイプ**（指を止めるとピタッと停止） | 窓を囲む光の枠 |
| 5. 濡らす | 窓を **タップ／なぞる** | 水色の枠・霧 |
| 6. 拭く | 窓を **横／縦にドラッグ** | 金色の枠・進捗バー |
| 7. 繰り返す | 窓5枚できらきらフィナーレ | 星が5つ点灯 |

失敗・落下・タイムアップはありません。1プレイおよそ2〜4分。縦画面・横画面の
どちらでも成立します。右下の丸い矢印ボタンで何度でも遊び直せます。

## 動かす

`index.html` をブラウザで開くだけです。単一ファイルに全部入っているので、
`file://` からでも動きます。サーバーも外部サービスも不要。

開発時は ES モジュール版を使えます（HTTP サーバーが必要）:

```
python3 -m http.server 8000   # → http://localhost:8000/dev.html
```

## 構成

```
index.html            配布物（three.js + ゲーム全部を1ファイルに同梱）
index.template.html   HUD と CSS のテンプレート
dev.html              開発用（src/ をモジュールとして読む）
build.mjs             esbuild で index.html を生成
src/textures.js       手続き的テクスチャと HDR 空（画像アセットゼロ）
src/geom.js           押出プロファイル・面取り・動的チューブ・2骨IK
src/world.js          空・街・カーテンウォール・屋上・アンカー
src/rig.js            ロープ・下降器・シートボード・ハーネス・作業者・道具
src/audio.js          Web Audio による全効果音（音声ファイルなし）
src/game.js           状態機械・カメラ・入力・清掃シミュレーション・演出
src/main.js           起動と HUD
tools/shoot.mjs       ヘッドレス通しプレイ＋スクリーンショット
tools/frame.mjs       特定フェーズだけを高速に撮る
```

ビルド: `npm install && node build.mjs`

## 技術メモ

- 世界はすべて Three.js の WebGL 3D 空間。HTML/CSS は HUD だけに限定。
- テクスチャ・空・音は全部ランタイム生成。外部ファイル参照ゼロ。
- 空は Float32 の equirect として生成し、太陽は HDR 値を持つ。そこから
  PMREM で環境マップを作り、ガラスの鏡像・金属の反射・全体の間接光を一貫させている。
- カーテンウォールは実断面の押出：スナップキャップ方立（面・目地・押縁）、
  水切り鼻付き無目、ガスケット、後退したガラス、プレキャストのスパンドレル。
- 作業者から近い12層は実ジオメトリのインスタンス帯、遠方は同じ割付のシェル。
  帯は下降に合わせて再配置される。
- 汚れは 2D canvas レイヤー。スプレーは水膜 canvas に描き、スクイジーは
  進行方向に直交したブレード幅で `destination-out` する。乾いた面は落ちない。
- 清掃済みの高さ `uCleanY` をシェーダに注入し、その線より上の汚れ層を
  溶かして粗さを落とす。降りるほどビル全体が輝いていく。
- ロープは平行移動フレームでツイストを防いだ動的チューブ。作業線・バックアップ線・
  余長の3本を別々に振らせている。
- 腕と脚は2骨IK。スクイジーは指の位置に置かれ、手のほうが道具を追いかける。
