# おはなの こうえん 🌷

4歳児向けの公園づくり3Dゲーム。かわいた寂しい公園に、タップ・スワイプ・ドラッグだけで水と花をとりもどします。

## あそびかた

すべての操作は **タップ / スワイプ / ドラッグ** のみ。画面の「おてて」ヒントが次にやることを教えてくれます。

1. 🍂 **はっぱを あつめよう** — 落ち葉をスワイプでなでると、かごに飛んでいきます
2. ⛏️ **つちを たがやそう** — 花壇をスワイプでこすると、畝(うね)ができます
3. 🌷 **たねを うえよう** — 耕した花壇をタップして、好きな場所に球根を植えます(9つ)
4. 🧩 **すいろを つなごう** — 落ちている水路のかけらをドラッグして、切れ目にはめます
5. ⛲ **ふんすいを なおそう** — 曲がったノズルをタップすると、ぽんっと直ります
6. 🌊 **すいもんを あけよう！** — 中央の大きな水門を上にドラッグ!

水門が開くと——水が水路を駆け巡り、水車が回り、噴水が噴き上がり、**植えた場所どおりに**チューリップが咲き、水の通り道から花畑が広がって、蝶と鳥が帰ってきます。

## うごかしかた

ビルド不要の静的サイトです(three.js は `lib/` に同梱)。

```bash
python3 -m http.server 8611
# → http://localhost:8611 を Safari / Chrome で開く
```

iPhone・iPad の縦横どちらでも遊べます(カメラが画面比率に合わせて自動フレーミング)。ホーム画面に追加するとフルスクリーンで遊べます。

## 技術メモ

- **WebGL 3D** (three.js r160): 透視投影・実ジオメトリ・遮蔽・影・フォグによる空気遠近。近景(作業対象)/中景(公園)/遠景(丘・山・空)の3層構成
- 音はすべて **WebAudio でリアルタイム合成**(水音・きしみ・チャイム・鳥の声など、音声ファイルなし)
- 落ち葉・群生の花は InstancedMesh、描画コールは常時 200 未満
- 蘇生演出は水路からの距離に応じて頂点色が緑に波及(植えた花・つないだ水路の配置がフィナーレに反映)

## 検証

```bash
npm install playwright   # 任意の場所で
node tools/autoplay.mjs 390 844 iphone-portrait   # 幅 高さ ラベル
```

`tools/autoplay.mjs` が全タスクを実際のジェスチャ(タップ/スワイプ/ドラッグ)で自動プレイし、各工程の状態をアサート、要所のスクリーンショットを保存します。iPhone/iPad の縦横 4 構成で全チェック通過を確認済み。
