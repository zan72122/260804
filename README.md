# バゲット職人 — 4歳からのバゲットづくり

スマホ・タブレットのブラウザで遊べる、文字を一切使わないバゲット作りゲームです。
**WebGL（three.js）による実寸の3Dパン工房**で、透視投影・遮蔽・視差のある空間の中で作ります。

このゲームの主役は **「自分が入れた斜めの切れ目（クープ）が、石窯の中でその場所どおりに割れて開く」** という体験そのものです。

## 遊びかた

`index.html` をブラウザで開くだけです。ビルド済みの `dist/game.js` を同梱しているので、
何もインストールせずに動きます。

```
open index.html            # macOS
npm run serve              # iPhone / iPad から見るとき（http://<PCのIP>:8080）
```

iOS の仕様上、音は最初に画面を1回タッチしてから鳴りはじめます。

## 12の工程

絵と手の動きだけで進みます。読む必要はありません。

| | 工程 | 操作 |
|---|---|---|
| 1 | 生地を置く | 台をトン、と押す（ポフ） |
| 2 | ガスを整える | ぷくっとした気泡を指で押す ×4 |
| 3 | 巻く | 手前から奥へなぞる |
| 4 | 細長く伸ばす | 軸に沿って左右になぞる |
| 5 | 布に並べる | バゲットを布までひっぱる |
| 6 | 発酵 | 見ているだけでふっくらする |
| 7 | **クープを入れる** | 斜めに「スッ」×3〜5本 |
| 8 | 石窯へ | 窯口へ向かってなぞる |
| 9 | 蒸気 | 蒸気ボタンを押す（シュワッ） |
| 10 | **焼成** | 切れ目が開き、黄金色になるのを見る |
| 11 | 取り出す | 手前へ引き出す |
| 12 | 叩く | パンをトントン（コンコン） |

最後に「同じ形」「べつの形」「自由クープ」から選んでもう一度。

## パンの種類

- 普通のバゲット（全長60cm・直径6cm）
- 小さなバゲット（40cm）
- 少し太いバタール風（33cm・直径9cm）
- 自由クープモード（角度の補正がゆるく、8本まで入れられる）

## つくりの方針

### クープは「絵」ではなく、頂点の変位そのもの

バゲットは 208×144 の格子で作った実ジオメトリです。クープを入れると、
指の軌跡から次の値を取り出して保存します。

- `t` … 軸方向の位置（0〜1）
- `off` … 頂点からの弧長のずれ［m］
- `angle` … 軸に対する傾き
- `len` … 長さ
- `depth` … 深さ（ゆっくり引くほど深い）

焼成パラメータ `bake` を上げると、**その同じ座標の頂点が実際に動きます**
（`src/loaf3d.js` の `rebuild()`）。切れ目の断面は1本の連続した折れ曲がり曲線として
定義してあり、耳の根元を軸に皮が起き上がって、谷が開き、内側のクラムが露出します。

- 焼く前 … 谷の半幅 2mm / 深さ 6mm（浅い一本線にしか見えない）
- 焼き上がり … 谷の半幅 11mm / 深さ 19mm / 耳の張り出し 12mm

耳は実体があるので、**自己遮蔽し、影を落とし、カメラを動かすと視差で動きます。**
差し替え画像は一枚も使っていません。

正規化座標なので、**画面を回しても、焼成の途中でも、生地もクープも失われません**。

### 入力補正

指が曲がっても、位置がずれても、きれいな斜め線になります。

- 角度は理想の傾き（約21度）へ78%寄せる。逆向きに引かれた線は
  0度をまたいで補間せず、いったん鏡写しにしてから寄せる（軸と平行になるのを防ぐ）
- 15〜47度に収め、生地からはみ出す場合は角度ではなく長さを詰める
- 横方向のずれは中央へ吸着し、近すぎる2本は自動的に離す

ただし **長さと深さは指の動きがそのまま残ります**。

### 空間の作り

すべてメートル単位の実寸です。

```
床 y=0 ／ 作業台の天板 y=0.92 ／ 天井 y=3.2
石窯の前面 z=-2.85 ／ 炉口 1.34×0.60m ／ 炉室の奥行き 1.15m
奥の壁 z=-6.3
```

- **近景** … 作業台の手前の縁、lame、ドレッジャー、スクレーパー、垂れた布巾
- **中景** … クーシュに寝かせた3本のバゲット、石窯
- **遠景** … 奥の壁、腰タイル、パンの並ぶ棚。空気遠近は指数フォグで

石窯は前面と本体をそれぞれ刳り抜いた「筒」で、炉口から炉床まで実際に見通せます。

### 材質と光

テクスチャは画像ファイルを持たず、起動時に canvas 上で焼いています
（`src/textures.js`）。アルベド／ラフネス／法線を作り、**汚れ・摩耗・打ち粉・煤を
必ず含めて**新品に見せないようにしています。

- 木（作業台）… 年輪・板の継ぎ目・使い込んだ傷・擦り込まれた打ち粉
- 麻（クーシュ）… 平織の浮き沈み・糸のふし・生地のしみ
- 耐火煉瓦 … 目地の凹み・角の欠け・炉口まわりの煤
- 鉄（窯の扉）… 錆の浮き・傷・鋲と蝶番

光は物理単位で、窓からの昼光（影を落とす主光源）、天井の裸電球、壁の跳ね返り、
炉口からのスポットと照り返し。**炉の中にいる間は環境光を落として**、
炉の光だけでクープの凹凸が読めるようにしています。

### 失敗がない

焦げる・膨らまない・食べられない、という結果はありません。
時間制限も、星の評価も、点数も、お金もありません。

### 画面の向き

- **縦画面** … 軸を奥へ振って、細長い画面に斜めに大きく収める
- **横画面** … 3本を並べ、石窯も広く見せる。プレイヤーが入れたクープの模様が
  隣の2本にも写し取られて、いっしょに開く

### 安全な描写

刃物と高温の窯を扱うのは大人の職人の道具立てです。プレイヤーは画面上の大きな
ジェスチャーでその仕事を体験します。lame は持ち手を大きく、刃は3.5cmと小さく。

### 音

すべて WebAudio でその場で合成しています（音声ファイルなし）。
生地を置く「ポフ」、成形の摩擦音（なぞる速さに追従）、クープの「スッ」、
蒸気の「シュワッ」、皮の「パチパチ」、叩いたときの「コンコン」。

## ファイル

```
index.html
dist/game.js        … 同梱のビルド済みバンドル（これだけで動く）
css/style.css
src/main.js         … 起動
src/stage.js        … レンダラ・カメラ・照明・空気遠近
src/loaf3d.js       … ★バゲットの実ジオメトリ。クープと焼成の心臓部
src/bakery.js       … 実寸の作業場（作業台・クーシュ・石窯・道具・棚）
src/textures.js     … 手続き的なマテリアル生成
src/particles.js    … 蒸気・打ち粉・パン屑（3D点群）
src/hud.js          … 文字なしUI（絵記号・ゴーストハンド）
src/game.js         … 工程の進行・カメラ・レイキャスト入力
src/audio.js        … WebAudio の効果音
```

## ビルド

`src/` を変更したときだけ必要です。

```
npm install
npm run build        # → dist/game.js
```
