# スルッ！ぷうっ！ピカッ！ひかりのパイプ隊

4歳から遊べる、iPhone・iPad 対応のタッチゲームです。
古くなった地中のパイプを、UV-CIPP（光硬化式 管更生工法）の流れにそって
「スルッ → みつける → するする → ぷうっ・ぴたっ → ピカッ・じわっ → スーッ」と直していきます。

## あそびかた

| ばめん | そうさ | ないよう |
|---|---|---|
| 1. スルッ | ゆびで スワイプ | カメラロボ「コロン」を古い管の中へ送り込む。速さで車輪の音と光が変わる |
| 2. みつける | ふぐあいを タップ | 亀裂（しずくの音）、根っこ（ゆれる緑）、ずれ（コトッという振動）をさがす。矢印は出ない。迷うとロボのライトがそっと教えてくれる |
| 3. するする | ウインチを おしつづける | 畳まれた樹脂ライナーが、管のカーブにそって するすると引き込まれる |
| 4. ぷうっ・ぴたっ | ポンプを おしつづける | 空気でライナーが入口から順番にふくらみ、管のかべに ぴたっと密着する |
| 5. ピカッ・じわっ | ひかりの列車を すすめる | 安全カバーが閉じたら、ランプの列車が通過。通った場所から じわっと色つや形が固まる。どんな速さでも必ず成功し、速さで光の尾と模様だけが変わる |
| 6. スーッ | みずボタンを タップ | 透明な水と葉っぱの舟が、引っかかりなく スーッと流れて修理の効果がわかる |

- 失敗はありません。行き過ぎ・衝突・時間切れは起こりません。
- 「もういちど」で、毎回すこし違うパイプ（曲がり方・ふぐあい・土や空の色）が生成されます。
- 音はすべて Web Audio によるやさしい合成音。右上のボタンで消音できます。

## 動かしかた

静的ファイルのみで動きます。ビルド不要・外部依存なし。

```sh
npx http-server .   # または任意の静的サーバー
```

を開き、iPhone / iPad の Safari でアクセスしてください。
「ホーム画面に追加」すると全画面のアプリとして遊べます（PWA・オフライン対応）。
横向きがおすすめです。

## 設計メモ

- これは施工訓練シミュレーターではありません。実時間・圧力・化学組成・温度・光量・閉所作業の危険は再現していません。
- 画面の中では、成人作業員とロボットが安全装置（両端の安全カバー、地上の柵と看板）のある環境で作業します。
- 硬化中の光は、実際のUV光を直接見せる表現ではなく、進行状況を示す紫〜青白色の「ステータス光」として描いています。
- 実工程の骨格（①管内カメラ調査 → ②樹脂含浸ライナーの引き込み → ③空気圧での密着 → ④UV光源の通過による順次硬化 → ⑤通水・検査）は保持しています。
- 布の物理シミュレーションは使わず、軽量な変形（サンプル列ごとの半径補間・揺れ・イージング）で説得力を出しています。
- 文字が読めなくても遊べるよう、操作は「スワイプ・タップ・おしつづける」の3種だけ。迷ったときは6秒で手のアイコンとロボの視線が案内します。

## ファイル構成

- `manifest.webmanifest` / `sw.js` / `icon-*.png` — PWA（ホーム画面追加・オフライン用）
