# えいしゃぎしさん — 映写技師 3D ゲーム

4歳児向けの、文字を読まずに一本指だけで遊べる WebGL 3D ゲームです。
古い映画館の映写技師になって上映の準備をし、最後にスタートボタンを
押すと、客席が暗くなり、カーテンが開き、映写室から光の筋が伸びて、
巨大スクリーンに色鮮やかな世界が映し出されます。

## あそびかた（全て一本指・文字なし）

1. **レンズみがき** — 映写機のレンズを指でこすって汚れを落とす
2. **フィルムえらび** — 棚の3本のリール（さかな 🌊 / おはな 🌼 / ほし 🌌）から1本タップ
3. **フィルムとおし** — 光る先端をつまんで、大きなローラーに沿ってなぞる
4. **おんきょう** — 赤いプラグをアンプの金色ソケットへドラッグ（スピーカーがドンドン！）
5. **ピントあわせ** — 左右にこすると、スクリーンの白い光がくっきりに
6. **ざせき** — 曲がった椅子をタップして直し、金色のふさでカーテンを閉める
7. **じょうえい** — 赤いスタートボタンを押す！

上映が始まると、選んだフィルムで内容が変わります（海 / 野原 / 宇宙）。
上映中もスクリーンをタップするとキャラクターが跳ね、右下のボタンで
フィルムの掛け替え・もう一回ができます。

## 技術構成

- **Three.js (r160, vendored)** による透視投影の実 WebGL 3D 空間
  （遮蔽・視差・実ジオメトリ。CSS疑似3Dではありません）
- 近景（映写機・手すり）/ 中景（客席）/ 遠景（スクリーン）の奥行き分離、
  フォグによる空気遠近、電球色の壁面照明、ブロブ接地影
- 実寸ベースの造形（スクリーン10m、座席58cm、映写機1.2m級）、
  金属・ベルベット・木・ガラスの材質分け、レンズの汚れ・リベット等のディテール
- 上映内容は Canvas ペイントの `CanvasTexture`（テーマ別アニメーション）
- 効果音・BGMはすべて WebAudio でリアルタイム合成（音源ファイル不要）
- iPhone / iPad 縦横対応（アスペクトに応じた FOV 調整、セーフエリア対応、
  `touch-action: none`、devicePixelRatio 上限2）

## 実行

```bash
npm start   # python3 -m http.server 8080
# → http://localhost:8080 を開く
```

サーバー経由での配信が必要です（ES Modules のため `file://` 不可）。

## 検証

`test/e2e.mjs` が Playwright で実際のタッチ操作を再現し、
全工程（レンズ→フィルム→音響→ピント→客席→カーテン→上映→
フィルム切替）を通しでプレイして状態を検証します。

```bash
npm i playwright-core
node test/e2e.mjs
```
