# ながして！ひらいて！かねのこうぼう

4歳児向けの、**鐘の鋳造工房**ブラウザゲームです。
iPhone / iPad の縦画面・横画面、モバイル Safari で遊べます。

何もない土から鐘の鋳型をつくり、溶けた青銅を流し込み、
固まった鋳型を割って、**中から現れた巨大な鐘を、最後にはじめて鳴らします。**

文字は一切出てきません。すべて絵と手の動きで進みます。

---

## あそびかた（3〜5分）

| | 工程 | 操作 |
|---|---|---|
| 0 | 鐘のかたちをえらぶ | 3つの中からタップ |
| 1 | **芯型（しんがた）** ねん土を鐘の内側のかたちに削る | 画面をぐるぐる**円をかく** |
| 2 | **仮鐘（かりがね）** その上に鐘そのものの厚みをつける | もういちど**円をかく** |
| 3 | **装飾** 星・花・波・鳥・魚…を貼りつける | トレイから**ドラッグ**（タップでも置ける） |
| 4 | **外型（そとがた）** 外側の土を塗り重ねる | 指で**なぞる** |
| 5 | **焼成** 乾かして仮鐘を焼き出し、空洞をつくる | 自動（透視カットで空洞が見える） |
| 6 | **炉** 鋳物師が防具を着ける → 金属を選ぶ → 安全扉を閉める → 点火 | **タップ**と横**ドラッグ** |
| 7 | **注湯** 取鍋を傾けて溶けた青銅を湯口へ | レバーを**下へ長押しドラッグ** |
| 8 | **冷却** 赤橙から暗い金属色へ | 自動（数秒） |
| 9 | **鋳型割り** ひびが走り、土が崩れ、**鐘が現れる** | **タップ**／なぞる |
| 10 | **吊り上げ** 鐘を起こし、舌（ぜつ）を中へ取り付ける | 上へ**スワイプ** → 舌を**ドラッグ** |
| 11 | **初鳴らし** 綱を引くと鐘が揺れ、舌が内壁を打つ | 綱を**下へ引く** |

失敗・タイムリミット・点数はありません。
どの工程でも、時間がかかりすぎたときは緑の「→」ボタンが出て先へ進めます。

## 設計上の要点

- **鐘鋳造にしかない工程鎖が主役**です。ハンマーで叩く鍛冶ゲームでも、
  完成した鐘を連打する音ゲーでもありません。
- **鋳型を割るまで鐘は一度も見えません。** 鐘のメッシュは冷却工程で
  鋳型の内側に生成され、外殻が砕けるまで完全に隠れています。
- **一つの輪郭から全部の面ができています。** 芯型＝鐘の内面、仮鐘＝鐘そのもの、
  外型＝鐘の外面＋土の厚み。だから「削ったかたまり」と「出てきた鐘」が
  同じものだと目で分かります。
- **因果が見えます。** 注湯中は、青銅がたまった高さまで鋳型の土が
  内側から熱で光ります（外からは中身が見えないのに、進行が分かる）。
- **音はすべて合成**です。鐘の音は倍音列（hum / prime / tierce / quint /
  nominal …）から組み立てていて、**鐘形3種で音色が変わり**、
  金属3種で明るさが、装飾の量で唸りと非調和性がわずかに変わります。
- **危険な行為は大人が担当**します。防具を着け、安全扉を閉めるまで
  炉は点火できません。
- 高速点滅は使わず、熱の揺らぎ・反射・煙・低い炉音で迫力を出しています。

## 技術構成

- **three.js r169**（`vendor/` に同梱、CDN 不要・オフライン動作）
- 素の ES モジュール。ビルド不要・依存パッケージなし
- テクスチャ、環境マップ、効果音はすべて実行時に手続き生成（アセットファイル0個）
- 音声は Web Audio API。iOS のサイレントスイッチ対策として無音メディア要素と
  `navigator.audioSession` を併用
- 端末が重い場合は解像度を自動的に下げ、それでも足りなければ影を落とす

### 動かす

静的ファイルなので、任意の HTTP サーバで配信するだけです
（ES モジュールのため `file://` では動きません）。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

```
  world/
    profiles.js      鐘形3種と、そこから導かれる面の一族

    moldRig.js       芯型→仮鐘→外型→鐘
    materials.js     手続きテクスチャと材質
    decorations.js   装飾12種（同じ輪郭からアイコンと立体を生成）

    particles.js     粉塵・火花・煙・湯気
  ui/
    hud.js           文字なしのヒントと進行リング
    style.css
vendor/three/        three.js r169 (MIT)
```
