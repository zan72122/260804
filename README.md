# ふわり！ナノリボン工房

4歳児のための、超薄切（ウルトラミクロトミー）のブラウザゲーム。
iPhone / iPad の縦横、指一本で遊べます。文字を読む必要はありません。

一周は約2〜4分です。

1. **ミステリーブロックを選ぶ** — 中身の見えない樹脂ブロックを一つタップ
2. **ホルダーへ装着** — 大きくドラッグ。近づけばカチッと吸着
3. **knife boat へ注水** — スポイトを押すと一滴ずつ。水面が刃先へ届くと反射線が一本になり、澄んだ音が鳴る
4. **超薄切** — 大きなレバーを引くとブロックが下降。膜がブロック面から剥がれ、刃先を越え、水面へ着地して少し広がる
5. **ナノリボン** — 切片が端同士でつながり、銀色〜淡い金色の干渉色を帯びたリボンになる
6. **静電気を落ち着かせる** — イオナイザーの風でふわりと水面へ戻る
7. **睫毛ツール** — 水の流れを介してリボンを整える（刃先には決して触れない）
8. **グリッドですくう** — 水面下へ入れ、表面張力と滴とともに持ち上げる
9. **TEM reveal** — 低倍率から高倍率へ滑らかに潜り、壁・膜・小胞・繊維が段階的に現れる
10. **再プレイ** — 大きな絵を一回タップすれば同じ切削へ戻る

## 設計方針

* 点数・星・制限時間・ゲームオーバー・破損・試料喪失は存在しません。
* ダイヤモンド刃先には、ブラシもグリッドも指も決して当たりません（`src/game/safety.ts` が手前で止めます）。
* すべての工程に自動アシストがあり、何もしなくても必ず先へ進みます。
* 3〜5秒操作がないときは、文字ではなく反射・波紋・道具の呼吸する光で次の対象を示します。

## 動かす

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # typecheck + 静的ビルド (dist/)
npm run test       # 単体テスト (vitest)
npm run audit:screens   # 4画面サイズの自動プレイ＋スクリーンショット監査
```

`npm run audit:screens` は `npm run build` の後に実行してください。
実機を模した4サイズ（iPhone 縦横 / iPad 縦横）で一周を自動操作し、
`audit/` にスクリーンショットと `report.json` を書き出します。
コンソールエラー、切片の連続性、干渉色、回転時の状態保持を検証し、
問題があれば終了コード 1 を返します。

## 構成

```
src/core/     ループ非依存の土台（数学、乱数、ポインタ、WebAudio 合成音）
src/game/     状態遷移・レイアウト・水・リボン・切片・安全域（すべて純粋、テスト対象）
src/render/   Canvas2D 描画（機械、水面、切片、道具、TEM）
tests/        vitest（状態機械・レイアウト・物理・色・安全域）
tools/audit.mjs  Playwright によるスクリーンショット監査
```

バックエンド、ログイン、広告、課金、分析SDK、個人情報の収集はありません。
外部アセットも読み込みません（音は WebAudio で合成、絵はすべて Canvas 描画）。
