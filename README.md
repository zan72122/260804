# ドライドック

巨大船をドライドックへ入れ、海水を全部抜いて、普段は見えない船底を
出現させるゲームです。iPhone / iPad のブラウザで動きます。

対象は 4 歳児。文字も採点もゲームオーバーもありません。
指で水位を動かすと、それだけで巨大船の見え方そのものが変わります。

## 遊びかた

画面のどこでも触れば始まります。

1. **入渠** — 巨大船がタグボートに押されて、ゆっくり水路を入ってくる
2. **ゲート閉鎖** — 画面を触ると、水路に倒れていたフラップゲートが起き上がる
3. **排水** — 画面を上下にドラッグするとポンプのレバーが動き、水位が変わる。
   下へ引くほど水が抜け、上へ戻せば水が戻る
4. **着底** — 水位が 9.4m を切ると、船が盤木（キールブロック）へ静かに座る
5. **船底の出現** — ここからが本番。残りの水がゆっくり抜け、
   赤い船底、スクリュー、舵が姿を現す
6. **短い作業** — スクリューを指でぐるぐる回す / 舵を左右へ動かす /
   船底をこすって付着物を落とす
7. **注水と出渠** — 上へドラッグすると水が戻り、船が浮き、ゲートが倒れ、
   汽笛を鳴らして出ていく。そしてまた最初へ

何もしなくても順に進みます。急かしたいときは画面を触ってください。

## 動かしかた

`index.html` をブラウザで開くだけです（ビルド不要、外部依存なし）。

- iPad / iPhone: Safari で開き、共有 →「ホーム画面に追加」すると全画面になります
- ローカルサーバ経由でも同じです: `npx http-server -p 8080` など

WebGL2 が必要です（iOS 15 以降の Safari、最近の Chrome / Firefox / Edge）。

## つくり

依存ライブラリなしの素の WebGL2 です。単位はメートルで、寸法は実船に
合わせてあります。

| もの | 寸法 |
| --- | --- |
| 船 | 全長 182m / 幅 28m / 深さ 15m / 喫水 6.8m |
| ドック | 内寸 232 × 40m、深さ 16m |
| 盤木の天端 | 底から 2.6m |
| 外海の水面 | 底から 13.4m（陸は 2.6m 高い） |
| プロペラ | 直径 6.2m、5 翼 |

船は喫水 6.8m で浮いているので、キールは 6.6m の高さにあります。
水位が 9.4m を下回った瞬間に盤木へ着底し、そこから残り 9.4m 分は
「船が下がる」のではなく「水だけが引いて船底が現れる」時間になります。

### 描画パス

1. 平行光源のシャドウマップ（2048、PCF 3×3）
2. 平面反射（1/2 解像度。外海用とドック内用で水位が違うので必要に応じ 2 枚）
3. 不透明シーンを HDR の FBO へ
4. 深度とカラーを blit し、水面を描画。スクリーンスペース屈折、
   深さに応じた吸光と散乱、フレネル、太陽のきらめき、接岸部の泡、
   排水渦のねじれ、水たまりへの分裂
5. パーティクル（しぶき・霧・粉塵）
6. ブルーム + ACES トーンマップ

近景（ドック縁・手すり・係船柱）、中景（船とドック）、遠景（対岸のクレーン、
街、丘）が距離フォグと彩度で分離されるようにしてあります。

### ファイル

| ファイル | 役割 |
| --- | --- |
| `src/math.js` | 行列・ベクトル |
| `src/gl.js` | シェーダ、メッシュ、FBO の薄いラッパ |
| `src/geom.js` | 手続き的ジオメトリと世界の寸法 |
| `src/shaders.js` | GLSL |
| `src/renderer.js` | 描画パイプライン |
| `src/particles.js` | パーティクル |
| `src/audio.js` | WebAudio による手続き的な音 |
| `src/game.js` | 状態遷移、カメラ、入力、演出 |
| `src/main.js` | 起動とメインループ |

音は全て合成です（音声ファイルはありません）。ポンプの唸り、排水の流れ、
ゲートの重い軋み、着底の衝撃、スクリューの風切り、汽笛、カモメ。

### 性能

フレーム時間を見て、反射の枚数 → 描画解像度 → 反射そのもの、の順に
自動で落とします。描画ピクセル数は 230 万で頭打ちにしてあります。
