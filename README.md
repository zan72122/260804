# くうこう グランドハンドリング

4さいの こどもが iPhone / iPad の たてがめん・よこがめん どちらでも あそべる、
**空港グランドハンドリング**の 3Dゲームです。

飛行機を「飛ばす」ゲームではありません。**空港の地上作業にしかない動作**を
指ひとつで体験することが、このゲームの中心です。

## あそびかた（操作は5種類だけ）

| 場面 | 固有の動作 | 操作 |
| --- | --- | --- |
| 1. マーシャリング | 発光ワンドを持ったマーシャラーが、巨大旅客機を停止位置まで誘導する | 指を左右にスライド（誘導）／長押し（両腕を交差させたSTOP合図） |
| 2. 輪止め | 巨大タイヤの前後へ、オレンジの輪止めを差し込む | 大きな物体をドラッグ |
| 3. ボーディングブリッジ | 蛇腹と車輪を持つ橋が伸び、機体ドアへ接続する | 指を横方向へスワイプ |
| 4. 地上作業 | 地上電源プラグの接続／主翼下での給油／ベルトローダーと手荷物 | ドラッグ・長押し・縦スワイプ |
| 5. プッシュバック | 小さなトラクターがトーバーで巨大旅客機を押し戻す | トラクターをドラッグ→ゆっくりスワイプ→切り離し |
| 6. 出発 | エンジンが回り、機体が誘導路へ去っていく | （見るだけ） |

終了時に点数は出ません。**つぎの ひこうき / おなじ ひこうきで もういちど /
マーシャリングだけ** の3つから選べます。制限時間・ゲームオーバー・
金銭管理・文字入力はありません。指がずれても意図を汲んで成功へ導きます。

## うごかしかた

`index.html` を開くだけです。ビルドもインストールも不要です。

```
# ローカルで確認する場合（file:// でも動きますが、httpのほうが確実です）
python3 -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```

GitHub Pages などの静的ホスティングにそのまま置けます。

## つくり

外部ライブラリを一切使わず、**WebGL の生API上に自作したレンダラ**で描いています。
CSSによる擬似3Dではなく、透視投影・遮蔽・視差・実ジオメトリを持つ 3D 空間です。

| ファイル | 役割 |
| --- | --- |
| `src/math.js` | 4x4行列・ベクトル演算 |
| `src/geo.js` | ジオメトリ生成（回転体・断面ロフト・翼型ロフト・チューブ・面の巻き順補正） |
| `src/render.js` | WebGLレンダラ。単一シェーダによる陰影＋パックドデプスのシャドウマップ（PCF）、手続き的な空、加算スプライト、空気遠近 |
| `src/tex.js` | プロシージャルテクスチャ（舗装・ゲート標示・機体塗装・ターミナル外壁・タイヤ等） |
| `src/models.js` | 旅客機・ボーディングブリッジ・プッシュバックトラクター・ベルトローダー・地上電源車・給油車・手荷物カート・作業員・空港環境 |
| `src/audio.js` | WebAudio による効果音合成（音声ファイルなし） |
| `src/game.js` | 入力・状態機械・カメラ演出・UI |

### 画づくり

- **近景・中景・遠景の分離**: 手前の作業員と車両、中景の機体とブリッジ、遠景の
  ターミナル・管制塔・僚機・山並みを、距離に応じた霞（空気遠近）で描き分けています。
- **実寸**: 胴体長 37.6m / 全幅 34m / 主脚タイヤ直径 1.24m / 輪止め高さ 0.26m など、
  実機に近い寸法で構築しています。輪止めとタイヤのサイズ差はここから生まれます。
- **接地と影**: 太陽光による本物のシャドウマップで、機体・車両・人物が地面に落ちる
  影を描いています。
- **材質**: 塗装のつや、未塗装アルミの腹部、ゴムタイヤ、再帰反射ベスト、ガラスなど
  質感を変えています。舗装には骨材・油染み・打継ぎ目を焼き込んでいます。

### 画面向きへの対応

横画面では水平画角を広く、縦画面では水平画角を保ったまま被写体へ少し寄ることで、
どちらの向きでも同じ作業が同じ大きさで見えるようにしています。
セーフエリア（ノッチ・ホームインジケータ）も避けて UI を配置します。
