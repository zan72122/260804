# よまつりの じゅんび 🏮

4歳向けの「夜祭り準備」3Dゲーム（WebGL / Three.js）。

明るい昼間に提灯づくりをして、町の通りと門へ飾りつけ。
夕暮れに大太鼓をひとつ「ドン!」と叩くと、太鼓の音に合わせて提灯が端から順に点灯し、
屋台・窓・門へ光が広がり、描いた絵が地面へ投影されて、町全体が夜祭りへ変わります。

## 遊び方（実作業を模した一本指ジェスチャー）

| 工程 | 操作 |
| --- | --- |
| 骨組み | 畳まれた骨を **上へ引き伸ばす** |
| 紙貼り | 提灯を **指でこする**（こすった場所から紙が貼られる） |
| 絵付け | **指でなぞって自由におえかき**（3色）+ 花🌸/魚🐟/星⭐スタンプ。描いた絵は夜そのまま光り、地面へ投影される |
| ろうそく | **つまんで運んで** 提灯の中へ（磁石スナップ） |
| ひもつなぎ | 提灯を **ドラッグしてフックへ** |
| 張り上げ | 引きロープを **下へ何度も引く**（滑車でひもが一段ずつ上がる） |
| 太鼓 | ばちを **上からシュッと振り下ろすスワイプ** |

- 当たり判定は見た目の2〜3倍 + 画面比13〜15%のフォールバックで4歳向けに緩く、失敗状態なし
- どの工程も **タップ連打だけでも少しずつ進む**（救済経路）ので詰まらない
- 8秒操作がないと光る手がお手本ジェスチャーを実演
- フィナーレはドラッグで見回し、タップで太鼓をもう一度。縦持ち・横持ち両対応

## 実行

静的サーバで配信して開くだけです（ES Modules のため file:// 不可）。

```
python3 -m http.server 8000
# → http://localhost:8000/
```

## 技術メモ

- Three.js（`vendor/` に同梱）による透視投影・実ジオメトリの WebGL 3D。
  近景（作業台）/ 中景（家並み・屋台・門）/ 遠景（山なみ）を FogExp2 の空気遠近で分離
- テクスチャはすべて Canvas で手続き生成（紙・木目・石畳・漆喰・縞幕・絵柄）
- 音はすべて WebAudio で合成（太鼓・鉦・笛・効果音）。
  点灯カスケードは AudioContext の時計でスケジュールし、描画側が同じ時計を参照して発火するため音と光が同期
- 夜の光は「実ポイントライト（近景）+ エミッシブ + グロースプライト + 地面投影ディスク」のハイブリッドでモバイル性能を確保
