# くるくるクルトシュ / Kürtőskalács

4歳児が iPhone / iPad で遊べる、**クルトシュカラーチ（chimney cake）を作る**モバイルWebゲーム。

> ながい ひもを ぼうに ぐるぐる まいて、やいて、さいごに スポッ。

`index.html` を開くだけで動きます。依存ライブラリ・ビルド・通信は一切ありません。

---

## あそびかた（文字は読めなくて大丈夫）

指1本だけ。全工程が指の動きに直結していて、失敗もタイマーもスコアもありません。

| # | 工程 | 操作 |
|---|------|------|
| 1 | ひもを ぼうへ | 生地の端を棒のほうへドラッグ → 近づくと自動で吸着 |
| 2 | ぐるぐる まく | 横／斜めになぞる → なぞった分だけ棒が回り、螺旋が育つ |
| 3 | ころころ ならす | 板を左右になぞる → 隣り合う生地が密着して1本の筒になる |
| 4 | おさとう | シェイカーを左右に振る → 砂糖が降って表面に付く |
| 5 | やく | ハンドルのまわりを回す／横になぞる → 炎の前を通るたび黄金色に |
| 6 | スポッ | 一方向にスワイプ → 完成品が棒からスルーッと抜け、中の空洞が正面を向く |

画面下の5つのドットが現在の工程を示します（数字なし）。最後に丸い矢印を押すと最初から。
右上のボタンで音のオン／オフ。

## 設計メモ

### 操作
- **3Dの螺旋を指で描かせない。** 指の移動量 `p` に対して spit の回転を
  `spin = θcontact − p·2π·turns` で決めているため、生地が置かれる接触点は
  常に画面の同じ位置（円筒の手前上）に留まり、「指を動かしたぶんだけ
  目の前で helix が育つ」動きになります。
- 生地の端は**磁石**になっていて、棒に近づくと吸い寄せられて吸着します。
  それでも届かない場合は一定量ドラッグした時点で自動吸着します（詰みなし）。
- 焼き色は経過時間ではなく**回した量**で進みます（`bake += heat(θ) · f(回転速度) · dt`）。
  回さないと片面だけ色づくので、自然に「回す」動機になります。

### カメラ
自由操作なし。各工程が「フレームに入れたい世界座標」を宣言し、
リグが投影バウンディングボックスから距離とパンを毎フレーム補正します
（`focusSet()` / `autoFrame()`）。これにより縦・横どちらでも自動で構図が決まります。
縦持ちのときは yaw を少し足して、円筒の長さを奥行きに逃がし、ケーキが小さくなりすぎないようにしています。

### 描画（Canvas 2D・ライブラリなし）
- **生地** … 螺旋の中心線をサンプリングし、深度で分割した**連続ラン**として
  ストロークします（`pushRuns` / `drawRun`）。1本のランにつき
  ベース → 砂糖 → 溝の影 → ハイライト → 艶、の重ね塗りで断面の丸みを出しています。
  影とハイライトのオフセット方向は、チューブ断面に投影した光源方向（3D法線由来）から
  求めているため、セグメント単位のちらつき（うろこ状のアーティファクト）が出ません。
- **焼き色** … 焼き度 × ランバート の 2D カラーLUT（起動時に一度だけ生成）。
  炎に向いた面は追加のライトとして明るくなります。
- **密着** … `merge` で生地の半径をピッチ以上に太らせ、同時に溝の影を弱めることで
  「隣接ターンが1本の筒になる」変化を表現しています。
- **中空のReveal** … 開口部の円でクリップし、
  「奥の暗い円盤 + 開口から奥までの内壁リング + 内リップのハイライト」で
  トンネルを描画。棒が抜けた長さぶんだけ穴が深くなります。
- **炎** … volumetric なし。ソフトスプライトを積んだ舌状の炎＋残り火＋加算グロー。
- **深度** … すべての要素（生地のラン、棒のスライス、トンネル）を1つのリストに入れ、
  画家のアルゴリズムでソートしています。

### パフォーマンス
DPR は 2 で頭打ち。フレーム落ちが続くとサンプル密度を自動で落とし、
回復すると戻します。グラデーションは毎フレーム生成せず、
粒子・炎・湯気はプリレンダしたスプライトの `drawImage` です。

## 動作確認

iOS Safari 想定（Pointer Events / `touch-action:none` / `viewport-fit=cover`、
safe-area 対応、ピンチ・ダブルタップズーム無効）。
縦・横どちらでも全工程を通しでプレイできることを、
Playwright + Chromium による自動プレイスルー（390×844 / 844×390）で確認しています。
