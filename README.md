# ☕ バリスタごっこ — Barista Play

4歳児がiPhone・iPadの指1本で遊べる、**エスプレッソマシン操作**のごっこ遊びゲームです。
文字・点数・時間制限・お金・ゲームオーバーはありません。失敗もありません。

「材料を入れるだけ」の料理ゲームではなく、**バリスタ特有の手の動き**そのものを遊びにしています。

## 遊びかた（読めなくても分かるように作ってあります）

1. 空のポルタフィルターをグラインダーの下へ運ぶ → 粉が落ちてくる
2. 指で左右になでて表面をならす
3. タンパーを真上からグッと押し込む → **トン**
4. ポルタフィルターを**下から**グループヘッドへ差し込み、**横へ回して**固定 → **カチッ**
5. カップをドリップトレーへ置く → **コトン**
6. レバーを引くと細いエスプレッソが2本落ちる
7. ミルクピッチャーをスチームワンドへ持ち上げる → **シューーー**、渦と泡
8. ミルクを注いでラテアート
9. 完成カップをトレーへ
10. 「同じもの」「別の飲み物」「自由ラテアート」を選ぶ

飲み物は カフェラテ／カプチーノ風／ホットミルク／ココア風 の4種類。
ホットミルクとココアはエスプレッソ抽出を省いた短い工程になります。

## 起動

ビルド不要・依存ゼロの静的サイトです。

```bash
npx http-server -p 8080 -c-1 .
# → http://localhost:8080
```

iPhone / iPad ではホーム画面に追加すると全画面で遊べます。

## 中核の作り込み

### シグネチャーアクション：ポルタフィルターの「カチッ」

このテーマ以外ではまず出てこない動作なので、単発のタップではなく
**指の移動に追従する連続した感触**として実装しています（`src/game.js` の `Game.scenes.lock`）。

| 段階 | 実装 |
|---|---|
| 下から接近 | 溝の下側からのみ磁力ガイドが働く（上から降ろしても噛まない） |
| 溝へ入る | 0.16秒の吸着アニメーション＋「コッ」＋軽いカメラキック |
| 回転 | 指の**角度**がハンドルを駆動。6度ごとにラチェット音が上がっていく |
| 抵抗が増える | 入力進捗 `ip` が0.70を超えると、指の要求の**40%しか**ハンドルが動かない。<br>画面上は0.87付近で止まり、本体が細かく震え、ハンドル先端に「もう一押し」のシェブロンが出る |
| カチッ | 見た目の全可動域を**12%押し切った**ところで固定。overshoot付きスナップ＋金属音＋火花＋閃光 |

途中で指を離しても失敗にはならず、進捗はほぼ保持されたまま握り直せます。

### スチーム

ワンドの先端とミルク液面の**相対位置**で挙動が変わります。

- 液面近く（depth ≈ 0.3）＝空気を巻き込む → 泡が育ち「チリチリ」が鳴る
- 深く沈める → 渦が速くなり、音が低くこもる（バンドパスが3.4kHz→1.25kHzへ）
- 指の横移動でピッチャーが傾き、渦が締まる

幼児向けなので**失敗にしません**。理想位置から180単位以内なら毎フレーム72%の強さで
自動補正がかかるため、だいたいの位置に持っていけば必ず綺麗な渦になります。

### ラテアート

精密描画テストではなく、**流体**です（`src/fluid.js`）。

- 90×90 の非圧縮性ソルバ（semi-Lagrangian移流 → 発散除去12反復 → 渦度強調）
- 注ぎ点にミルク濃度と運動量を注入。指の速度がそのまま流れに乗る
- 左右に振ると往復回数を数え、**5回以上→ロゼッタ / 2回以上→チューリップ / それ以外→ハート**
- 最後に手前から奥へ一本線を引くと、その線を流体に刻んだうえで
  0.72秒かけて型へ収束。ただし**プレイヤー自身の場を22%まで残す**ので、
  「自分が作った」テクスチャが必ず残ります

めちゃくちゃに塗りたくっても必ずかわいい模様になることは自動テストで確認済みです
（混沌・往復・一点・全面の4パターン）。指を離して3.2秒経つか、
長く注ぎ続けた場合は自動的に模様が完成するので、**詰まることがありません**。

### 音

すべてWebAudioの合成音です（音源ファイルなし＝操作と完全に同期）。

グラインダー / タンピング「トン」 / 固定「カチッ」 / 抽出ポンプの低い機械音 /
カップへ落ちる音（液面が上がると共鳴が高くなる） / スチーム「シューーー」 /
ミルクの「チリチリ」 / カップを置く「コトン」

### 画面

ワールド座標（1180×640）ひとつをカメラで写しています。

- **縦画面**：工程ごとに手元へ寄る（ロック時は約1.05倍、ラテアート時は約1.44倍）
- **横画面**：グラインダー・マシン・スチームワンド・完成トレーまでカウンター全体
- **回転**：ゲーム状態はカメラと独立しているため、進行状況はそのまま保持されます

## ファイル

```
index.html      起動ページ（音声アンロック用のタップゲート付き）
src/style.css   全画面キャンバス、iOSのズーム・バウンス抑止
src/core.js     数学ヘルパ / カメラ / 単一指ポインタ / 合成音エンジン
src/art.js      ワールド配置と全描画（マシン・グラインダー・ポルタフィルター・カップ・ピッチャー）
src/fluid.js    ラテアートの流体ソルバと模様テンプレート
src/game.js     工程ステートマシンとジェスチャー
src/main.js     キャンバス初期化・入力・リサイズ・フレームループ
```

## 動作確認

Chromiumの実機相当ビューポート（iPhone 390×844 / 横 844×390 / iPad 1024×768）で
実際にポインタ操作を流し、全工程の通しプレイ・2周目の再プレイ・画面回転・
ホームボタン・自由ラテアートまで自動テストしています。
描画1フレームあたりの update+draw は DPR3・流体稼働中で中央値 2.3ms（p95 2.9ms）です。
