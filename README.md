# 🍰 ぱてぃしえ だいすき！

4歳向けのパティシエ3Dゲーム。WebGL（three.js）による実ジオメトリの3D空間で、
まぜる → そそぐ → やく → かさねる → かざる → チョコドームでかくす → あたたかいソースでとかして
おひろめ、までを指1本で遊べます。失敗も採点もありません。

## あそびかた

| 工程 | そうさ |
|---|---|
| まぜまぜ | ボウルの上で ゆびを ぐるぐる |
| そそぐ | ながおし |
| やく | オーブンを タップ |
| クリーム | いろを えらんで ながおし |
| かざり | すきなボタンを タップ |
| しあげ | ながおしで ソースを かける |

最後にチョコレートドームがとろりと溶け、虹色のケーキ・流れるソース・飾り・光るろうそくが一斉に現れます。

## 実行

外部依存はありません（three.js は `vendor/` に同梱）。静的サーバーで配信するだけです。

```bash
node test/server.js        # http://localhost:8347/
```

iPhone / iPad の Safari（縦・横どちらでも）、およびデスクトップブラウザで動作します。

## 自動試遊テスト

Playwright で全フェーズを通しでプレイし、スクリーンショットとコンソールエラーを検証します。

```bash
npm install                 # playwright-core (devDependency)
node test/server.js &       # サーバー起動
node test/playthrough.js portrait    # iPhone縦
node test/playthrough.js landscape   # iPhone横
```

スクリーンショットは `test/shots/` に出力されます。

## 構成

```
index.html        UI（ヒント・パレット・トレイ・進捗）と起動
src/main.js       フェーズ進行・入力・カメラ・メインループ
src/cake.js       ケーキ関連オブジェクトと流体シェーダー
                  （生地の渦・注ぐ流れ・絞りクリーム・溶けるドーム・ソース・炎・紙吹雪）
src/env.js        キッチン環境（近景/中景/遠景・照明・環境マップ・フォグ）
src/audio.js      WebAudio合成サウンド（効果音・オルゴールBGM）
src/util.js       トゥイーン・イージング・プロシージャルテクスチャ
vendor/           three.js r160（同梱）
test/             静的サーバー・自動試遊テスト
```

## 技術メモ

- 透視投影 + 実ジオメトリ + 影 + 環境マップ + 暖色フォグで近中遠の奥行きを表現
- 流体はカスタムシェーダー: 生地の渦（頂点変位+法線再計算）、注ぐ流れ（くねり+テーパー）、
  絞りクリーム（TubeGeometryのdrawRange逐次表示）、チョコドーム（ワールド高さ+ノイズによる
  溶解カット・垂れ下がり頂点変形）、キャラメルの垂れ（角度ノイズによるアルファカット）
- 進捗・トゥイーンは実経過時間ベースなので低フレームレート環境でも体感が安定
- 音はすべてWebAudioで合成（外部アセットなし）。初回タップでアンロック
