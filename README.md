# ピザやさん — 石窯のピザ職人ごっこ

4さいの女の子が、iPhone / iPad の**たて画面・よこ画面**どちらでも遊べる、
ピザ職人あそびの Web ゲームです。文字は 1 文字も出てきません。

`index.html` を開くだけで遊べます（ビルド不要・外部素材ゼロ・オフライン可）。

---

## このゲームの主役は「具をのせること」ではありません

ピザ職人にしかない **からだの動き** を看板にしています。

**まわす → とばす → ピールにのせる → 窯の奥へスッ → 窯の中でクルッ → 手前へスッ**

とくに **ピールで石窯へ滑り込ませる操作**（シグネチャーアクション）は、
画面奥へスワイプすると **ピールとピザが指と 1 対 1 で同期して前進**し、
最後のひと押しで **ピザだけが石床にスルッと残り、ピールが手前へ戻ります**。
「窯をタップしたら消えた」式の表現はどこにもありません。

---

## あそびの流れ（ぜんぶ絵とジェスチャーだけ）

| | やること | 指の動き |
|---|---|---|
| 1 | 生地玉を置く | ボウルから板へタップ／ドラッグ |
| 2 | 押し広げる | 生地の上をなぞる（押した方向に伸びる） |
| 3 | まわす | 円を描く（遠心力でまるく・大きくなる） |
| 4 | 空中へとばす | 上へスワイプ（弱→ふわっ／強→高くくるくる） |
| 5 | ソースをぬる | 中心から外へ、うずまきを描く |
| 6 | 具をのせる | 器から大きくドラッグ（チーズはなぞると降りつづける） |
| 7 | ピールへ移す | ピザをピールへドラッグ（吸着あり） |
| 8 | **窯の奥へスッ** | **画面奥へ長いスワイプ** |
| 9 | 焼ける | 見て楽しむ（窯をつつくと火がぶわっ） |
| 10 | **窯の中でクルッ** | ぐるっと円を描く（炎に近い側の焼き色が入れかわる） |
| 11 | 手前へスッ | 手前へスワイプ |
| 12 | カット | 大人の職人の手がカッターを持ち、なぞって切る／1切れ持ち上げるとチーズが伸びる |
| 13 | つぎをえらぶ | おなじピザ／ちがうピザ／じゆうに |

メニューは **マルゲリータ / コーン&チーズ / カラフルやさい / じゆうトッピング** の 4 つ。

---

## 4 さいのための設計

- **失敗がない** — 生地は落ちない、焦げて食べられなくなることもない、叱られない。
  弱いスワイプでも生地は少し浮いて必ず手元へ戻ります。
- **文字ゼロ・数字ゼロ** — 得点・星・お金・待ち時間・ゲームオーバーなし。
  次にすることは、光る輪・矢印・くり返し動く手のシルエットだけで伝えます。
- **止まらない保険** — 15 秒さわらないと、職人がその操作をやってみせます。
  そのまま何もしなくても最後まで一周します（`tools/idle-test.js` で検証済み）。
- **指ひとつで完結** — マルチタッチ不要。ターゲットは大きく、
  ドラッグには吸着（具材・ピール）と軌道補正（ピールは経路に射影）が入っています。
- **手ざわり** — 押した強さで生地の伸び方が、回した速さで回転と丸まり方が変わります。
- **安全な構図** — 高温の窯に手を入れる絵はありません。
  プレイヤーが操作するのは長い柄のピールで、窯のそばに立つのは大人の職人です。

## 画面の向き

- **たて**：ピザと手元を大きく。窯は上、手前から奥へ突き上げる長いスワイプ。
- **よこ**：職人 → ピール → 石窯までがひと続きの空間。
  カウンター手前から窯の奥まで、画面を横切る長いスワイプになります。

向きを変えると、ワールドの配置・カメラ枠・トレイの並びがすべて組み替わります。

## 見た目・音

すべて **Canvas 2D による手続き的描画**で、画像ファイルは 1 枚も使っていません。

- 生地は 72 点の可変半径ポリゴン。押すと局所的に伸び、回すと表面張力でまるくなります
- コルニチョーネ（ふち）がぷくっと膨らみ、気泡が浮き、焼き色の斑点が出ます
- **焦げは炎に近い側ほど濃くなる** ので、窯の中で回す操作に意味があります
- 溶けるモッツァレラ、うずまくソース、舞う小麦粉、揺れる炎、飛ぶ火の粉
- 窯の中は **横スライスをずらして転写**することで、熱でゆらぐ空気を表現しています
- 音は WebAudio でその場で合成（効果音・窯の火のループ・ひかえめなマリンバ）

ピンク・虹色はエプロン、ピールの柄、皿、店内の飾りに使い、
ピザそのものと石窯の質感はリアル寄りに保っています。

## ファイル

```
index.html
css/style.css
js/util.js     算数・補間・乱数
js/audio.js    WebAudio の効果音合成
js/art.js      石窯・炎・ピール・職人・粒子・ガイドの描画
js/pizza.js    ピザのモデルと描画（生地・ソース・具・焼成）
js/stages.js   あそびの流れ（各ステージの操作とガイド）
js/game.js     レイアウト・カメラ・入力・描画パイプライン
tools/         検証用（実機サイズでの自動プレイ・各ステージの撮影・無操作テスト）
```

## 検証

```
node tools/playtest.js  iphone-p|iphone-l|ipad-p|ipad-l   # 実寸で一周あそぶ＋撮影
node tools/shots.js     iphone-p|...                      # 各ステージの見た目を撮影
node tools/idle-test.js iphone-p                          # 無操作でも一周できるか
```

（Playwright + Chromium が必要です）
