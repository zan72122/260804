# おえかきパティシエの おかし通り

4歳の子どもが「一本の線」と「一回のぽん」だけで、
自分の線がそのまま骨格になった立派なお菓子を完成させるWebゲームです。

子どもの線は消しません。描いた曲線・渦巻き・ジグザグが、
そのままホイップクリーム・チョコソース・アイシングの中心線として立体化されます。

## 遊び方

1. おかし通りで、光っているお店(住民のおねがい)をタップ
2. 3色のクリーム/アイシングから1つ選ぶ(選ばなくてもOK)
3. お菓子の上に指で一本の線を描く(点だけでもOK → 小さなクリームのお花になります)
4. 好きなところを一回「ぽん」とタップ → イチゴやチェリー、スプリンクルが乗って完成
5. 住民がお菓子を受け取って食べてくれます
6. 完成したお菓子はお店のショーケースに飾られ、作るほど通りが賑やかになります
   (3個でベンチの住民、5個で誕生日会、8個で夕方になり街灯が点きます)

文字は使いません。タップと一本指ドラッグだけで遊べます。
やり直したいときは左上の「くるん」矢印ボタン。

## 動かし方

ビルド不要の静的サイトです。

```
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

iPhone / iPad(縦・横どちらも)、マウス、Apple Pencil に対応しています。
効果音はWebAudioで生成しており、音が出ない環境でも遊べます。
作品は localStorage に保存されます。

## 構成

- `index.html` — エントリ
- `js/util.js` — スプライン・平滑化・乱数などの基盤
- `js/audio.js` — WebAudioによる効果音
- `js/materials.js` — ホイップ/ソース/グレーズのレンダラとトッピング素材
- `js/sweets.js` — 3種のお菓子の土台(ショートケーキ・カップケーキ・ドーナツ)
- `js/chars.js` — 住民キャラクター
- `js/street.js` — おかし通りシーン(進行演出・ショーケース)
- `js/making.js` — 制作台シーン(描画→成長→トッピング→お祝い)
- `js/main.js` — ループ・入力・シーン遷移・保存
