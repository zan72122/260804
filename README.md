# ねつききゅうを とばそう！ 🎈

4歳向けの熱気球「地上スタッフ」3Dゲーム（WebGL / Three.js）。

平らな巨大布を広げるところから始まり、ロープをほどき、かごをつなぎ、
大型ファンで空気を送り、バーナーと重りを準備。最後にバーナーのレバーを
長押しして最後のロープを外すと——布が巨大な気球へ膨らみ、ゆっくり
起き上がり、朝焼けの空へ浮かんで、町・雲・朝日・虹を見下ろします。

## あそびかた

```bash
# リポジトリ直下で
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

（`index.html` をダブルクリックしてファイル直開きでも動きます）

- **一指操作のみ**: タップ・なぞる・長押しだけ。失敗はありません。
- **縦横対応**: スマホ縦持ち・横持ち・PCどちらでも遊べます。
- 👆 の手が次にさわる場所をいつも教えてくれます。

## おしごと（全7ステップ）

1. 🫳 布をなぞって大きく広げる
2. 🪢 もつれたロープを3つタッチしてほどく
3. 🧺 かごをタッチして接続（倒した姿勢で連結、本物と同じ）
4. 🌀 ボタン長押しで大型ファンの送風（布が波打つ）
5. 🧸 砂袋の重りを3つ取り付け
6. 🔥 バーナーのレバーを長押しして点火
7. ✂️ 最後の係留ロープをタッチ → 膨張 → 起立 → 離陸！

## 技術メモ

- Three.js r149（`lib/three.min.js` を同梱、外部通信なし）
- 気球の外皮は 2,220頂点のパラメトリックメッシュを毎フレーム CPU モーフ
  （たたみ束 → 平らな布 → 横倒し膨張 → 直立、法線再計算つき）
- 透視投影・PCFソフトシャドウ・フォグによる空気遠近・ACES トーンマッピング
- 町・木・山はジオメトリ結合で低ドローコール化、雲・虹・鳥・火炎は専用シェーダ/加算合成
- 音は全て WebAudio でプロシージャル生成（オルゴールBGM、ファン・バーナーのノイズ、効果音）
- 自動試遊テスト（Playwright）で縦横両方の全ステップ通しを検証済み
