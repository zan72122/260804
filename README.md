# かげえ げきじょう — 影絵劇スタッフ3Dゲーム

4歳児向けの WebGL 3D ゲーム。きみは影絵劇団の小さなスタッフ。
舞台裏で影人形を作り、白い幕の裏に仕込み、最後に会場を暗くして背面ライトを点けると——
手のひらサイズの人形が、幕いっぱいの巨大な動物・城・森・海に変わります。

## あそびかた

1. **どうぶつえらび** — うさぎ・ことり・おさかな から1つタッチ
2. **にんぎょうづくり** — 光るパーツをタッチして組み立て（厚紙3mmの実寸工作）
3. **いろがみはり** — 透明セロファンを選んで穴に貼る（本番で色つきの光になる）
4. **はいけいかさね** — 森・城・海の背景カードをレールに吊るす
5. **ぼうといと** — 操作棒と可動部の糸をつける
6. **まくのうらへ** — 指でドラッグして人形をクリップへ（磁石スナップ・失敗なし）
7. **ライトのきょり** — 指でライトを前後させると裏の幕の影が伸び縮み
8. **ほんばん** — 客席側は真っ白のまま（準備はないしょ）。暗転→背面ライト→
   小さな人形が巨大な影絵になり、森→城→海と背景が入れ替わり、
   ホタル・コウモリ・魚・泡・帆かけ舟が動き出す。上演中のタッチはきらきら＆ジャンプ。

- **一指操作のみ**（タップとドラッグ、マルチタッチは無視）
- **縦画面・横画面 両対応**（画角を自動調整）
- **失敗なし**（どの順でも進める・ドラッグはどこで離してもOK）

## 実行方法

静的ファイルのみ。ローカルサーバで配信してブラウザで開くだけです。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

## 技術メモ

- **Three.js（同梱: `lib/three.module.min.js`）** による透視投影・遮蔽・実ジオメトリの WebGL 3D。
  CSS疑似3Dは不使用。
- **影絵投影**: ランプ位置に置いた投影用カメラでレイヤー1のオブジェクト
  （人形・背景・棒・糸）をレンダーターゲットへ描画。カード紙は黒、セロファンは乗算合成で
  色付きの透過光を再現。ライトとの距離で影の拡大率が物理どおりに変化
  （`拡大率 = ランプ〜幕 / ランプ〜人形`）。
- **幕**: 表と裏で別マテリアル。準備中は裏面のみに投影を表示し、
  客席側は照明が入るまで真っ白（仕込みを見せない）。織り目・周辺減光を乗算。
- **実寸・材質**: 幕1.5×1.125m、人形約0.3m（厚紙3mm＋貼り合わせ段差）、机0.73m、
  ランプ三脚・ドリー・ケーブル、床板の木目・節・すり傷、机の絵の具汚れ、
  漆喰壁の染みなどを手続きテクスチャで生成。
- **照明**: 作業ペンダント＋客席ペンダント＋キーライト（シャドウマップ）、
  本番は暗転して背面スポット＋幕からの照り返しのみ。ビーム円錐と塵で空気感。
- **音**: WebAudio による完全合成（タップ音・紙音・チャイム・上演オルゴール
  「きらきら星」＋ディレイ）。外部アセットなし。
- **奥行き**: 近景（机・道具）/ 中景（額縁舞台・幕）/ 遠景（壁・ポスター・客席）の
  3層分離、指数フォグによる空気遠近。

## 開発

`window.__game` に試遊用のデバッグAPI（現在工程・ヒント座標・投影の自己診断など）があります。
Playwright による自動通しプレイで縦横両方の完走を検証済み。
