# すいすい すいぞくかん おそうじ

4さいのこどもが、ゆびいっぽんで あそべる 3D の すいぞくかん おそうじゲームです。

飼育員さんが ぶくぶく泡を出しながら水槽へ潜り、ガラスをすいーっと磨き、
透明ホースをフィルターにつなぎ、底の落ち葉を吸いとります。
作業がすすむほど水がだんだん澄んでいき、最後におさかなが帰ってきて
すいすい泳ぎだします。

**あそびかた: 画面をゆびでなぞるだけ。**

---

## 設計のきほん

4歳児向けなので、つまずく要素をすべて外してあります。

| 入れていないもの | 理由 |
|---|---|
| 失敗・ゲームオーバー | 何をしても先へ進める |
| 点数・タイム | 競争させない |
| 酸素ゲージ | 急かさない |
| 2本指の操作 | 一指だけで完結させる |
| 文字を読ませる場面 | 絵とアニメで伝える（文言はすべてひらがな） |

かわりに、**強い補助**を入れています。

- 道具の当たり判定は見た目よりずっと大きい（ガラス磨きの半径は約 0.95 ワールド単位）
- ホースの口金は、ドラッグ中ずっと つなぎ口へ引き寄せられ、近づくと自動で吸い付く
- 落ち葉はノズルが近づくだけで、ふわっと浮いて寄ってくる
- あと少しで終わりというところ（86%）からは自動で仕上がる
- **3秒さわらないと、飼育員さんが自分で作業を進める**（画面を見ているだけでも話が進む）

## そうじの流れ

1. **ガラスみがき** — 手前のガラスを指でなでるとコケが落ちる
2. **ホースつなぎ** — 透明ホースの口金を、光っているフィルターの差込口へ運ぶ
3. **おちばそうじ** — ノズルで底をなでると、落ち葉が透明ホースの中を通ってフィルターへ運ばれていく
4. **ごほうび** — 水がすっかり澄み、おさかなが帰ってくる

水の澄みぐあいは `ガラス 0.30 + ホース 0.22 + おちば 0.30` で決まり、
最後のごほうびで 1.0 まで抜けます。

## 見た目まわり

すべて手続き的に生成しています（外部の画像・モデル・音声ファイルはゼロ）。

- **ポストプロセス** — HDR オフスクリーン → 明部抽出 → 分離ガウシアン →
  合成（水のゆらぎ・水中の色被り・周辺減光・ACES トーンマップ・微量のグレイン）
- **コースティクス** — 砂・岩・背面に、水面が作る光の網を頂点／フラグメント注入で乗せる
- **光のカーテン** — 水面から差す加算合成の光条
- **水面** — 手続き的な波の法線＋フレネル＋鏡面のきらめき
- **泡** — フレネルで縁が光り、薄膜干渉のような虹色がうっすら出る
- **海藻** — 根元は動かさず先ほどよく揺れる頂点シェーダ。フィルター稼働中は揺れが強まる
- **おさかな** — 体を頂点シェーダでくねらせ、尾びれは同じ式を JS 側で再現して追従
- **音** — WebAudio でその場で合成（環境音・泡・こする音・かちっという音・チャイム）

### 端末対応

- iPhone / iPad の縦・横 どちらにも対応。回転しても遊びは途切れません
- 画面の縦横比に応じてカメラの距離と切り取りを変え、必ず遊べる広さを確保します
  （`src/world/config.js` の `fitHalfHeight()` と `minHalfWidth`）
- 場面ごとにカメラがそっと寄り、作業する場所がいつも画面のまん中に来ます
- HUD の下に作業対象が潜り込まないよう、遊び場を内側マージンで制限しています
  （縦持ちと横持ちで値を入れ替え）
- セーフエリア（ノッチ・ホームバー）を避けて UI を配置
- 実測フレーム時間から解像度を静かに調整します（`Stage.adapt`）

## うごかす

サーバー不要のファイル構成ですが、ES モジュールを使うため
`file://` ではなく HTTP で開いてください。

```bash
npx http-server -p 8123 -c-1 .
# → http://localhost:8123/
```

GitHub Pages などの静的ホスティングにそのまま置けます。
