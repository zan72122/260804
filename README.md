# ぬいぬい！ フェルトタウン

4歳女児向けのWebゲーム・プロトタイプ。
子どもが描く**一本の線**と**最後の一点**をもとに、ゲームがフェルト・糸・ボタン・刺繍の世界観で立派な作品に自動的に仕立てます。子どもの線は完成品の中に「ぬい目・糸・飾り縫い」として必ず残ります。

## 遊び方

1. タイトルをタップして町へ
2. 光っている場所（！マーク）をタップ
3. 毛糸玉から色を1つ選ぶ
4. ボードに一本の線をすーっと描く
5. 最後に一点を「ぽんっ」と置く
6. 線から布が生え、糸が縫われ、ボタンが留まる仕立てアニメーション
7. 住民がお祝いにやってきて、作品は町に残る

2個作るごとに住民のパレードが起こります。作品はブラウザに保存され、次回も町に残っています。同じ場所をもう一度タップすると作り直せます。

## 制作スポット

| スポット | 線のなりゆき | 点のなりゆき |
|---|---|---|
| ふわふわハウス | 屋根の稜線・飾り縫い | ドア（下のほう）／ボタン窓（上のほう） |
| おはなガーデン | 花の茎（花が線に沿って咲く） | いちばん大きなボタン花 |
| りぼんショップ | 看板リボン・レースの縁飾り | ボタン飾り |
| ふわふわブリッジ | 橋のアーチ・板のステッチ | 旗（高い位置）／大ボタン（低い位置） |

線の個性（長さ・丸み・波・尖り）が、大きさ・花びらの数・飾りに反映されます。どんな線でも失敗にはなりません。

## 実行方法

ビルド不要の静的サイトです。

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

iPhone / iPad のSafari・縦横両画面に対応。操作は一本指のタップとスライドのみ。

## 技術

- Canvas 2D のみ（ライブラリ・アセット無し。フェルト質感・キャラクター・UIはすべてプロシージャル描画）
- WebAudio によるオルゴール風BGMと効果音（初回タップで再生開始、♪ボタンでミュート）
- 町の完成品はオフスクリーンキャッシュで描画し、モバイルでも滑らかに動作
- `localStorage` に町の状態を保存

## ファイル構成

```
index.html      エントリ
js/util.js      数学・乱数・線の分析
js/audio.js     効果音・BGM
js/felt.js      フェルト・糸・ボタン・レース描画プリミティブ
js/chars.js     住民キャラクター
js/build.js     線+点 → 作品の自動仕立て（4スポット分のジェネレータ）
js/main.js      シーン管理・入力・町・演出
```
