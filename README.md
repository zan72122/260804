# ピカッ！かくれひびラボ

4歳児向けの蛍光磁粉探傷（MT検査）タッチゲーム。iPhone / iPad のモバイルブラウザ（縦・横）で動作します。

見えない金属のひびに蛍光磁粉が集まり、暗くしてUV-Aライトを当てると黄緑色の線がじわじわ浮かび上がる——その発見の驚きを、一指の操作で最初から最後まで体験できます。

## あそびの流れ

1. 部品（鋼の歯車）が検査台へ届く
2. 布でこすって表面をきれいにする
3. U字ヨークをドラッグして置き、ボタンで磁化（低いブーン音と磁力線）
4. 蛍光磁粉液をそそぐ（粒子が漏洩磁束に引かれて少しずつ列を作る）
5. 暗幕を下へスワイプして閉じる
6. UV-Aライトを動かすと、点々 → 粒子列 → 細線 → 明瞭な蛍光指示へ育つ
7. カメラでパチリと記録
8. ヨークを約90度回して二回目の検査 —— 別方向のひびが現れる
9. 消磁リングに部品を通す（音が弱まり、メーターの針が中央へ）
10. アルバムを見て、もう一度・新しい部品・自由走査を選ぶ

磁化方向と直交するひびだけが指示を作る、消磁で残留磁気が戻る、光は修理ではなく発見のための検査——という因果関係を保っています。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run build      # 型検査 + ビルド (dist/ は静的デプロイ可能)
npm test           # 状態機械・亀裂生成のユニットテスト
npm run e2e        # Chromium で iPhone/iPad 縦横の全工程を自動プレイ + スクリーンショット
```

`npm run e2e` は `--shots-dir DIR` でスクリーンショット出力先を指定できます（既定 `e2e-shots/`）。
URL に `?seed=N` を付けると亀裂配置が固定されます（テスト用）。

## 構成

- `src/statemachine.ts` — 検査工程の状態機械（純関数・テスト対象）
- `src/cracks.ts` — シード付き亀裂生成と漏洩磁束の検出可能性（sin² + ソフト閾値）
- `src/game.ts` — フェーズ進行・一指入力・粒子/発光シミュレーション・描画
- `src/draw.ts` — 全プロップのベクター描画（歯車・ヨーク・暗幕・ロボット等）
- `src/audio.ts` — WebAudio 合成効果音（初回タッチ後に開始）
- `scripts/e2e.mjs` — 実ジェスチャーのみで全工程を通す自動検証
