# き の おひっこし — ツリースペード

4歳児向けのモバイルWebゲーム。
**「おおきな き を、つち ごと スポン と ぬいて、おひっこし する」** 体験を、
実在の重機「ツリースペード（tree spade）」の固有動作でまるごと遊べるようにしたものです。

## あそびかた

1. **あたらしい ばしょ に あなをあける** — 4本の刃を一本ずつ下へ。土のかたまりがスポンと抜けて穴になる。
2. **き のところへ うごかす** — 大きな横スワイプ。ゲート側の刃がひらいて幹を迎え入れる。
3. **刃を 一本ずつ 地中へ** — ズズズズッ。半分ほど入ると地面が断面表示になり、地下で刃が根鉢を包む様子が見える。
4. **木を 根鉢ごと ぬく** — レバーを上へ。抵抗 → 亀裂 → **スポン！** → 自動ドリーアウト。
5. **はこぶ → さっきの穴へ スポッ**
6. **刃を一本ずつ抜いて、水をやる**

操作はすべて指1本（タップ / 大きな上下スワイプ / 左右スワイプ / 長押し）。
時間制限もゲームオーバーもありません。タップだけでも必ず前に進めます。

## モード

- **ストーリー**：上の 1〜6 を一周
- **「ズズズ → スポン」だけ**：刃を入れて木を抜くところだけを何度でも

樹木3種（まるい／ほそながい／はなの木）× 移植先3種（こうえん／ひろば／がっこう、土質も変わる）。

## 動かしかた

静的ファイルだけなので、任意の HTTP サーバで配信するだけです。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

（`file://` では ES modules が読めないのでサーバが必要です。）

## 技術メモ

- Three.js r169 を `vendor/` に同梱（CDN 不要・オフラインで動作）
- テクスチャはすべて Canvas で手続き生成（画像アセットなし）
- 音は WebAudio による手続き合成（音声ファイルなし）
- 地下の断面表示は、カメラ手前側の扇形を `discard` する自作シェーダ（半透明の重ね合わせを避けて破綻をなくす）
- 根鉢・穴は「栓（Plug）」メッシュの抜き差しで表現。物理シミュレーションはしない
- 縦画面／横画面はカメラの自動フレーミング（必要な画枠から距離を逆算）で対応。回転しても進行は保持
- fps が落ちる端末では影・解像度を自動で落とす
