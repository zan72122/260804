# バーをくみたてて、あそぶ

4 歳児が **クレーンゲームの「橋渡し」フィールドを自分で組み立てて、そのまま試遊できる** iPhone / iPad 向けの 3D ブラウザゲームです。

遊びの中心は「二本のバーを置く → 間隔と向きを変える → 景品を置く → 爪で押す → 動きを見る → バーを少し変えてもう一度」の往復です。

## 起動

静的サイトなのでビルドは不要です。任意の静的サーバで `index.html` を配信してください。

```
npm start          # http://localhost:8080/ で配信（開発用の簡易サーバ）
```

そのまま GitHub Pages や Netlify などにディレクトリごと置いても動きます（three.js は `vendor/` に同梱、外部リクエストなし）。

確認用のコマンド:

```
npm run check      # 全モジュールの構文チェック
node tools/sim.js  # 描画なしで物理だけを回し、配置ごとの挙動を一覧表示
```

## 二つのモード

**組立モード** — 画面下の工具台にある二本のバーをドラッグして、左右のソケットへ入れます。近づくと吸着して「カコン」と固定されます。バー端の大きな丸ハンドルをドラッグすると、間隔（狭い / 中 / 広い）と高さ（低い / 高い）が段階的に切り替わります。カプセルか箱の絵をタップすると景品がスタート位置に載り、クレーンの絵をタップすると試遊へ移ります。

**試遊モード** — 爪を一指で横へドラッグして離すと、爪が降りて景品を横から押します。景品は滑り・回り・転がり・傾き、落ちた場合は斜面を滑ってシュートへ入ります。落ちなくても位置は必ず変わります。レンチの絵をタップすると即座に組立へ戻ります。

文字メニュー・数値スライダー・星評価はありません。操作はすべて一指のドラッグとタップです。

## 作れる配置

バー端ごとに 3 段階の間隔 × 2 段階の高さから選べるので、最低でも次の 4 つが作れます。

| 配置 | 作り方 | 起きること |
| --- | --- | --- |
| 狭い平行 | 両端とも内側 | 押しても落ちない。位置だけずれる |
| 広い平行 | 両端とも外側 | ほとんどの押し方で棒のあいだへ落ちる |
| ハの字 | 手前を外側・奥を内側 | 落ちにくいが、押した向きへ大きくずれる |
| ゆるい坂 | 手前を低く・奥を高く | 丸いカプセルが手前へ転がっていく |

「ハの字＋坂」のように混ぜると、転がった先で隙間が広がって落ちる、といった発見が生まれます。

## 前回との比較

数値も文章も出しません。代わりに、

- 前回の景品の軌跡を、薄い光の線で数秒だけ残す
- 動かしたバーだけ、組み替えた直後に一度光る
- カプセルの中の小景品が、大きく転がるほど大きく揺れる
- 箱は角で止まり、カプセルはコロコロ進む

## 技術

- WebGL2 / three.js（`vendor/` に同梱）。ビルド工程なしの ES モジュール
- 物理は自作の簡略剛体（`src/physics.js`）。バーと爪は線分、景品は箱とカプセルの厳密 SDF で接触を作り、逐次インパルスで解く。反発ゼロ・速度上限つきで、同じ操作なら同じ結果になる
- 形状・テクスチャ・効果音はすべてコード生成（外部素材なし）
- 縦横どちらのレイアウトにも対応し、回転しても配置は保持。最後の配置は localStorage に保存

### ファイル

| ファイル | 役割 |
| --- | --- |
| `src/config.js` | 筐体の寸法とソケットの段階 |
| `src/rig.js` | 描画・物理・テストで共有する筐体の形 |
| `src/physics.js` | 玩具物理のソルバ |
| `src/stage.js` | 見た目（筐体・バー・景品・爪） |
| `src/camera.js` | カメラ連鎖 |
| `src/game.js` | モード、入力、状態 |
| `tools/sim.js` | 描画なしの挙動チェック |
