# おへや ぴかぴか — こども内装職人3Dゲーム

4歳児向けのWebGL 3Dゲーム。暗くて古い部屋を、内装職人になってすこしずつリフォームし、
最後に大きなシートを引っぱると部屋全体が明るく美しい空間へ大変身します。

## あそびかた（一指操作・文字なし・失敗なし）

光る輪と手のしるしが、次にさわる場所をいつも教えてくれます。

1. **養生** — ソファ・テーブル・棚・床をタップして白いシートをかける（左右の壁にも自動でシートが下りる）
2. **穴埋め** — 壁の穴をタップするとパテごてが穴をふさぐ
3. **壁紙はがし** — 古い壁紙を下へなでると、めくれて落ちる
4. **色えらび** — 3色のペンキ缶からすきな色をタップ
5. **塗装** — ローラーで壁をなでて塗る（塗り残しへカメラが寄ってくれる）
6. **模様** — 光る場所をタップして花のスタンプ
7. **照明** — 天井をタップして新しいペンダントライトを取り付け
8. **カーテン** — 窓をタップして新しいカーテンを取り付け
9. **大公開** — 大きなシートの端を引っぱると、全部のシートが一斉に飛んでいき、
   新しい壁・床・家具・カーテン・照明の明るい部屋が現れる 🎉

そのあとは自由時間。家具をタップするとよろこびます。

## 技術

- Three.js（vendor同梱）による透視投影・遮蔽・実ジオメトリのWebGL 3D空間
- 近景（脚立・道具・シートの皺）/ 中景（家具・壁）/ 遠景（窓外の木・丘・空、フォグによる空気遠近）
- 実寸ベースの部屋（4.4m × 3.8m × 天井高2.6m）、家具・巾木・窓枠に厚みと接地影
- 布ドレープはレイキャスト高さ場＋斜度制限で計算した実ジオメトリ
- テクスチャは全てCanvasで動的生成（外部アセットなし）
- 効果音・BGMはWebAudioで合成（音声ファイルなし）
- iPhone / iPad の縦・横両対応（画角とカメラ距離を自動調整、シングルポインタのみ受付）

## 実行

```
python3 -m http.server 8000
# → http://localhost:8000/index.html をiPhone/iPadまたはブラウザで開く
```

ES Modulesを使うため、`file://` ではなくHTTPサーバー経由で開いてください。

## 自動試遊

`window.__game.getHint()` が「次の一手」の画面座標を返すため、
Playwright等でタップ/ドラッグを自動化して全フェーズを通しでテストできます。
