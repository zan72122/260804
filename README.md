# シールドマシン トンネルこうじ — TBM Tunnel

4 さいの こどもが iPhone / iPad で あそべる、**シールドマシン（TBM）で トンネルを ほる** 3D ゲームです。
WebGL（Three.js）による本物の透視投影・遮蔽・視差をもつ 3D 空間で動きます。

```
open index.html      # ローカルファイルのまま開けます（外部通信なし）
```

または任意の静的サーバに置くだけで動きます。

---

## このゲームの主役

単なる「穴ほりゲーム」にしないため、**TBM でしか起こらない動作の鎖**を中心に据えています。

1. 巨大カッターヘッドが ゴゴゴゴ…と回りだす
2. 岩盤を削りながら前進する
3. 削った土砂がチャンバへ落ち、**スクリューコンベア**を螺旋で上がり、**ベルトコンベア**で後方へ流れる
4. **推進ジャッキ**が伸びて機体を押し進める（シューは後方のリング前面に残る）
5. 掘った直後の空間に、**セグメントエレクター**が湾曲したコンクリートセグメントを持ち上げる
6. セグメントを一枚ずつ円形にはめ込む（カコン）
7. 最後の**キーセグメント**が楔状に押し込まれ、リングが完成して円全体が光る

### 2 つの視点を使い分ける

TBM は「筒の中の機械」なので、ふつうに撮ると何も見えません。そこでフェーズごとにカメラを切り替えます。

| フェーズ | 視点 | 見せるもの |
|---|---|---|
| 掘進 | **地下断面（カットモデル）** — 手前半分の地山をクリップ面で取り除く | 地層、切羽、カッターヘッド、機内のコンベア、後方に生まれていくトンネル壁 |
| セグメント組立 | **トンネル坑内** — 地山を閉じ、組立中のリングを正面に据える | 円形に組み上がっていくリング、エレクター、キーセグメント |
| リング数達成時 | **引き** — 坑内を後退 | 自分が掘ったトンネルが長くつながっている様子 |

視点の切替は 0.5 秒の暗転でつなぎます。

## そうさ（4 さい向け）

- **スタートレバー** … 上にドラッグ → カッターヘッドが回りだす
- **「ほる」ボタン** … 長押し（画面のどこを押しても掘れます）
- **ジャッキハンドル** … 下にドラッグ → 推進ジャッキが戻る
- **セグメント** … 画面を指でぐるっと回す → 光る場所の近く（±24°）で磁石のように吸着
- **キーセグメント** … 上へスワイプ、または「ぐいっ」ボタン

ゲームオーバー・時間制限・数値入力はありません。
14〜16 秒 なにも操作がないと、自動でそっと手助けします（詰まらないように）。

## 見た目のつくり

- **近景／中景／遠景**：機械のホース・ジャッキ（近）→ 覆工リング・坑壁（中）→ 霧に沈む坑口（遠）
- **空気遠近**：`FogExp2` の濃度をフェーズごとに変える（断面 0.021 / 坑内 0.042 / 引き 0.008）
- **実寸法**：Ø8.7 m 級。セグメント外径 8.32 m・厚さ 0.34 m・幅 1.5 m ＝ 1 ストローク
- **材質応答**：塗装は誘電体、鋼材・摩耗面は金属として別々に設定。汚れ・錆・傷・リベットは
  すべて Canvas2D の手続き型テクスチャ（法線マップ・粗さマップつき）で生成 — 外部アセットなし
- **リング割付**：標準 5 ピース（62°）＋ K セグメント（50°、前端が細い楔）。奇数リングは千鳥組
- **地層**：ストロークごとに 6 種類（やわらかい土／じゃり／かたい岩／きらきら鉱石／ねんど／砂岩）が
  切り替わり、切羽の色・土砂の色・掘進速度・きらめきが変わります

ピンク・虹・星は TBM 本体には使わず、**作業灯・ヘルメット・セグメントの小さなマーク・完成時の
ライトアップ**にとどめています。いちばんのごほうびは「自分が掘った場所が長いトンネルになった」
という視覚変化そのものです。

## 音

すべて WebAudio による合成音で、音声ファイルはありません。

- カッターヘッドの唸り（ブラウンノイズ＋デチューンした低音 2 基）
- 砕石のガラガラ、ベルトの走行音
- 油圧のシュッ、電動機の起動
- 「カコン」（打撃ノイズ＋減衰する胴鳴り 3 倍音）
- リング完成のファンファーレときらめき

iOS の制約のため、最初のタッチで `AudioContext` を resume します。

## ファイル構成

```
index.html          画面
css/style.css       UI（縦横両対応・セーフエリア対応）
dist/tbm.js         バンドル済み（これだけで動きます）
src/
  main.js           起動とループ
  game.js           状態遷移・カメラ・照明・演出
  config.js         寸法とリング割付（すべて実スケール m）
  tbm.js            TBM 本体のモデル（カットモデルとして構築）
  world.js          地山・切羽・素掘り坑・覆工リング・土砂・粉じん
  textures.js       手続き型テクスチャ
  audio.js          WebAudio 合成音
  ui.js             タッチ操作系
tools/              自動試遊・スクリーンショット（Playwright）
```

### ビルド

`src/` を編集したら再バンドルします。

```
npm install
npx esbuild src/main.js --bundle --format=iife --target=es2019 --outfile=dist/tbm.js
```

IIFE 形式なので `file://` からでも読み込めます。

### 自動試遊

```
npx http-server -p 8080 -s .
node tools/shot.mjs land     # 横画面で 1 周ぶんスクリーンショット
node tools/shot.mjs port     # 縦画面
node tools/quick.mjs erect   # 単一シーンだけ素早く確認
```

ヘッドレスは SwiftShader（ソフトウェア描画）で 1 フレームに数秒かかるため、
実時間の `requestAnimationFrame` ではなくシミュレーションを直接進めています。

## 動作環境

WebGL 2 が使えるモダンブラウザ（iOS Safari 15+ / Chrome / Firefox）。
`devicePixelRatio` は 2 で頭打ちにし、完成したリングは 1 メッシュに結合、
カッターディスク・土砂・ローラーはインスタンス描画で、描画コールは 350 前後です。
