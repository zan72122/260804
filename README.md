# ガコン！くるん！レーンのうらがわ工場

4歳の女の子向けの iPhone/iPad ブラウザゲーム。ボウリングでピンが倒れたあと、レーンの奥に隠れているピンセッター機械の中をのぞき、詰まったピンやずれたベルトなどを見つけて指で直し、機械が10本のピンをきれいに並べ直すまでを見届ける「点検・修理ごっこ」です。ワンタップ・ワンドラッグで完結する4つの「看板体験」（扉をパカッと開ける／ベルトをガラガラなぞる／ピンをくるんと起こす／ピンをストンと置く）を中心に構成しています。

対象は未就学児（4歳〜）。iPhone・iPad の Safari を主な対象端末とし、縦画面・横画面の両方に対応します（回転時は構図ごと切り替わります）。外部ランタイム依存なし・演出音は WebAudio によるその場合成・絵はすべて Canvas 上のベクター描画で、進行状況は localStorage に保存されます。

## 起動方法

```bash
npm install
npm run dev
```

`npm run dev` は `vite --host` で起動するため、開発PCと同じLAN内の実機（iPhone/iPad）から `http://<開発PCのホストIP>:5173` にアクセスすれば、そのまま Safari で試遊できます。

## ビルド方法

```bash
npm run build
```

`tsc --noEmit` による型チェックのあと Vite が `dist/` に静的ファイルを出力します。`dist/` の中身はそのまま任意の静的ホスティング（S3、Netlify、GitHub Pages など）に配置できます。

ビルド結果をローカルで確認する場合は次のコマンドを使います。

```bash
npm run preview
```

## 遊び方

1. **投球**: レーンの手前でボールを上へスワイプして投げる。
2. **異常発生**: ピンが倒れたあと、機械から異常音がして停止する。
3. **奥へ**: レーンの奥（機械側）へスワイプ／タップして近づく。
4. **安全ロック**: レバーを下へドラッグして「ガコン」とロックする。
5. **扉を開ける**: 取っ手を横へドラッグして「パカッ」とカバーを開ける。
6. **故障発見**: カットモデル内の怪しい箇所をタップして故障を見つける。
7. **修理**: 故障の種類に応じて、詰まったピンをドラッグで救出したり、ベルトをなぞったり、ローラーを指で回したりして直す。
8. **試運転「くるん」**: カバーを閉め戻すと試運転モードになり、選別機に流れてきたピンをスワイプして向きを直す。
9. **10本ラック**: 直した10本のピンが1本ずつラックに収まっていく。
10. **ストン**: ピンテーブルのレバーを下げ、10本を「ストン」とレーンへ置く。
11. **ボールリターン**: ボールリターンのフラップを上へスワイプして、地下経路からボールを戻す。
12. **完全試運転**: 安全レバーを元に戻すと機械がロック解除され、ストライク〜回収〜くるん〜ラック〜ストン〜ボール返却までを自動で通しで見せてくれる（お祝い演出つき）。
13. **リプレイ**: 「同じ詰まりをもう一度」または「新しい詰まりで」から再プレイを選べる。

操作はすべて指1本で完結します（タップ／スワイプ／ドラッグ／なぞり／円を描くように回す、の5種類のみ）。判定は幼児向けに寛容で、実体より大きめの当たり判定と、近くの操作対象への吸着的な補助を持たせています。

## 実装済みの故障（5種）と機構

`src/sim/faults.ts` で管理される故障は次の5種類です。

| 故障ID | 内容 | 直し方 |
|---|---|---|
| `pin-jam` | 横向きのピンが回収ベルトの曲がり角で詰まる | 詰まったピンをドラッグして救出する |
| `belt-derail` | 回収ベルトがローラーから外れて空転する | ベルトをなぞって溝に戻し、ローラーを円でなぞって動作確認する |
| `guide-shift` | 選別機のガイドがずれる | ガイドをドラッグして直す |
| `rack-gate` | ラックの1か所のゲートが閉じたまま | ゲートをタップ／上スワイプで開ける |
| `flap-stuck` | ボールリターンのフラップが閉じたまま | フラップを上スワイプで開ける |

初回プレイは `pin-jam` と `belt-derail` の固定2種（11本目投球時には `flap-stuck` も追加）、2周目以降は5種からランダムに1つが発生します。

機械側の機構としてピット、回収ベルト、エレベーターホイール、選別機、10本ラック、ピンテーブル、スイープバー、ボールリターンの地下経路を実装しています。また自由遊びモード（`free-play`）では、透明カットモデル表示（X線／xray）、シミュレーション速度切替（0.5x/1x/1.5x）、装飾切替（クラシック／ピンク／虹／花）を試すことができます。

## 主要ファイル構成

- `src/core/` — エンジン基盤（ゲームループ、レイアウト/セーフエリア、カメラ、入力システム、localStorage保存）。編集禁止の共有契約ファイル `types.ts` / `events.ts` / `geometry.ts` を含む。
- `src/sim/` — 機械シミュレーション本体（`MachineState` の唯一の書き手）。ピン/ベルト/選別機/ラック/テーブル/ボールリターンの挙動と5種の故障定義。
- `src/render/machine/` — レーン奥のカットモデル（機械側）の描画。ハウジング、各機構、扉、ロボットなどを描く。
- `src/render/lane/` と `src/render/sprites.ts` — レーン正面シーンの描画とピン/ボール/整備ロボットなどの共通スプライト。
- `src/flow/` — 進行ステートマシン（`FlowStep` の遷移、カメラ演出の指揮、ヒント表示、故障の割り当て、`src/main.ts` からの全モジュール配線）。
- `src/audio/` — WebAudio によるSE合成とセリフ代替チャイム。
- `src/ui/` — 画面座標系のオーバーレイUI（タイトル/リプレイメニュー/HUDなど、絵文字を使わずcanvasで描く大きな絵ボタン）。

アーキテクチャ全体の契約（モジュール間のデータフロー、公開API、Interactable ID一覧など）は `docs/CONTRACTS.md` にまとまっています。実装や仕様の詳細を確認する際はまずこちらを参照してください。

## テスト/検証

型チェックのみを行う場合:

```bash
npm run typecheck
```

一周プレイを自動で再現する Playwright スクリプトが `e2e/playthrough.mjs` にあります。あらかじめ `npm run dev`（または `npm run preview`）で開発サーバーを起動しておき、別ターミナルから実行します。

```bash
PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers \
PW_CHROMIUM_PATH=<Chromiumの実行ファイルパス> \
BASE_URL=http://localhost:5173 \
node e2e/playthrough.mjs
```

一般的な環境では、事前に `npx playwright install chromium` でブラウザをインストールしておけば `PW_CHROMIUM_PATH` は省略でき、Playwright にバンドルされた Chromium が自動的に使われます。

このスクリプトは `window.__game` デバッグフック（`src/main.ts` が公開）経由で `flow.step` / `sim.state` をポーリングしながら、canvas へ合成PointerEventを発行してタップ・スワイプ・ドラッグ・なぞり・円回しの各ジェスチャーを再現し、タイトルからリプレイメニューまでの一周を完走させます。

検証済みの内容:

- iPhone/iPad相当の縦横4種類のビューポートでの一周完走。
- `replay-new` を使った5種類全ての故障パターンでの通しプレイ。
- 連打、逆方向スワイプ、操作途中での指離し、端末回転、バックグラウンド遷移後の復帰、多重タッチ、保存データ破損など、幼児の実操作を想定した想定外入力への耐性（カオステスト）。
