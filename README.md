# するする！しずめて！うみのケーブルせん

4歳の女の子が、iPhone / iPad の縦画面・横画面で遊べる、**海底ケーブル敷設船**のブラウザゲームです。
文字を読まなくても、指一本（タップ・スワイプ・長押し・なぞる）だけで最後まで進めます。
失敗・制限時間・破損・罰・点数はありません。

遊びの中心は、海底ケーブル敷設船にしかない一連の動作です。

1. 地図でふたつの島を選ぶ（通信マークが消えている＝まだつながっていない）
2. 船内の円形ケーブルタンクから、ケーブルの先端を太いガイドへドラッグする
3. ガイドローラー → ドラムエンジン → テンショナー → 船尾シーブへ自動で通る
4. レバー長押し／後方スワイプで、ケーブルが船尾からするすると海へ出る
5. カメラがケーブルを追って海中へ潜る
6. 暗い海底でROVのライトを点ける
7. 太い経路をなぞると、ケーブルプラウが溝を掘る
8. ケーブルが溝へ沈み、砂がふわっと戻って埋設される
9. 地図に戻り、夕暮れの海にケーブルが光り、両方の町に明かりがともる

## いちばん大事にしていること

**「一本のケーブルが、船内から船尾を通り、海面を越え、暗い海底まで連続してつながっている」**

これはカット割りや演出ではなく、実装上も本当に一本です。
`TubeStrand`（`src/world/cable.ts`）は 320 リングの単一メッシュで、その背骨は毎フレーム

- 海底に敷かれた区間
- 海面から海底へ垂れるカテナリー
- 船尾シーブ → テンショナー → ドラム → ガイド → ベルマウス → タンク内

を順につないだ一本のポリラインとして書き換えられます。切れ目はありません。

さらに、各リングは「アンカー側（すでに敷設済みの端）から測った素材座標」 `aM` を持ちます。
アンカーは動かないので、`aM` から描かれるらせんマーカーは、繰り出した長さとまったく同じ速さで
甲板の機械を通って後方へ流れていきます。指を動かすとケーブルが動いて見えるのは、この仕組みです。

## 操作

| 場面 | 操作 |
| --- | --- |
| タイトル | 画面のどこでもタップ |
| 地図 | 島の組み合わせをタップ → 下のアイコンでケーブル色・ROV・かざりを選ぶ → 緑のボタン |
| 船上準備 | 光っているケーブルの先端を、太いローラーへドラッグ（近づけば自動で吸着） |
| 繰り出し | 大きなレバーを長押し、または画面をケーブルの向きへスワイプ |
| 海中 | 自動（スワイプで少し速くなる） |
| ROV | ROVをタップしてライト点灯 → 海底の光る道を指でなぞる |
| 完了 | ↻ でもう一度、🗺 で地図へ |

どの場面でも、しばらく操作がないと自動で少しずつ進みます。行き止まりにはなりません。

## 技術構成

- TypeScript + [three.js](https://threejs.org/) (WebGL) + Vite。静的ファイルのみで配信できます。
- 画像・音声のアセットファイルはゼロです。
  - テクスチャ（塗装、甲板、鋼材、砂、ケーブル外被、法線マップ）は Canvas 2D と値ノイズから生成（`src/core/textures.ts`）。
  - 効果音・環境音はすべて WebAudio の合成音（`src/core/audio.ts`）。最初のタップで unlock します。
- 影マップは使わず、接地は接触シャドウと材質・照明で表現しています（モバイル Safari での安定性優先）。
- ライトの本数はセッション中に変えません（本数が変わるとシェーダが再コンパイルされ、カクつくため）。

### 寸法

ゲーム内の単位は 1 = 1 メートルです。

| もの | 寸法 |
| --- | --- |
| ケーブル敷設船 | 全長 78 m / 幅 16 m / 乾舷 4.0 m / 喫水 5.4 m |
| 円形ケーブルタンク | 直径 12.4 m / 深さ 2.9 m（中央コーン付き） |
| 船尾シーブ | 直径 5.0 m、A フレーム頭部・海面上 9.5 m |
| ケーブル | 直径 約 0.31 m（実物より太め。4歳児が見て追える太さを優先） |
| ROV | 全長 約 2.6 m |
| ケーブルプラウ | 全長 約 8 m / 幅 4 m |
| 水深 | 約 52 m |
| 敷設区間 | 380 m |

### ディレクトリ

```
src/
  core/      textures / audio / input / util / content（3ルート・3地形・2ROV・3ケーブル色・3かざり）
  world/     ship, cable, seabed(+trench), ocean, sky, rov(+plough), islands, life
  game/      map（海図と最後の点灯）, sea（本編）, game（全体進行・カメラ・HUD配線）
  ui/        hud（アイコンのみのDOMオーバーレイ）, styles.css
tools/
  playtest.mjs   iPhone/iPad 相当の4画面で一周操作し、スクリーンショットとコンソールエラーを収集
  shots.mjs      各場面へ直接ジャンプして縦横のスクリーンショットを撮る（画づくりの反復用）
  probe.mjs      海底の掘削・敷設・埋設まわりの診断用
```

## 開発

```bash
npm install
npm run dev        # http://localhost:5173  （--host なので実機からも開けます）
npm run typecheck
npm run build      # tsc --noEmit && vite build -> dist/
npm run preview
npm run playtest   # dist を配信して4画面ぶん自動プレイ（要 build）
```

`playtest` / `shots` は Playwright の Chromium を使います。ブラウザのパスは `CHROMIUM_PATH` で指定できます。

```bash
npm run build
CHROMIUM_PATH=/path/to/chromium node tools/playtest.mjs
CHROMIUM_PATH=/path/to/chromium node tools/shots.mjs        # 全場面
CHROMIUM_PATH=/path/to/chromium node tools/shots.mjs trench # 一場面だけ
```

出力は `playtest/` 以下に入ります（git 管理外）。

## デプロイ

`vite build` の出力（`dist/`）をそのまま静的ホスティングに置くだけです。
`base: './'` なのでサブディレクトリ配信でも動きます。サーバ側の処理は不要です。
