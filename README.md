# しばって！そめて！ひらくとびっくり！あいぞめラボ

4 歳の子が iPhone / iPad の**たて画面でも よこ画面でも**あそべる、**絞り染めと藍染**の
ブラウザゲームです。WebGL（three.js）による実際の 3D 空間で動きます。

**これは塗り絵ではありません。** 色を選んで塗るのではなく、

> 白い布を **おって** → 糸や板で **しばって** → 藍甕に **しずめて** →
> 空気に触れて **みどりから青へ変わって** → **ほどいて** → **ひらいて** →
> はじめて模様が現れる

という、絞り染めにしかない**工程の鎖**そのものが遊びの中身です。

```
open index.html          # ビルド不要。静的ファイルだけで動きます
python3 -m http.server   # file:// では ES モジュールが読めないので簡易サーバ推奨
```

---

## 2 つのシグネチャー

**1. 引き上げた直後の色が、空気に触れて連続的に変わる。**
藍のロイコ体は染液中では無色〜黄色で、空気に触れて酸化してはじめて青くなります。
本作では布を引き上げた瞬間の酸化度を 0 に戻し、指ではらう（＝風を送る）たびに

`きみどり → みどり → あおみどり → あお → ふかい あいいろ`

へと **1 本の連続量として** 変化させます。段階の切り替えではありません。
フラグメントシェーダの `indigoRamp()` が 5 色を補間し、布の場所ごとに
空気の当たりやすさ（ふち・ノイズ）で酸化がまだらに進むので、
青い部分がじわじわ広がって合流します。

**2. ほどいて開くまで、模様は誰にも見えない。**
束は本当に折りたたまれた 3D ジオメトリなので、内側の面は**遮蔽されていて見えません**。
「完成図に切り替える」処理はどこにもありません。折り目が 1 本ずつ開いていく
`foldT: 1 → 0` の連続変形の結果として、白い模様が順に現れます。

## 模様はどこから来るのか

固定画像を選んでいるのではありません。**折り位置と縛り位置から毎回生成**しています。

```
      布の座標 (u,v)
          │  折りエンジン（鏡映の合成）
          ▼
   たたんだ束の中の位置 (a, b)   ← 糸と板はこの空間に置かれる
          │  防染の計算
          ▼
   染まらない量 resist(u,v)     ← 384²/512² のテクスチャに焼く
```

折りは「片側を折り線で反対側へ倒す」鏡映の列です（紙折りと同じ規則で層番号も反転します）。
束の中の**1 か所**を縛ると、その 1 か所が折りの対称性のぶんだけ
展開後の布に**繰り返し**現れます。三角折りなら 8 回、蛇腹なら折り数だけ。
これが絞り染めが左右対称・万華鏡状になる理由そのもので、
本作もまったく同じ計算で模様を作っています。

さらに、

* **層の深さ (burial)** — 束の奥に埋まった層ほど染液が届きにくく、防染が強く出ます
* **毛細管現象** — 防染の境界をノイズで揺らし、輪郭を有機的にします
* **巻き上げの寄り** — 締めたときに布が縮むぶん、すじが波打ちます

を重ねているので、**同じ折り方・同じ縛り数でも毎回すこしずつ違う布**になります。

### 折り 4 方式

| 方式 | 束のかたち | 縛ると出る模様 |
|---|---|---|
| 蛇腹折り | 細長い帯 | 平行なしま・格子 |
| 三角折り | 小さな三角 | 8 回対称の星・雪花 |
| 中央つまみ | 放射状のひだ円錐 | 同心円・くもの巣 |
| 巻き上げ | らせん状の筒 | ななめのすじ（嵐絞り） |

### 縛り 2 方式

* **糸縛り** — 指で**ぐるぐる円を描く**と、半周ごとに 1 巻き。同じ場所を重ねると太く強くなります
* **板締め** — まる／しかく／さんかく／ほし／ろっかく の板を束にタップで置き、輪ゴムで締めます

### 生まれる模様（17 種類）

しま／こまかい しま／こうし／いちまつ／ほしの わ／せっか／やまなみ／まどわく／はなび／
おおきな まる／なみの わ／くもの す／たいよう／あらしの すじ／たけの ふし／
なみがしら／まぼろし

## 遊びかた（2〜4 分）

| | 工程 | 操作 |
|---|---|---|
| 1 | ぬのを おる | 布を**なぞる**。指の向きから折り方を推定して大きく寄せます。もう一度なぞると さらに折れます |
| 2 | いとで しばる | 指で**ぐるぐる**回して糸を巻く／板をえらんで**タップ** |
| 3 | あいがめに しずめる | 画面を**ながおし**すると竿ごと沈む。指を横に動かすと液中でやさしく揺らせます |
| 4 | かぜに あてる | **さっとはらう**と風が起き、みどりから青へ変わっていきます |
| — | 重ね染め | 何度でも。回数の正解はありません |
| 5 | いとを ほどく | 糸や板を**はらう** |
| 6 | そっと ひらく | **ドラッグ**するぶんだけ開き、模様が少しずつ現れます |
| 7 | みずで すすぐ | 水の中で指を**横に動かす** |
| 8 | かぜに ほす | 物干しに掛かった布が風で大きく揺れます |

操作は **タップ・ドラッグ・円運動・ながおし・スワイプ** の 5 つだけ。
**点数・制限時間・失敗・罰はありません。** どんな操作をしても美しい布になります。

## たて画面 / よこ画面

* **たて** — 甕と布の上下動が画面の縦に乗るよう、低い視点で寄ります
* **よこ** — 布を大きく広げ、模様の全体像が見えるよう上から広く構えます
* **回転しても、折り方・縛り位置・染色状態・工程はそのまま保たれます**（見え方だけ切り替わります）

カメラは「注視点と収める半径」から距離を毎フレーム計算するので、
どんな画面比でも被写体が切れません。

## ビジュアル

* **CSS 疑似 3D ではありません。** 透視投影・遮蔽・視差・実ジオメトリを持つ WebGL 空間です
* **近景**（作業台と布）／**中景**（藍甕・すすぎ桶・踏み台・手桶）／**遠景**（土壁・窓・干し布）を
  シルエット・材質・照明・空気遠近（フォグ）で分離
* 寸法は実物基準 — 藍甕は口径 0.9m・高さ 0.66m、作業台は高さ 0.34m、布は一辺 0.86m
* 布は**表・裏・小口**を持つ実ジオメトリ。折ると層と層のあいだに隙間ができ、重なりが見えます
* 糸は本当に布を**へこませ**、板は本当に束を**つぶします**
* 藍液は専用シェーダ — 波紋、かき混ぜたときの白いすじ、発酵の泡（藍の華）の金属光沢
* 濡れているあいだは色が濃く、つやが出て、しずくが落ちます。乾くと軽くなります
* 乾燥ステージだけ Verlet 布シミュレーションに切り替わり、風で大きくはためきます

ピンク・虹・星は工房の飾り、輪ゴム、模様のバリエーションに使っていますが、
主役はあくまで**藍と白の対比**です。

## モバイル Safari 対策

* ビルド不要の素の ES モジュール（import map も使いません）
* `touch-action: none` / `overscroll-behavior: none` / 引っぱり更新とピンチ拡大の抑止
* `viewport-fit=cover` + `env(safe-area-inset-*)` でノッチとホームバーを回避
* AudioContext は最初のタップまで作りません（合成音のみ、外部ファイルなし）
* devicePixelRatio は 2 で頭打ち。**フレームレートが落ちたら自動で解像度を下げます**
* `pointercancel` / タブ切り替え / 途中で指を離す → かならず後始末が走ります
* 工程アニメにはステージの印がついていて、**連打で先へ進んでも前の演出が割り込みません**

## 検証

```
node tools/playtest.mjs [--shots]   # 自動試遊（Playwright + Chromium）
node tools/dbg.mjs [--land] [--fam accordion|triangle|pinch|roll]   # 各工程のスクリーンショット
```

`playtest.mjs` が確認すること:

* たて画面（390×844）とよこ画面（844×390）でのフルプレイ通し
* 引き上げ直後は酸化しておらず、はらうたびに連続的に濃くなること
* 重ね染めで甕に戻れること
* **ひらく前は模様が出ておらず**、開くほど段階的に現れること
* 画面回転で工程・折り方・縛り・折りたたみ状態が保たれること
* 連打 / 途中で指を離す / タブ切り替えで壊れないこと
* 再プレイで完全に初期化されること
* iPad たて（820×1180）での起動
* 折り 4 方式 × 縛り 2 方式から 12 種類以上の模様が生まれること
* 縛り位置を変えると白の出方が変わること

ヘッドレスは SwiftShader（ソフトウェア描画）なので実機よりずっと遅く、
テストは待ち時間を固定せず状態が変わるまでポーリングします。

## ファイル構成

```

styles.css          HUD（ひらがな中心・押せるものは大きく）
vendor/             three.js r160（npm から取得して同梱）
src/
  folds.js          折りエンジン。折り＝鏡映の列。footprint (a,b) の定義   ★心臓部
  resist.js         糸・板 → 防染マップの生成、模様の見立て               ★心臓部
  cloth.js          布の実ジオメトリ、藍と酸化のシェーダ、Verlet 乾燥
  scene.js          工房（近景・中景・遠景）、藍甕と液面シェーダ、照明
  fx.js             糸・板・泡・しずく・風・藍のにごり
  input.js          タップ／ドラッグ／円運動／ながおし／スワイプ
  ui.js             DOM の HUD
  game.js           工程の状態機械とカメラ
  main.js           起動・ループ・画面回転
tools/              自動試遊とスクリーンショット
```
