# ベルベット ケーキやさん 🍰

4歳から遊べる、冷凍アントルメ（entremet）にベルベットスプレーを吹き付けるモバイルWebゲームです。

つるつるに凍ったケーキに、パティシエのスプレーガンでココアバターの微細な霧を吹き付けると、
吹いた軌跡だけがベルベット状のマットな質感に変わっていきます。
ターンテーブルを回して全面をふわふわに覆うと、最後に側光が当たり、
ベルベットの柔らかな質感が浮かび上がります。

## あそびかた

- **ゆびでケーキをなぞる** → シューッとスプレーが出て、なぞったところがベルベットになる
- **左右の回転ボタン / お皿を横にスワイプ** → ターンテーブルが回る
- **右の色ボタン** → チョコ・いちご・ピスタチオ・マンゴーの色をえらべる
- 全部ぬれたら、よこからの光でベルベットのけばだちが見えるフィナーレ！

## 動かしかた

静的ファイルのみで動きます。サーバーに置くか、ローカルで:

```
python3 -m http.server 8000
# → http://localhost:8000/ をiPhone/iPad/PCブラウザで開く
```

iOS 16.4+ / Android Chrome / デスクトップブラウザ対応（WebGL2 + importmap使用）。

## 技術

- Three.js（`lib/` にベンダリング済み、ビルド不要）
- ケーキはLatheGeometry + UVペイント。スプレー痕はCanvasテクスチャに堆積し、
  カスタムシェーダー（onBeforeCompile）で glossy glaze → velvet matte へ
  roughness / clearcoat / sheen / micro-normal を局所変化させています
- スプレー液滴はGPUポイントパーティクル、音はWebAudioで手続き生成
