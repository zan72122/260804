# かなざわ きんぱく — Kanazawa Gold Leaf

4歳児向けの、金沢の金箔づくりをなぞる iPhone / iPad 用ブラウザゲーム。
金色に「塗る」のではなく、**金箔という物体そのものの振る舞い**を触って遊ぶ。

```
トントン → ぺろん → ふわっ → ぺたっ → キラッ
たたく    ひらく    ゆれる    のせる    ひかる
```

失敗も、制限時間も、点数も、読ませる文章もない。終わったら素地が変わって、また最初から。

## 遊びかた

触る操作は5つ。その間に、職人の手が動く工程が挟まる。

| 動作 | 操作 | 起きること |
| --- | --- | --- |
| **トントン** | 画面をタップ ×3 | 槌が落ちる。**打紙の下で金が広がっていくのが紙越しに透けて見える**。束は一打ちごとに少し回る |
| **ぺろん** | 上へスワイプ | 打紙が蝶番のように開き、**縁のちぎれた**極薄の箔が現れる |
| **ふわっ** | 左右になでる | 指の起こした気流で箔に波が走り、端がめくれる |
| （箔切り） | 見ている | 竹箸で箔を革盤へ移し、**竹の枠で109mm角に裁つ**。余った縁が箔くずになって舞う |
| （押し漆） | 見ている | 毛棒が下地に漆を引き、表面が**濡れて粘る**状態になる |
| **ぺたっ** | 大きくドラッグ | 箔箸で箔を運び、漆の上へ。**触れた点から外へ吸い付いていく** |
| **キラッ** | なでる | 皺が伸び、**縁からはみ出した箔足が払われ**、表面を反射がひと息に走る |

どの操作も大まかで通る。方向を間違えても、狙いが外れても、進む。

### 金がたどる道のり

画面の中で金は本当に姿を変える。数値はすべて実際の工程に合わせてある。

| 段階 | 大きさ | 厚さ | 見え方 |
| --- | --- | --- | --- |
| 小間（上澄を12枚ほどに切ったもの） | 55 mm角 | 3/1000 mm | 鈍い、不透明、硬い |
| 一打ち | 79 mm角 | ↓ | 紙の下で広がりはじめる |
| 二打ち | 103 mm角 | ↓ | 縁の線が紙越しに動く |
| 打ち上がり | 128 mm角・不定形 | 1/10000 mm | 透ける、青緑の透過光、縁はちぎれたまま |
| 箔切り後 | **109 mm角**（三寸六分） | 1/10000 mm | 四角い、金沢四号 |

## 金箔の表現

普通の黄色い紙にしないために、箔だけは専用のシミュレーションと専用のシェーダーを持つ。

- **厚みゼロの実ジオメトリ** — 45×45 の膜メッシュ。金箔の実厚は約 0.1 µm（1万分の1 mm）で、
  押し出す厚みなど存在しない。だから板ではなく膜として解いている。
- **減衰波動方程式**（`src/scene/leaf.js`）— 1/240 秒の固定サブステップで解く。
  波が 109 mm の箔を渡り切るのに必要な波速は、1 フレーム刻みでは発散するため。
- **自分から浮く端** — 静止形状そのものが、縁と角でわずかに持ち上がっている。
- **皺の記憶** — 頂点ごとの皺の場が残り、毛棒でなでた場所だけ消えていく。皺は反射を曲げ、
  消えると反射が通る。これが「キラッ」の正体。
- **異方性の光沢** — 打たれた金属なので、ハイライトは点ではなく打ち目に沿って流れる。
- **緑の透過光** — 本物の金箔は透かすと青緑に見える。裏面と斜めの縁でその色が出る。
- **視線角度で変わる不透明度** — 正面からはほぼ不透明、浅い角度では向こうが透ける。
- **厚さで変わる材質** — 小間（3/1000mm）は鈍く不透明で拡散が強い。打たれて 1/10000mm に
  なると鏡のように締まり、透過光が出る。同じ物体の同じシェーダーが、厚さ一つで別物になる。
- **縁は切られるまで直線にならない** — 打ち上がりの境界はノイズで、竹の枠が入って初めて
  109mm の直線になる。

## 物体は互いを通り抜けない

金箔の各頂点は、シミュレーションの後に**ワールド空間で**拘束される。

- **下** — 作業台、革盤、打紙束、そして下地のシルエット（皿・椀・まりそれぞれの
  「その半径での固体の上端」）。`groundHeight()` と `baseClearance()`。
- **上** — 打紙の間にある間は、その紙の裏面が天井になる。`PeelSheet.heightAt()`。
- **運ぶとき** — 束の上を通るときは束の高さより上を通り、後端が抜けてから降りる。

## 画面

- **遠景** 障子の面光源、梁と柱のシルエット、藍の暖簾。空気遠近（指数フォグ）で沈む。
- **中景** 打紙の在庫、膠と灰汁の壺、竹道具の筒。
- **近景** 作業台、革板、打紙束、槌、箔箸、毛棒、真綿、漆の下地。

CSS の疑似3Dではなく、透視投影・遮蔽・視差・実ジオメトリを持つ WebGL2 空間。
影は指向性シャドウマップ、描画は HDR → ブルーム → ACES トーンマップ。
寸法はすべて実寸（メートル）で、作業台の天板が y = 0。

| もの | 寸法 |
| --- | --- |
| 金箔（金沢四号相当） | 109 mm 角 |
| 打紙 | 158 mm 角 |
| 革板 | 322 mm 角 |
| 作業台 | 1420 × 780 mm、天板厚 45 mm |
| 漆の小皿 | 直径 156 mm |

## 工程の下敷きにした事実

幼児向けに工程数は大胆に畳んでいるが、**残した工程の中身**は実際の金沢箔に合わせてある。

**製造は三つに分かれる。** 純金に微量の銀と銅を加えた合金を打ち延ばして厚さ1000分の1mmの
**上澄**に仕上げる**澄工程**（担当は**澄屋**）、上澄と箔打紙を交互に重ねて1万分の1mmまで
打ち延ばす**箔工程**（担当は**箔屋**）、そして**紙仕込み工程**。
澄工程はさらに5段階（小兵6cm角 → 荒金12cm → 小重20cm → 大重 → 化粧打ち → 上澄）。

**箔工程の中身。** 上澄を12枚ほどの大きさに切ったものが**小間**。これを一枚ずつ箔打紙に
挟む作業が**引き入れ**で、1800枚ほどを束にして打つ。小間打ちが終わると**まま紙**に移し替え、
10〜15分打っては冷まし、また打つ。打ち続けると紙の中の温度が上がって金が紙に貼り付くからで、
これを繰り返して1万分の1mmに至る。**約2gの金が畳一畳分に広がる。**

**打ち上がってから。** 箔を**広物帳**に移す**抜き仕事**、鹿皮を張った**革盤**へ**竹箸**で移し、
四角い竹製の刀＝**枠**で規定の大きさに裁つ**箔切り**。竹と**天狗爪**が使われるのは
**静電気が起きにくい**から。裁った箔は**箔合紙**（三椏製）に一枚ずつ重ね、100枚を一包とする。
規格は**三寸六分＝109mm角**（金沢四号）。

**箔打紙。** 手漉きの**雁皮紙**を水・**藁の灰汁**・**柿渋**・**卵**に浸し、**約半年**かけて仕込む。
何年も叩かれ続けた紙はさらに滑らかになり、使い古しは「ふるや紙」＝あぶらとり紙になる。
ゲーム中の打紙が茶褐色なのはこの仕込みのため。

**押し（貼り）。** 漆を接着剤に、**最適な粘り**になった瞬間を捉えて竹箸で箔を配し、
**真綿**で押さえて定着させる。はみ出した箔＝**箔足**は柔らかい刷毛で払う。
押さえる力加減で艶の強さが変わる。

## 動かす

ES モジュールなので、ファイルを直接開くのではなく HTTP で配信する。

```sh
python3 -m http.server 8123
# iPhone / iPad の Safari で http://<PC の IP>:8123/ を開く
```

WebGL2 が必要（iOS 15 以降の Safari、Android Chrome、デスクトップ各種）。
縦横どちらの向きでも遊べる。画面の縦横比に応じてカメラの引きが変わり、
縦持ちでは上半分が工房の奥行きに使われる。

## 検証

`tools/shoot.mjs` が Playwright で実機相当の画面サイズを開き、5つの動作を実際に操作して
各局面のスクリーンショットを撮り、状態を出力する。

```sh
node tools/shoot.mjs iphone   390 844 1     # iPhone 14/15 縦
node tools/shoot.mjs iphone-l 844 390 1     # 同 横
node tools/shoot.mjs ipad     820 1180 1    # iPad Air 縦
node tools/shoot.mjs ipad-l   1180 820 1    # 同 横
```

## 構成

```
index.html            画面と、大きな文字ひとつだけのオーバーレイ
src/main.js           5つの動作の状態機械、カメラ、進行
src/ui.js             オノマトペと指の動きのアイコン
src/core/renderer.js  影 → HDR → ブルーム → 合成
src/core/shaders.js   材質シェーダー、金箔シェーダー、ポスト
src/core/geometry.js  箱・円柱・回転体・格子の生成
src/core/audio.js     5つの音をその場で合成（音声ファイルなし）
src/core/input.js     タップ／スワイプ／ドラッグ／なで
src/scene/atelier.js  工房（遠景・中景・近景）
src/scene/props.js    道具と下地
src/scene/leaf.js     金箔の膜シミュレーション（広がり・薄さ・裁ち・貫通拘束）
src/scene/peel.js     ぺろんと開く打紙（天井としての高さ問い合わせも）
src/scene/flakes.js   箔切りの箔くずと、払われた箔足
```

`tools/frames.mjs` は各局面を1枚ずつ撮る。構図と工程の確認はこちらが速い。

```sh
node tools/frames.mjs stage 500 720
```
