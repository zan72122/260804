# ❄️ きらきら ひょうぞうまつり

4歳のお子さま向けの、雪像・氷像づくり3Dゲームです。
巨大な雪のかたまりを積んで、削って、磨いて、透明な氷を組んで、中に照明を入れて——
夜になったらスイッチON！ カーテンが落ちて、氷のお城やペンギンが青・紫・虹色に輝きます。

## あそびかた

1. **えらぶ** — 🏰おしろ か 🐧ぺんぎん をタッチ
2. **つむ** — ボタンをおして巨大な雪のかたまりを4つ積む
3. **けずる** — 指でなぞってゴシゴシ。かたまりから形が出てくる（完成面に当たるとカチンと音がします）
4. **みがく** — ブラシでやさしくなでて、表面をつるつるに
5. **こおり** — 光る場所をタッチして、透明な氷のパーツ（星・とんがり・王冠…）をはめる
6. **あかり** — 像の中の光る玉をタッチして、照明を仕込む
7. **よる → スイッチ！** — 夜になったら大きな赤いスイッチをON。
   雪のカーテンが落ちて、氷の中を光が走り、雪が舞い、花火が上がるお祭りのクライマックス！

制作中は雪のカーテンと霧が会場を囲んでいて、完成までまわりからは見えません。

- 画面下の ↺ ↻ ボタンでまわりから見られます（ホイール/ピンチでズーム）
- 縦画面・横画面どちらでも遊べます
- まちがえても大丈夫：完成する形より内側は削れません

## 起動方法

ローカルサーバーで配信して開くだけです（ビルド不要・外部通信なし）。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

タブレット/スマホでも動きます。音は最初のタッチで有効になります。

## 技術メモ

- **WebGL (Three.js r160 同梱)** — 透視投影・シャドウマップ・霧・実ジオメトリによる本物の3D空間
- **ボクセル彫刻** — 約1.6万個のインスタンスボクセルをグリッドDDAレイキャストで削る。
  ターゲット形状はSDF（符号付き距離場）で定義され、「余分」「表皮」「芯」に分類される
- **昼→夕→夜の遷移** — 空シェーダー（星・月）、太陽/月光、空気遠近（霧＋遠景の山の色）
- **フィナーレ** — カーテンはクロスシェーダーで波打ちながら落下。氷の発光はインスタンス色を
  毎フレーム更新し、青→紫→虹のパレットと像を駆け上がる光の帯を表現。内部のポイントライトが
  会場の雪面を照らす
- **音** — 効果音・オルゴール音楽ともWebAudioでリアルタイム合成（音声ファイルなし）
- **試遊** — Playwright + ヘッドレスChromiumで全フェーズを自動プレイし検証
  （`window.__game` デバッグAPI）
