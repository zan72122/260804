# GAME_VISION — レールけずりでんしゃ (Rail Grinder Night Work)

## 体験の核

4歳児(文字が読めない)が iPhone / iPad の Safari で遊ぶ、レール削正車の触覚玩具。
点数もゲームオーバーもない。魅力は「因果が体に伝わる」こと:

1. **サーッ** — レーザースキャンで、見えなかったレールの波状摩耗が光る波として現れる
2. **ガコン** — 大レバーを下へスワイプ → 削正ユニットが段階的に降り、重いロック音で接触する
3. **シャーッ** — 指で削正車を進めると火花が後方へ流れ、指の速さ・車速・レールの凸凹に応じて火花と削れ方が連続的に変わる
4. **スーッ** — 試験列車が「ガタガタ」だった線路を静かに滑り、車内のぬいぐるみが揺れなくなる

「自分がレールを直した」という因果が、形(波→平ら)、音(ガタガタ→スーッ)、光(火花→静かな夜)の三重で伝わる。

## プレイループ(2〜4分)

入場 → 作業前スキャン → ユニット準備(吸着ドッキング) → ガコン(レバー) →
シャーッ(削正走行) → 作業後スキャン(前後比較) → 試験走行 → 再プレイ選択(同じ線路 / 別の波形)

## 非目標(絶対に足さない)

- 制限時間・ゲームオーバー・採点・星・順位
- 通貨・資材購入・経営・アンロック・追加ステージ(垂直スライス外)
- 細かな数値設定、必須ピンチ/マルチタッチ、長文チュートリアル
- 赤いエラー表示、誤操作による線路破壊
- バックエンド、ログイン、広告、分析、課金

## トーン

上質な鉄道模型と絵本の中間の 2.5D 夜景。銀のレール、黄色い作業灯、
橙→白の火花、青白いレーザー、細かな水ミスト。全画面の高速点滅は禁止。
