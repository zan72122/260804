# ACCEPTANCE — 実行中のゲームで確認できる完成条件

すべて実行中のゲーム（http://127.0.0.1:8000/）で確認する。
自動確認は `node qa/drive.mjs` が同項目を検証し docs/qa/shots/ に証跡を残す。

## 対象環境

- iPhone 相当 390×844（縦）/ 844×390（横）
- iPad 相当 820×1180（縦）/ 1180×820（横）

## 条件

### シミュレーション
- [ ] 繊維投入後、粒子が水中に実際に分散して漂う（静止画差し替えでない）
- [ ] 指のなぞりに近くの繊維が**遅れて**追従し、指を離した後も少し流れ続ける
- [ ] レバー操作直後に水が消えない：水位低下→流速上昇→方向転換→欠損へ集合→最後の水膜、の時間変化がある
- [ ] 吸引中、繊維が**離れた位置から**欠損へ移動する（紙面全体へ均一に貼り付くだけの挙動ではない）
- [ ] 穴・破れの充填率が連続的に増える（`__qa.state().fill` が 0→1 を漸進）
- [ ] 元の紙がある場所より欠損部の方が繊維を強く引く（透水性マスク）

### 意味的忠実さ
- [ ] 修復後も、損傷で失われた図版の線・絵は復元されない
- [ ] 新しい繊維は無地で、風合い（色）の違いとして完成紙に残る
- [ ] 湿紙は支持布と一緒でないと持ち上がらない（布なしは揺れのみ、失敗にはならない）

### 子どもの操作
- [ ] 全工程がタップ／一方向スワイプ／太いなぞり／寛容なドラッグのみで完了する
- [ ] 連打・逆方向スワイプ・途中離し・2本目の指で進行不能にならない
- [ ] 3〜5秒無操作で文字なしの視覚誘導（ハンド・輪・揺れ）が出る
- [ ] 文章・数値・制限時間・ゲームオーバー・点数・星評価が存在しない

### 画面・周回
- [ ] 4画面サイズ全てで一周（本→修復→本へ戻す→メニュー）できる
- [ ] 横画面では水槽断面で水が下へ抜ける様子が見える
- [ ] 回転しても繊維数・水位・充填率・工程が保持される
- [ ] 一周後、メニューのカード1タップ（＋本のページ引き出し）＝2操作以内で再開できる
- [ ] 自由実験モードは修復工程と分離され、いつでも戻れる
