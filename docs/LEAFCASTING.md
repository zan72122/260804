# LEAFCASTING — 実工程とゲーム上の省略

## 実際のリーフキャスティング（漉きはめ）

紙資料の欠損部（虫損・破れ・穴）を、水中に分散させた紙繊維で充填する修復技法。

1. 資料の調査（透過光で損傷範囲・紙厚を確認）
2. 損傷紙を透水性の支持面（メッシュ／サクションテーブル）に置く
3. 紙繊維（コウゾ等）を水に分散させたスラリーを注ぐ
4. 下から吸引（または自然濾水）。**元の紙がある場所は水を通しにくく、
   紙のない欠損部で水が下へ抜ける**
5. その水流が繊維を欠損部へ運び、堆積して新しい紙層になる。
   欠損が埋まるほど流れが弱まり、堆積は自然に平衡する（自己調整性）
6. 湿紙は支持材（不織布など）ごと慎重に持ち上げる（カウチング）
7. フェルトに挟んで加圧脱水、プレス下で乾燥
8. 乾燥後、必要ならサイジング・裁ち・再製本

リーフキャスティングが直すのは**紙の支持体**。失われたインク・絵は戻らない。

## ゲームでの対応と省略

| 実工程 | ゲーム | 省略・変形 |
|---|---|---|
| 透過光調査 | ライトテーブルでレンズを動かし損傷を見つける | 記録・計測は省略 |
| メッシュに置く | ドラッグで水槽内メッシュへ | 湿し・フラットニング省略 |
| スラリー投入・分散 | 鉢タップ＋指で撹拌 | 濃度計算・叩解は省略 |
| 吸引 | レバー下スワイプ。透水性マスクに基づき欠損へ繊維が集まる | 完全な流体計算はしない（欠損指向の流れ場+粒子で近似） |
| 自己調整性 | 充填が進むと透水性が下がり流れが弱まる（permAt が堆積で減衰） | — |
| カウチング | 支持布を重ね布ごと持ち上げ | — |
| 加圧・乾燥 | プレス→送風スワイプで乾燥 | 乾燥日数は数秒に圧縮 |
| 再製本 | ページを本の綴じ位置へ戻す | 綴じ直し工程は象徴化 |

## 守っている禁則

- 失われた文字・線・絵は再生成しない（図版レイヤは損傷形状でパンチ済み、
  堆積は無地のパルプのみ）
- 完成画像への瞬間差し替えをしない（粒子堆積→損傷単位の膜閉じ）
- 余った繊維は欠損充填後に薄いベールとして全面へ僅かに沈着
  （実技でも生じる現象。主動作は常に欠損への集中）

## ご褒美の表現

修復の成果は「破れずにめくれる」「本へ戻る」「元の絵を安全に眺められる」
「逆光で新旧繊維の透過差が美しい」で表現する。絵の補完はしない。
