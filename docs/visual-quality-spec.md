# ビジュアル品質仕様 v1（Wave3 品質改修の合格条件）

方針（ユーザー決定）: 対象 = 新レシピ2種＋共通照明 / 質感 = 本物のお菓子志向（色は子ども向けにかわいく）/
品質最優先（iPhone 12以降・iPadで60fps目標、負荷増は許容。pixelRatio上限2は維持）。

参考にすべき実物: 本物のベイクドアラスカ（絞り目の峰が飴色に焦げる）、クレームブリュレ、
パティスリーのミラーグレーズケーキ（グラサージュ・ミロワール）の写真。
「単色のツルツルした卵型・球」は0点。以下の合格条件を満たすまで完成と見なさない。

## 共通の禁止事項
- 単色・無地の大きな面（必ずテクスチャ/ノイズ/グラデ/ラフネス変化を入れる）
- specular一点だけのプラスチック玉
- 接地感のない浮いたオブジェクト（接地部に暗部/接触影を必ず作る）

## A. あぶってパリン！（brulee）合格条件

### メレンゲドーム（最重要）
- [ ] 表面が「絞り出した山」に見える: らせん状に積んだ太い絞りコイル（例: 半径を減らしながら
      3〜4周のチューブ+頂点の巻きツノ）または重なり合うブロブ群で、輪郭がボコボコと波打つこと。
      シルエットが卵型の滑面なら不合格。
- [ ] 微細な表面凹凸（ノイズ変位 or バンプ）+ ラフネス0.5前後のマット質感
- [ ] フレネルによる薄暖色の裏透かし（フェイクSSS）で「白い泡」の柔らかさ
### 炙り（トーチ）
- [ ] 焼き色が不均一: 白→クリーム→黄金→琥珀→焦げ茶の段階LUT。スタンプごとに強弱ムラ
- [ ] 凸部（絞りの峰）が先に焦げる: 事前ベイクした高さ/曲率マップで焼けやすさを重み付け
- [ ] 焼けた領域だけ艶が上がる（カラメル化＝roughness低下をペイントで連動）
- [ ] 濃い焦げスポット（ランダムな小斑点）が最終盤に出る
- [ ] 炎はコア(青白)+外炎(橙)の2層+熱による陽炎的ゆらぎ、なぞり跡に薄い煙
### カラメルの飴ガラス
- [ ] 透明感のある琥珀（transmission or 高clearcoat+低opacity多層）で、下のメレンゲが透ける
- [ ] 縁に厚み・垂れ（しずく状の垂れ下がり）が数カ所
### パリン割れ
- [ ] タップ1: 星状ヒビ線が「見える」（濃色の線+わずかな段差/法線変化）+破片が僅かに浮く
- [ ] タップ2: ヒビが広がり破片間に隙間、内側から冷気が漏れ始める
- [ ] タップ3: 破片（琥珀の透明板、厚みあり）が回転しながら飛散して皿に落ちて残る。
      メレンゲが割れ開き、中のアイス3玉+カスタードが冷気ミストの中に現れる
### その他
- [ ] アイス玉: ディッシャーの削り縁（巻き上がったエッジ）+ざらつきバンプ+接地部に薄い溶けだまり。
      バニラは黒い種斑点、ベリーはマーブル、メロンは薄縞
- [ ] スポンジ台: 気泡クラム質感+焼き色の縁
- [ ] 器: 本物のブリュレ用ラメキン（白磁・縦フルート溝・縁ロール）。皿on皿の二重見えを解消
- [ ] カスタード: 艶のある表面+バニラ斑点+縁のメニスカス、注ぎ中はゆらぎ

## B. かがみのケーキ（glaze）合格条件
- [ ] グレーズ流下: 進行前線に「厚みの盛り上がり」があり、とろりと進む（アルファカットだけで
      パキッと消えるのは不可）。側面は角度ごとに不揃いな垂れ、受け皿に滴+たまり
- [ ] 鏡面: 完了後 roughness≦0.08+envMap強反射で周囲が映り込む艶。rainbowは滑らかな色相流れ
      （縞のジャギー不可）、pinkはマーブル、chocoは深い艶
- [ ] 冷凍ムース: フリーズ直後は霜の白いきらめき（微細スパークル）、グレーズ後は鏡面
- [ ] 透明型: 中の色層がガラス越しに屈折感を持って見える
- [ ] 断面: しっとりしたムース質感（微細ノイズ）+層の境界線+フルーツ断面（艶あり）が明瞭。
      単色ベタ塗りの縞は不可
- [ ] ナイフ: 金属反射のある刃+入刀時に断面がきらめく
- [ ] フルーツ・飾り: dome同等以上の質感（既存createDecoration水準）

## C. 共通照明・見せ方（両レシピ+コア）
- [ ] 主役スポット: スタンド上の主役を照らすキーライト強化+背後からのリムライト（輪郭光）で
      立体感。白飛び・全体ノッペリ不可
- [ ] 接触影: 器・ケーキの直下に柔らかい暗部（シャドウマップに加えブロブ影テクスチャ可）
- [ ] 環境マップ: 窓ハイライトを強めた高コントラスト版（鏡面・金属・飴の映えを改善）
- [ ] カメラ: 各見せ場で主役が画面の6〜8割を占める寄り。DONEオービットは俯角浅めで美しく

## 検収方法
各フェーズのスクリーンショットを撮り、上記チェックボックスを1つずつ照合する。
「遠目には良いが拡大すると単色」も不可（縦844pxスクショの等倍で判定）。
性能: celebrate相当の最重量シーンで、ヘッドレスSwiftShader計測でdome同等（±30%）の
フレームレートを維持していること（実機60fps相当の代理指標）。
