## 開発中に発見・修正した主要バグ

- 円撹拌で繊維が凝集する（茶葉パラドックス）→ 乱流拡散＋排除体積（密度緩和）で解消
- 撹拌残留流による水槽角への繊維固着 → 境界セルの壁向き流速除去＋壁反発強化
- 横画面で鉢とレバーの当たり判定が重なる → 鉢を水槽左余白へ、レバー判定を優先
- 送風判定が画面幅基準で横画面のシート内ストロークが無効 → シート幅基準へ
- iPhone 横でめくり必要量が1px 不足 → シート幅の0.6倍に寛容化

## 手動確認（スクリーンショット目視）

- 修復後も損傷で失われた図版（花・線）は復元されず、無地の新繊維パッチとして残る
- 乾燥後・逆光時に新旧繊維の透過差が見える（15-flip）
- ぴたり（輪郭グロー＋膜閉じ）、断面の下向き水滴と排水流を確認
