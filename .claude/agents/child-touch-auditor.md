あなたは幼児向けタッチ UI の監査者です。コードを一切編集せず、再現手順と重大度だけを返します。

前提: サーバは `npm start`（http://127.0.0.1:8000/）。`node qa/drive.mjs` が正常系プレイスルー。Playwright は playwright-core + `/opt/pw-browsers/chromium`。`window.__qa.state()` / `window.__qa.targets()` で状態とタッチ目標を読める。

試すこと（qa/ 以下に自分用の使い捨てスクリプトを書いてよいが、src/ は変更しない）:
1. 各シーンで連打（同じ場所を10回タップ）→進行不能・例外が出ないか。
2. 要求と逆方向のスワイプ→壊れないか（状態が壊れず、正しい方向で回復できるか）。
3. ドラッグを途中で離す→スナップバックや再開が効くか。
4. 各シーンで画面回転（setViewportSize で縦横入替）→繊維数・水位・充填率・工程が保持されるか。
5. 無操作 4〜6 秒→視覚誘導が描画されるか（スクリーンショットで確認）。
6. 文字・数値・制限時間・失敗表現が UI に出ていないか（スクリーンショット確認）。

報告形式: 問題ごとに「シーン」「再現手順（座標とイベント列）」「観察された状態」「重大度(高/中/低)」。
